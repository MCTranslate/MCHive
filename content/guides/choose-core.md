# 核心怎么选：决策树版

网上的核心选择教程喜欢把 Paper、Purpur、Pufferfish、Folia、Leaves 全部列出来讲一遍特性，看完你还是不知道选哪个。本站换个思路：**先说你的需求，直接给答案。**

## 10 秒决策版

> 想都不想，直接选 **Paper**。
>
> 90% 的插件服，Paper 都是最优解。往下看只是为了确认你是不是那特殊的 10%。

## 什么情况下不选 Paper

### 你要开超大型服务器（100+ 人同时在线）

选 **Pufferfish** 或 **Folia**。

- **Pufferfish**：Paper 的深度优化版，兼容 Paper 插件，适合 100 人以上的生存服。上手难度和 Paper 一样，直接替换 jar 即可。
- **Folia**：把世界拆成多线程区域跑，理论上限最高，但**很多插件不兼容**（插件需要专门适配 Folia）。除非你的服务器人真的多到 Paper 扛不住，否则别碰。

### 你要原版机制极致还原（红石机器不能坏）

选 **Paper**（关闭部分优化）或 **Leaves**。

Paper 为了性能会阉改一些原版行为，某些红石装置会失效。Leaves在 Paper 基础上做了「原版兼容修复」，国内生电圈用得比较多。红石党的完整方案：

- 先装 Paper 或 Leaves
- 在配置里关闭 `redstone-implementation` 相关优化
- 用红石机器逐个测试

### 你要加模组（Mod）混合玩法

插件核心和 Mod 核心是两个世界：

| 需求 | 选择 |
|------|------|
| 只要插件 | Paper / Pufferfish |
| 只要模组 | Forge / Fabric / NeoForge |
| 插件 + Forge 模组混合 | Mohist / Arclight |
| 插件 + Fabric 模组混合 | Cardboard（不成熟，慎用） |

混合核心的插件兼容性永远是最差的，很多 Paper 插件在上面会出诡异 bug。**能只用插件就不要混模组。**

### 你就是想折腾、想尝鲜

选 **Folia**、**Leaves** 或 **Mili**还有**arbor**跟**Lophine**。折腾精神值得鼓励，但请先在本站的 [避坑指南](#/guide/faq) 里确认你用的插件有没有 Folia 适配版。

## 核心版本怎么挑

2026 年 Minecraft 改用了年份版本号，先弄清这个再谈选版本：

```
旧方案：1.21 / 1.21.4 / 1.21.7 ...（2024-2025 年）
新方案：26.1 / 26.2 / 26.3 ...（2026 年起，数字 = 年份.序号）
```

当前（2026 年 9 月）玩家客户端主要分布在 **26.x**（如最新版 26.3，主题 "Wilderness Bound"）和 **1.21.x** 两个区间。三条铁律：

1. **跟随主流**：服务器版本 = 大部分玩家的客户端版本。开新服直接选 26.x；老服玩家都在 1.21.x 就继续留 1.21.x，等插件生态完全跟上再升。
2. **插件适配看核心不看版本**：现代主流插件大多同时支持 1.21.x 和 26.x，但小众插件要逐个确认，Folia 系尤其如此。
3. **别追最新**：核心和客户端更新当天就升是大忌，插件要一两周才能跟上。落后一个小版本最稳。
