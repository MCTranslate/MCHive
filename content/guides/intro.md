# 为什么是「MC 插件汉化站」

> 本教程更新于 2026 年 9 月，适用 Paper 26.x / 1.21.x / Folia 全系核心。

> 本站的三个关键词：**配置逐项讲** · **汉化开箱即用** · **组合直接抄**

## 我们是谁

你可能已经看过 [笨蛋开服教程](https://nitwikit.8aka.org/)——它确实是社区里最棒的开服百科。那为什么还需要我们？答案很简单：**笨蛋开服教你怎么把服务器开起来（从 0 到 1），我们教你怎么把服务器开好（从 1 到 100）。**

本站面向的读者画像：

- ✅ 已经跟着笨蛋开服或其它教程把服务器**开起来了**，但被插件配置折磨的人
- ✅ 想给服务器加**中文支持**、让玩家看到全中文界面的人
- ✅ 想知道「别人家服务器那个功能用什么插件实现」的人
- ✅ **第一次**开服，想少走弯路直接抄成熟方案的人

本站**不适合**的读者：

- ❌ 想了解红石机械原理或生电机理 → 请看专业生电教程
- ❌ 想开发自己的 Bukkit 插件 → 请看 Spigot/Paper API 文档
- ❌ 想找「一键安装包」→ 我们教的是原理和配置，不是封包

## 我们和笨蛋开服的差别

下面的表格不是踩一捧一，而是帮你判断该站资料能不能解决你当前阶段的问题：

| 维度 | 笨蛋开服 | 本站 |
|------|---------|------|
| 定位 | 通用开服百科，大而全 | 插件方向深度站，小而精 |
| 核心选择 | 罗列各核心特点，自己挑 | 决策树：说需求 → 给答案 |
| 插件讲解 | 安装命令 + 少量配置说明 | 安装 + **逐项配置** + 参数含义 + 推荐值 |
| 语言文件 | 需要自己找汉化、自己翻译、自己排错 | 每个插件提供**可下载的成品汉化** |
| 插件组合 | 单插件孤立讲解 | 按服务器类型给全家桶方案，含加载顺序与权限搭配 |
| 排错 | 散落在各章节的注意事项 | 独立速查手册 + 插件冲突表 + 日志模式速查 |
| 时效性标注 | 偶尔标注 | **每篇教程标注适用范围和更新日期** |

一句话总结：**笨蛋开服把你带到服务器门前，我们教你装修门后的每一个房间。**

## 我们解决的三件「笨蛋开服没做到的事」

### 1. 汉化文件开箱即用

全网的插件汉化散落在各种网盘、QQ 群文件、来路不明的帖子里，版本还不一定对得上。常见问题：

- 找到的汉化是半年前的，新版插件加了字段，汉化不完整 → 游戏里出现 `translation key not found`
- 找到的汉化是其他玩家 DIY 的，只翻译了他用的功能 → 一半中文一半英文
- 下载回来发现 YML 格式错误（中文引号、缩进不对）→ 插件直接报错加载失败

本站的做法：每个插件页面底部都有**一键下载**的成品汉化文件，和教程里的版本严格对应。下载 → 放进 `plugins/插件名/` → 重启，三步生效。

```
完整流程（全部只需命令行）：

1. 进入插件目录
   cd ~/mcserver/plugins/插件名/

2. 下载汉化文件（以 EssentialsX 中文语言文件为例）
   wget https://mctranslate.github.io/MCHive/downloads/plugins/essentialsx/lang_zh.yml

3. 修改 config 启用中文
   # 编辑 config.yml，找到 locale: en 改成 locale: zh

4. 重启服务器
   # 控制台输入：restart
```

### 2. 配置逐项讲人话

官方 config.yml 动辄几百行英文注释，笨蛋开服的插件章节基本上是「改这里就行」——新手想调一调，发现压根不知道每个参数的含义。

本站每个插件的 Config Tab 都是**逐项中文注释版**：这个是干什么的、默认值是什么、改大了会怎样、推荐值是多少、什么情况下需要改。

你甚至不用下载，直接在网页上对照抄到你的配置文件里。

示例对比（同一个 LuckPerms 配置项）：

```yaml
# ======= 官方英文注释 =======
# The method used to store data. 
# See: https://luckperms.net/wiki/Storage
storage-method: YAML

# ======= 本站中文注释 ======= 
# ❶ 存储方式：决定插件数据存在哪里
#    可选值：YAML（单服推荐）、MYSQL（多服必选）、MARIADB、SQLITE
#    默认值：YAML
#    推荐值：单服保持 YAML，多服群改 MYSQL
#    修改后需：重启生效，旧数据需迁移（见本站 Wiki）
storage-method: YAML
```

### 3. 组合方案直接抄

开服最难的从来不是装插件，是**选型**：

- 「权限插件有 LuckPerms、PermissionsEx、GroupManager 和 UltraPermissions，我用哪个？」
- 「经济插件有 EssentialsX Economy、XConomy、Conomy，能不能混着用？」
- 「Multiverse-Core 和 MyWorlds 都管世界，装两个会不会冲突？」

现在你不需要再纠结了。本站按服务器类型给出完整的全家桶方案：生存服用什么、RPG 服用什么、小游戏服用什么、公益服用什么，互相之间的权限依赖关系、加载顺序、兼容版本都写清楚了。装完一次到位。

## 本站承诺：只推荐免费插件

这也是和很多教程站的本质区别。网上大量教程「顺手」推荐付费插件（LiteBans、MMOItems、BedWars1058 这类），新手照着买一圈下来几百块，其中一半功能用不上。

本站所有推荐遵循两条铁律：

1. **只收录免费插件**——优先开源项目，作者跑路了社区还能 fork 继续维护
2. **付费插件只出现在对比说明里**——告诉你付费版的差异在哪、免费方案能覆盖到什么程度，绝不做无脑推荐

省下的钱给服务器升个配，不香吗。

## 时效性保证机制

插件版本和 Minecraft 版本都在快速变化（2026 年 Minecraft 已改用年份版本号，如 26.3）。我们保证：

| 机制 | 说明 |
|------|------|
| | **每篇教程标注适用版本**（如「适用 Paper 26.x」） |
| | **保留历史版本说明**（旧版流程用折叠块标注，不删除） |
| | **更新说明章节**顶部标最后更新日期 |
| | **社区纠错渠道**：发现内容过期可直接在 GitHub 提 Issue |

## 关于内容共建

本站是开源项目，所有教程和汉化都托管在 GitHub。我们需要的共建类型：

- 🔧 **纠错**：发现配置项翻译错误、命令拼写错误、版本号过时
- 📝 **补全**：某插件的 config 有参数你更了解 → 提 PR
- 🌐 **汉化**：能翻译但找不到汉化文件的小众插件 → 提交成品
- 📖 **教程**：想写某个专题（如 BungeeCord 群组服搭建、MySQL 部署等）→ 联系我们

我们相信：**插件生态的中文资料，应该由中文玩家一起维护。**
