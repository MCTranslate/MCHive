# Maintenance 汉化机制

> 以下结论来自官方仓库文件树核实。**这一页的重点是：Maintenance 只有繁体中文，没有简体。**

## 一、语言文件清单

仓库里中文相关只有一个文件：

```
language-zh_tw.yml    ← 繁体中文
```

**没有** `zh_cn.yml`，也**没有** `zh-CN.yml`。

| 语言 | 文件 | 状态 |
|------|------|------|
| 繁体中文 | `language-zh_tw.yml` | ✅ 官方提供 |
| 简体中文 | — | ❌ **官方未提供** |

注意命名是 `language-` 前缀 + **连字符**，这是和其他插件的常见风格（GSit 用 `zh_cn.yml` 下划线，Carbon 用 `messages-zh_CN.properties`），**三者不通用**。做通用汉化方案时别想当然。

## 二、对简体中文服的实际影响

**简体中文客户端进服，Maintenance 的界面提示是英文。**

具体哪些地方会露出来：

- `/maintenance` 的状态回显
- 玩家被踢出时的提示消息
- 维护模式相关的操作反馈

如果你的服是简中玩家为主，这部分会比较显眼。

## 三、怎么给简中服补一份简中

这是唯一可行的办法（除非 PR 给作者提交），而且**比想象的简单**。

### 操作步骤

```
1. 进 plugins/Maintenance/ 目录
2. 复制 language-zh_tw.yml 一份，命名 language-zh_cn.yml
3. 打开新文件，把里面繁体字逐条改成简体
4. 改完重启服务器
```

**键名一个字都不要动。** 只改等号后面的值。这是 YAML，语言文件是 `键: 值` 结构——具体格式以你手上那份 `language-zh_tw.yml` 为准。

### 繁体 → 简体的替换思路

繁体转简体**不是纯字符替换**。有几类字一对一，但更多的需要换词：

| 类型 | 例子 | 能不能直接换 |
|------|------|------------|
| 一对一简繁对应 | 設→设、護→护、執→执 | ✅ 可以 |
| 需要换用词 | 資訊→信息、記憶體→内存 | ❌ 官方简中用词习惯不一样 |
| 地区用词差异 | 伺服器→服务器、软件→軟件 | ⚠️ 简中玩家习惯是「服务器」 |

**建议用现成的繁简转换工具处理一遍，然后人工检查关键句子。** 逐个手改 20 条消息不现实，但漏改一两个词玩家也不会怪你——**比全英文好得多**就够了。

> ⚠️ 命名必须是 `language-zh_cn.yml`，**和繁体那份的命名风格保持一致**（前缀 `language-`、连字符、小写语言码）。写成 `lang_zh_cn.yml` 不会被加载，插件静默回退英文，**不报错**。

## 四、四个容易踩的坑

**文件名写错，静默失效**

插件找不到对应语言文件时**不报错**，直接用默认英文。所以「改了半天没反应」十次里有八次是文件名问题。改完必须**实际验证**。

**改了没生效**

语言文件在启动时加载。**完整重启服务器**，`/maintenance reload` 是否重读语言文件取决于版本，不确定就重启。

**直接在 jar 里改**

不要。升级插件就没了。语言文件要从数据目录读，不是从 jar 读。

**用繁体那份当模板改出问题了**

`language-zh_tw.yml` 里可能有**只在繁体下才有的条目**（比如某些只在特定地区显示的提示）。照抄结构没问题，但要意识到有些条目简中下根本不会触发。

## 五、验证有没有生效

```
改完重启 → 用简体中文客户端进服
  → 敲 /maintenance
  → 看回显是中文还是英文
```

**还是英文** → 回检查文件名（最常见原因）。
**还是英文但文件名对** → 确认你改的是 `plugins/Maintenance/` 下的文件，不是别处复制来的。
**显示繁体** → 你可能复制错了源文件，或者文件名指向不对。

## 六、什么不会被汉化

语言文件只管**插件自己发出的文本**。这些仍然是英文或由你决定：

- **原版界面元素**（踢出界面、按钮）—— 跟随客户端语言
- **你配置文件里自己写的告示文本** —— 在配置文件里写，可以直接写简中
- **其他插件的提示** —— 各写各的

## 七、全站汉化机制对比

| 插件 | 简中 | 繁中 | 文件名风格 |
|------|------|------|-----------|
| **Maintenance** | ❌ | ✅ | `language-zh_tw.yml` |
| GSit | ✅ | ✅ | `zh_cn.yml` / `zh_tw.yml` |
| LifestealZ | ✅ | ✅ | `zh-CN.yml` |
| SkinsRestorer | ❌ | ❌ | 无语言文件（硬编码英文） |
| Carbon | ✅ | ✅ | `messages-zh_CN.properties` |

**结论：简中覆盖率不是 100%。** 本站的汉化机制逐插件核实，就是因为「哪个有简中、哪个没有」完全是插件作者各自决定的，没有统一规律。
