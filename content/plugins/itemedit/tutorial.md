## ItemEdit 安装教程

### 1. 它是什么

ItemEdit 是一个**纯命令驱动的物品编辑器**。核心价值是：让你不靠 `/give` 后面那一长串 NBT，就能把一个物品改成你想要的样子。

| 能做 | 例子 |
|------|------|
| 改名 / 改 Lore | 「&b寒冰之刃」+ 一段说明，支持复制粘贴 |
| 隐藏附魔 + 发光 | 附魔照常生效，但 Lore 里不显示——**这是最经典的用法** |
| 自定义药水颜色 | 超过 65000 种颜色，还能把药水效果藏起来做「秘密药水」 |
| 改属性 | 护甲值、最大生命、伤害、攻击速度等 |
| 材质 / 稀有度 | 皮革盔甲染色、药水颜色、自定义 model data、稀有度配色 |
| 改模型 | custom model data、item model（**做资源包必备**） |
| 特殊物品 | 烟花、旗帜（GUI 编辑）、指南针指定目标、图书类型、护甲纹饰 |
| 改持久 / 修复 | 无敌耐久、一键修复 |
| 变食物 / 变装备 | 把任何物品变成可吃的、或者可穿戴的 |
| 其他 | 隐藏标签、鞘翅、不可破坏、20+ 子命令 |

### 2. 三条命令线的定位

ItemEdit 有三个主命令，**分清楚了就不乱**：

| 命令 | 别名 | 干什么 |
|------|------|--------|
| `/itemedit` | `/ie` | 改**你手上**的物品 |
| `/serveritem` | `/si` | 改**服务器统一管理**的物品，能给、卖、买 |
| `/itemstorage` | `/is` | **玩家个人**的物品仓库 |

选哪个：

- 玩家自己想改着玩 → `/ie`
- 你要做「商城里卖的那把屠龙刀，全服玩家拿到的都是同一把」 → `/si` + `save`
- 创造服玩家想存自己做的花样 → `/is`

`/ie` 改的是**物品实例**，`/si` 管的是**服务端注册的物品模板**。这两个不是一回事——用 `/ie` 改完的物品不会自动同步给别人，必须走 `/si` 才能统一发放。这是新手最常混的一点。

### 3. 前置依赖

| 插件 | 必要性 | 用途 |
|------|--------|------|
| 无 | — | 核心功能自足 |
| Vault + 经济 | 可选 | `/si` 的买卖功能 |
| PlaceholderAPI | 可选 | 变量 |
| ShopGUI+ | 可选 | 商店集成 |

平台：3.6.3 提供 **Bukkit / Paper / Purpur / Spigot** 构建（3.7.x 起才加了 Folia）。

### 4. 权限模型

权限格式很规整：

```
itemedit.<命令>.<子命令>
```

举例：

- 改名 → `itemedit.itemedit.rename`
- 用 `/itemedit` 主命令 → `itemedit.itemedit`
- 用 `/serveritem` → `itemedit.serveritem`
- 用 `/itemstorage` → `itemedit.itemstorage`

**这里有个必须注意的现实问题**：权限节点细到这个粒度，意味着「部分 OP 用不了」是常态。作者在评论里给的标准答复是——**用任意权限管理插件管理这些节点**（LuckPerms 是最常见的）。完整列表见插件仓库的 `plugin.yml`。

> 如果你打算给玩家部分编辑能力（比如只允许改名和加 Lore，不允许改属性），**必须逐个子命令配权限**。默认全开的做法会让「无限耐久 + 高攻击」流入普通玩家手里。

### 5. 常用命令

**`/ie`（改手上物品）**

| 子命令 | 作用 |
|--------|------|
| `rename` | 改名字 |
| `lore` | 改 Lore |
| `amount` | 改数量 |
| `enchant` | 加附魔 |
| `attribute` | 改属性（护甲/生命/伤害/攻速） |
| `glow` | 发光（配合 `hide` 就是隐藏附魔） |
| `hide` / `hideall` | 隐藏指定 / 全部附魔标签 |
| `unbreakable` | 不可破坏 |
| `custommodeldata` | 自定义 model data |
| `color` | 药水/皮革盔甲染色 |
| `firework` | 烟花（GUI） |
| `banner` | 旗帜（GUI） |
| `food` | 改食物属性 |
| `rarity` | 稀有度颜色 |
| `maxdurability` | 改最大耐久 |
| `repaircost` | 修复成本 |
| `save` | 存成服务器物品 |
| `show` | 查看手上物品的信息 |
| `help` | 分页帮助 |

**`/si`（服务器物品）**

| 子命令 | 作用 |
|--------|------|
| `save` | 把手上物品注册为服务器物品 |
| `give` / `giveall` | 给自己 / 全服发放 |
| `drop` / `take` | 丢给玩家 / 从玩家收回 |
| `sell` / `buy` | 通过 Vault 卖 / 买 |
| `show` | 打开 GUI 浏览 |
| `setnick` | 设置昵称 |
| `update` / `delete` | 更新 / 删除 |

**`/is`（个人仓库）**

`save` / `get` / `update` / `delete` / `show`

**工具命令**

| 命令 | 作用 |
|------|------|
| `/itemeditreload` | 重载配置和语言文件 |
| `/itemeditinfo` | 看插件版本 + 依赖挂载状态（Vault/PAPI 有没有接上） |
| `/itemeditimport` | 从老版本 ItemEditor 导入物品 |

`/itemeditinfo` 排错很有用——装了 Vault 但没生效，先跑它。

### 6. 三个实用配方

**隐藏附魔发光**

```
/ie enchant sharpness 5
/ie glow
/ie hideall
```

效果：剑有 5 锋利，实际伤害生效，但玩家看不到「锋利 V」这行字，也不会发光提示。

**秘密药水**

```
/ie color #RRGGBB
/ie hideall
```

药水颜色自定义 + 效果信息隐藏。用来做「只有喝下去才知道是什么」的活动道具。

**统一发放的定制物品**

```
# 1. 管理员手上拿把剑，改好
/ie rename '&b&l寒冰之刃'
/ie lore '&7冰封之地的遗物'
/ie enchant sharpness 5 damage_all 3
/ie attribute attack_damage 12
/ie glow

# 2. 注册成服务器物品
/si save

# 3. 发放（用注册时取的标识）
/si give <标识> <玩家>
```

> 标识怎么填，以你版本的 `/is show` GUI 里显示的为准。命名规则是插件自定的，**别猜，直接看 GUI**。

### 7. 1.20.5+ 的两个真坑

这两个是新版特有的，值得单独拎出来。

**① 属性不再按槽位生效**

1.20.5 起，属性绑定的是**装备槽位组**而不是单个槽位。`hand` 这个别名**同时指主手和副手**。

作者在评论里给的处理方式是：改 `aliases.yml` 里的 `equip_group`，把

```yaml
hand: hand
```

改成

```yaml
hand: hands
```

或者直接删掉 `aliases.yml` 让插件重新生成。这条对「只想要主手生效」的服很关键。

**② 物品名字默认被强制斜体**

改名后名字会变成斜体。作者给的绕过办法是在名字开头加 `<!i>`。这是客户端渲染行为，插件层面只能绕。

### 8. 汉化

> **本站未核实到该插件的官方中文语言文件机制，若要汉化需自行确认。**

ItemEdit 的汉化有个**很实际的前提**：

它的很多玩家可见文本是你**自己在物品上写的**（改名、加 Lore），那部分天然就是中文。真正需要汉化的是插件自己的提示消息。

需要改的：

| 改什么 | 在哪 |
|--------|------|
| 插件提示消息 | 语言文件（打开 `plugins/ItemEdit/` 找 messages / lang 之类的文件，**以实际文件名为准**） |
| 命令帮助 | 同上，帮助文本也在语言文件里 |
| 物品名称 / Lore | 不用改文件，直接用命令写中文 |

**一个需要验证的点**：插件自称支持「按客户端语言发送消息，内置 10+ 语言」，物品材质名会自动翻译成各客户端语言。**这意味着可能有内置中文**，但本站没有核实到具体是哪种语言文件机制、文件名是什么、简体中文是否完整——**请你自己打开语言目录确认**。

> 别急着下结论说「支持 10+ 语言所以肯定有中文」，也别说「没有中文文件」。打开看，这是 10 秒钟的事。

`/itemeditreload` 会同时重载配置和语言文件，改完直接用。

### 9. 常见坑

**命令说没权限，但我是 OP**

权限节点是 `itemedit.itemedit.<子命令>` 这种粒度。OP 默认应该都有——**如果你用了 LuckPerms 且 OP 没有被自动继承全部节点**，就会这样。用 `/lp user <名> parent info` 看 OP 实际拿到什么。

**物品给别人就消失 / 变成原版物品**

经典问题。两种原因：

1. 服务器有**物品白名单/反作弊插件**在清理 NBT 异常物品
2. 资源包里的 custom model data 对不上

排查顺序：先拿另一个玩家测试（同账号不行），再查反作弊插件日志。

**GUI 打开报错**

1.20.5+ 的物品组件格式变化可能让旧 GUI 逻辑出错。检查控制台堆栈，尝试更新到 3.7.x。

**改完的物品在别的插件里显示异常**

ItemEdit 用 NBT 和 meta 改物品。如果同时用了 MMOItems / ItemsAdder / 高级附魔插件，**它们的 item handler 会在 ItemEdit 之后重新解析物品**，可能覆盖掉你改的东西。这类插件的相性需要实测。

**改的属性无效（攻击速度消失之类）**

先确认 1.20.5 的槽位组问题（第 7 节），再确认属性名写对了没。
