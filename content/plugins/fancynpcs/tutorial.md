## FancyNpcs 安装教程

### 1. 先搞清它「轻量」在哪

市面上的 NPC 方案分两类：

| 方案 | 原理 | 代价 |
|------|------|------|
| **重型**（经典做法） | 在服务端真的生成一个实体（通常是假玩家） | 占实体数、吃性能、有时会被反作弊/区块机制影响 |
| **FancyNpcs 这类** | **用数据包向客户端发送「假实体」** | **服务端不生成实体** |

**这带来的差别很实在：**

- **100 个 NPC 不会把实体计数撑爆**
- **不触发 mob 相关机制**（刷怪上限、附近怪物 AI 之类）
- **玩家看不见它们被区块卸载**——它们跟着玩家的可见范围走

> FancyNpcs 官方自我描述是「简单、轻量、快的**数据包** NPC 插件」。这个技术路线是它和重型方案的根本区别，也是它性能好的原因。

### 2. 它能做什么

| 功能 | 说明 |
|------|------|
| **创建 NPC** | 站着的、坐着的、睡着的姿势 |
| **自定义皮肤** | 指定皮肤（玩家名/皮肤站/图片） |
| **自定义显示名** | 头顶的名字，支持 MiniMessage 格式 |
| **点击对话** | 玩家右键 NPC 触发一段文字 |
| **点击执行命令** | 右键触发命令（可加权限检查） |
| **消息框** | 带按钮的GUI 对话（可让玩家点按钮执行命令） |
| **体型/姿态/装备** | 外观细节调整 |
| **可见性控制** | 按权限隐藏某些 NPC |

**「点击执行命令」是这个插件的核心用途**——它把 NPC 变成了**功能性入口**：

```
点「公会传送员」NPC  →  弹出按钮菜单  →  点「主城」  →  传送到主城
点「新手引导员」NPC  →  右键  →  触发一段任务/对话
```

### 3. 什么时候用

**值：**

- **功能入口** —— 需要一个「点哪里就能做某事」的界面
- **装饰/迎宾** —— 主城门口的引导 NPC
- **教程引导** —— 新手村的 NPC 指引
- **商店/功能 NPC** —— 不想做复杂 GUI 时的轻量替代

**不值 / 先想清楚：**

- **需要 NPC 有真实行为的**（会走动、会战斗、会被攻击）—— **它做不到**。它是纯客户端渲染的假实体，服务端没有这个实体
- **想要真 NPC**（能对话、能加入队伍、能被保护）—— 这个不是干这个的
- **纯装饰大型场景** —— 满屏 NPC 虽然不占实体，但视觉上仍然需要你仔细摆

> ⚠️ **「NPC 不存在于服务端」这件事有实际影响。** 比如 `/kill` 杀不到它、世界保护插件管不到它、它不会被区块卸载机制影响。反过来说，**它也不会被任何保护机制误伤**——这是好事也是坏事，取决于你想要的保护级别。

### 4. 前置条件

| 要求 | 说明 |
|------|------|
| **服务端** | **Paper / Folia**（Modrinth 标注 paper，**不建议在 Spigot 上用**） |
| **MC 版本** | 1.19.4 起 |
| **硬依赖** | 无 |
| **可选** | MiniMessage 格式支持、跨服 |

**支持 Folia** 是个加分项——如果你跑 Folia，NPC 类插件能用的不多。

### 5. 安装

1. 从官方渠道下载（**FancyInnovations/FancyPlugins**，Modrinth: `fancynpcs`）
2. 丢进 `plugins/`
3. 启动

**注意**：`FancyPlugins` 是一个**插件合集仓库**，里面有 FancyHolograms、FancyDialogs、FancyEconomy 等。**你只需要 FancyNpcs 一个的话，下载 FancyNpcs 的单独 jar**，别把全家桶都塞进去。

生成的配置目录是 `plugins/FancyNpcs/`。

**命令**以你版本的 `plugin.yml` 和文档为准。官方文档在 `fancyinnovations.com/docs/minecraft-plugins/fancynpcs`。

> ⚠️ **版本号要留意**：Modrinth 上 FancyNpcs 的发布是 `2.12.1`、`2.12.1+377` 这种形式（带构建号），**而且3.x 的快照也在同时发布**。**装之前看清你下的是哪个通道** —— 快照版和稳定版行为可能不同。

### 6. 一个必须知道的坑：MiniMessage

FancyNpcs 支持 **MiniMessage 格式**。这意味着：

- 颜色/装饰/渐变/悬浮/点击都能用
- **但 MiniMessage 格式写在普通配置文件里，如果你的服务器装了**某些格式化插件**，可能产生格式冲突

**这是装 FancyNpcs 之前值得确认的一件事**：你服上有没有其他插件在管聊天/显示格式（EssentialsX Chat、Carbon 等）。**多个插件都想管格式是聊天插件冲突的头号原因**，NPC 的显示名也会被牵连。

> 具体格式语法请见 MiniMessage 官方文档，**本页不复述语法** —— 抄一份可能过时的语法比不抄更糟。FancyNpcs 官方文档里有 MiniMessage 使用说明。

### 7. 常见坑

**NPC 看不见**

- 数据包发送基于玩家的可见范围，**玩家不在附近就是看不见** —— 这是设计如此
- 确认玩家不是隐身的某些状态
- 版本不匹配（NPC 是按 MC 版本的数据包格式发的，**服务端版本要和玩家客户端匹配**）

**皮肤不显示**

- 皮肤来源是否有效（皮肤站需要玩家名或 UUID）
- 首次加载可能有延迟
- **玩家自己的皮肤**（正版/Xbox 绑定）在某些条件下才生效

**点击没反应**

- 权限不足（NPC 配置里可以设权限要求）
- 没有可交互的交互配置
- 确认命令执行者——**配置里要设命令由谁执行（玩家还是控制台）**

**和其他 NPC/ hologram 插件冲突**

⚠️ **同类插件装多个必出问题。** FancyHolograms、FancyNpcs 是同一个合集里的不同插件（不同功能，可共存）；但**别的 NPC 插件和它不兼容**。**同类只装一个。**

**性能担忧**

**这个插件性能很好**（这是它的核心卖点），但也别无脑塞：

- 每个 NPC 都要持续向附近的玩家发数据包
- **玩家越多、离得越近，发包越多**
- 一堆 NPC 站在主城中心，所有路过的人都收到它们的数据

> 实践上：**几十个到一两百个 NPC 完全不是问题**（这是它比重型方案好的地方），但别做上千个。

### 8. FancyNpcs vs FancyHolograms

这两个是同一个合集（FancyInnovations/FancyPlugins）的插件，**功能不重叠，可以共存**：

| 插件 | 做什么 |
|------|--------|
| **FancyNpcs** | 拟人化 NPC（人形的，可以有皮肤、姿势、对话） |
| **FancyHolograms** | 全息文字/物品/方块悬浮展示（不是人形） |

**选择：**

- 想要「一个人站在那儿，可以对话」→ FancyNpcs
- 想要「一行字飘在门框上」/ 「展示一个物品」→ FancyHolograms

### 9. 关于汉化

**本站未核实到该插件的官方中文语言文件机制。** 若要汉化需自行确认。

我们核实了它的仓库（FancyInnovations/FancyPlugins），在 `plugins/fancynpcs/src/main/resources/languages/` 目录下有一个 `default.yml`，**但没有找到中文语言文件**。

**这意味着：**

- 插件的**系统提示消息**是英文
- 但**NPC 的显示名、对话内容是你自己配的** —— **这些直接写中文就行**，不走语言文件

**要汉化系统消息的话：**

1. 进 `plugins/FancyNpcs/` 看有没有语言覆盖目录
2. `default.yml` 里的键值是可改的，**具体键名和加载方式以你版本的文件结构为准**
3. 仓库 `FancyInnovations/FancyPlugins` 里搜 `languages` 目录了解机制

> **好消息**：这个插件最需要汉化的部分（NPC 对话）本来就在配置里，你直接写中文。真正需要改语言文件的只有系统提示，价值有限。
