# BlueMap 网页地图自带多语言 — 无需配置

**结论先说：BlueMap 的网页地图界面自带多语言支持，自动跟随玩家浏览器的语言设置。**

## 机制

BlueMap 的 Web 前端（网页界面）内置了多语言文件，浏览器会自动选择对应的语言版本。你的玩家用中文浏览器打开，就会看到中文界面——**服务端不需要任何配置**。

## 如果需要自定义翻译

BlueMap 的翻译同样通过 **Crowdin** 社区协作维护（[crowdin.com/project/bluemap](https://crowdin.com/project/bluemap)）。如果你发现某个词条翻译不准确，可以在 Crowdin 上提交修改，下个版本就会带上。

## 网页地图上能看到什么

- 3D / 2D / 洞穴三种视图模式
- 在线玩家的实时位置标记
- 世界时间、天气、坐标显示
- 点击区块可查看详细信息

> 这些功能由前端 JS 驱动，与 `config/paper-world.yml`（Paper 的世界配置）无关。
