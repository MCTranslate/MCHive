## AtomShulkers 安装教程

### 1. 它就干一件事

原版潜影盒（Shulker Box）**必须放在地上才能打开**。手里拿着一个装满东西的潜影盒，想看内容，只能先蹲下放地上、开界面、再收起来。

AtomShulkers 让你**拿着就能开**。

就这么一件事，做完了。

### 2. 为什么原版要这么设计

这不是原版忘了，是**有意为之**，而且理由很硬：

| 原因 | 说明 |
|------|------|
| 潜影盒是**容器方块** | 它占一个方块槽位，能被活塞推动、被爆炸摧毁、被水流冲走 |
| 手持开盒没有方块位置 | 盒子「不存在」在世界里，开关时它在哪？ |
| 潜影盒是潜影壳做的 | 做成不可移动的「背包」会破坏它的设定 |

**换成实际影响**：原版设计里，你必须把潜影盒放在固定位置（家、船上、商店）才能当存储用。**AtomShulkers 把这个限制解开了。**

对玩家的实际收益：

- 塞满东西的潜影盒可以直接拿出来清点
- 战利品箱里掏潜影盒不用反复蹲下放起
- 手上拿着潜影盒时想拿东西，不用先找地方放下

**收益明确，但不大。** 这是一个「用了会感谢、没用也不会难受」的小插件。

### 3. 安装

- 源码 / 问题反馈：<https://github.com/atombuilt/atom-shulkers>
- Hangar：搜 `AtomShulkers`（作者 atombuilt）
- Modrinth：搜 `AtomShulkers`

```
1. 下载对应 MC 版本的 jar
2. 丢进 plugins/
3. 重启
```

**没有前置，没有依赖，没有配置步骤。** 这是它最舒服的地方。

### 4. ⚠️ 严格的环境要求

这个插件的门槛全在运行环境上：

| 项目 | 要求 |
|------|------|
| MC 版本 | **1.19.4 - 1.20.4**（注册表记录的区间） |
| 平台 | **Paper**（Modrinth 标注的平台只有 Paper） |
| Java | **17+** |

**这三条都要注意：**

⚠️ **MC 上限只到 1.20.4。** 1.21+ 没有支持版本。这是小插件的常态——作者维护到某个点就停了。**要在新版本上用得自己承担风险。**

⚠️ **平台标注是 Paper。** Spigot 系能不能跑没明确说。Paper 本身就是 Spigot 的超集，理论上大部分情况能跑，但**没有核实到官方声明**，自己测。

⚠️ **Java 17+。** 1.19.4 以后的 MC 本身就要 Java 17，这条基本自动满足。

### 5. 没有任何设置

**这个插件没有配置文件。**

| 项目 | 有没有 |
|------|--------|
| 配置文件 | 无 |
| 命令 | 无 |
| 权限 | 无 |
| 配置项 | 无 |

作者的说法是「尽可能简单、完全原版友好」。所以你**别去找配置文件**——找不到不是因为路径不对，是真的没有。

**没有任何开关**意味着：

- 你**不能**限制哪些玩家能用
- 你**不能**改成需要按某个键才打开
- 你**不能**关掉它对某个世界的效果

**全服统一生效。** 对一个零配置的小插件来说这是合理的；对需要精细管理的服来说，这是限制。

### 6. 它做了什么 / 没做什么

搞清楚边界，避免想当然：

| 行为 | 插件接管了？ |
|------|------------|
| 手持潜影盒打开 GUI | ✅ 这是它的全部 |
| 潜影盒丢在地上打开 | ❲ 原版行为不变 |
| 潜影盒放容器里再取出 | ❲ 原版行为 |
| 潜影盒作为方块被活塞推动 | ❲ 原版行为 |
| 潜影盒在潜影盒里（禁止嵌套） | ❲ 原版限制不变 |
| 潜影盒的耐久 / 破损掉落 | ❲ 原版行为 |

**它不改变潜影盒本身的任何性质**，只是省掉「放下再捡起」这一步。

### 7. 可能的功能冲突

如果你的服**已经装了别的开箱插件**，要注意重名行为：

| 类型 | 冲突情况 |
|------|---------|
| 另一个「手持开箱」插件 | **两个都想处理同一个右键事件**，可能出现重复打开、GUI 闪退、物品状态异常 |
| 箱子 GUI 类插件 | 潜影盒界面可能被接管 |
| 大型菜单 / 背包类插件 | GUI 框架不同，可能渲染不出来 |

**如果你已经在用别的开箱插件，先想清楚要不要装它。** 装之前备份，最好在测试服先试。

### 8. 常见问题

**没反应**
- 检查 jar 在不在 `plugins/`
- 确认看的是 `plugins/` 目录不是某个子目录
- 重启了没（不是 `/reload`）
- Java 是不是 17+
- 手上拿的**确实是潜影盒物品**，不是潜影壳、不是别的箱子

**潜影盒打开后又立刻关上 / GUI 闪退**
典型的功能冲突。**卸掉其他开箱类插件。**

**潜影盒的 GUI 显示异常（物品错位、名字乱码）**
也可能是和其他 GUI 插件打架。逐个排查。

**能不能给部分玩家关掉**
**不能。** 插件没有权限系统也没有配置。要限制只能靠权限插件**卸载它**——那就没意义了。

**能不能改成右键不打开、只有潜影盒才开**
不能，它只作用于潜影盒，已经是这个行为了。

### 9. 关于汉化

**没有核实到官方中文语言文件机制。**

**但这个插件大概率根本不需要汉化**——理由是它**没有配置、没有命令、没有任何玩家可见的文本**。

一个「手持开箱」的插件，玩家能看到的只有原版潜影盒 GUI 界面，而那个界面是**原版客户端渲染的**，服务端插件改不了。

引导式排查（只是为了确认）：

1. 解压 jar 看 `resources/` 下有没有语言资源（按作者的风格，大概率没有）
2. 启动后看 `plugins/` 下是否生成了新目录（大概率只有 bStats 的配置）
3. **如果你看到的是英文文本，那不是这个插件的**——那是原版界面或其他插件的

> **需要汉化别的插件？** 潜影盒相关的 GUI 如果要汉化，去查同服其他 GUI 类插件。

### 10. 什么时候别用它

- **已经在用同类开箱插件** → 功能重复，还会冲突
- **1.21+ 的服** → 没有支持版本，风险自己担
- **要求精细控制（谁能用、在哪生效）** → 它没有任何开关
- **想解决的是「潜影盒放哪」的管理问题** → 这是个体验插件，不是存储管理方案
