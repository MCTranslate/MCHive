## Nova 安装教程

### 1. 它是什么

Nova 的定位是**服务端的「伪模组」框架**。目标是：把模包里那些爽点搬到插件服务器上，**但玩家手机上什么都不用装。**

实现方式是资源包 + 服务端逻辑：

```
管理员上传资源包（自定义材质、模型）
        ↓
玩家进服时自动下载
        ↓
服务端发「这个物品叫星星镐、伤害 8、附魔 XX」
        ↓
玩家看到的是自定义图标和 3D 模型，功能是真的
```

**这是它和 Minecraft 资源包最大的区别**：原版资源包只能换皮，Nova 的资源包**带着真实的服务端数据**——物品属性、配方、机器行为都是服务端算的。

### 2. 它能做什么

| 模块 | 内容 |
|------|------|
| **自定义物品** | 工具、武器、护甲、食物、可穿戴物，可自定义伤害、攻速、耐久、击退抗性 |
| **自定义方块** | 可自定义破坏时间、粒子、音效，甚至能做成实体方块 |
| **机器** | 太阳能板、充电器、粉碎机、熔炉、石头生成器等 |
| **线缆网络** | 自定义电缆和电网，把机器连成网络供能 |
| **存储** | 真空吸尘箱、超大存储单元、流体罐 |
| **GUI** | 自定义界面 |
| **TileEntity 系统** | 有方块实体数据的东西（掉落物、展示框等）能挂上 NBT |
| **能力系统** | 给物品加特殊能力 |
| **配方系统** | 自定义合成类型，不只是工作台 |
| **NPC / 任务** | 通过 addon 提供 |

### 3. 硬依赖：一个都没有

**Nova 本体没有硬依赖。** 但有两件事必须做：

| 要求 | 说明 |
|------|------|
| **服务端** | Paper / Spigot / Purpur（**1.19.3+**） |
| **资源包** | 必须配置并让玩家下载，否则自定义物品显示成紫黑方块 |

**资源包这一条是最容易翻车的。** 装完 Nova 不配资源包，玩家看到的所有自定义物品都是紫黑块的「未找到物品」纹理。

### 4. 安装

- Modrinth 搜 `nova`
- 官方 wiki：<https://wiki.novamc.dev/>

步骤：

1. Nova jar 放 `plugins/`，重启
2. 编辑 `plugins/Nova/config.yml`，按注释配置资源包上传地址
3. **生成并上传资源包**（`/nova resourcePack` 相关命令）
4. 玩家进服自动下载

> ⚠️ **资源包地址玩家必须能访问。** 你填一个只有自己内网能访问的地址，玩家就下不到，然后满屏紫黑块。填公网可访问的直链或用对象存储。

### 5. 机器系统怎么玩

Nova 的机器是它最有存在感的功能。几个典型的：

| 机器 | 作用 |
|------|------|
| **太阳能板** | 从阳光采集能量（**晚上不发电**，但存的能量还能用） |
| **充电器** | 存储多余能量，给需要电力的设备或物品充能 |
| **粉碎机** | 把矿石粉碎成原料 |
| **石头生成器** | 水+岩浆自动产石头，也能产黑曜石（会消耗岩浆） |
| **真空箱** | 半径内自动吸取掉落物 |
| **存储单元** | 存放远超 64 堆上限的物品 |
| **流体罐** | 存液体，多个档位 |

**通用流程**：太阳能板 → 电缆 → 充电器 → 设备。

**石头生成器的 GUI 有输入和输出槽**，很多人以为坏了其实是不会用。

### 6. 常用命令

| 命令 | 权限 | 说明 |
|------|------|------|
| `/nova items` | `nova.command.items` | 列出 Nova 和所有 addon 的全部物品 |
| `/nova give [玩家] [物品]` | `nova.command.give` | 给自己或别人发自定义物品 |
| `/nova advancedTooltips <on/off>` | `nova.command.advancedTooltips` | 开关高级物品提示 |
| `/nova addons` | `nova.command.addons` | 列出已安装的 addon |
| `/nova resourcePack` | `nova.command.resourcePack` | 资源包系统主命令 |
| `/nova reload` | `nova.command.reload` | 重载插件和所有 addon |
| `/nova renderDistance <1-6>` | `nova.command.renderDistance` | 设置 Nova 自己的渲染距离 |
| `/nova debug` | `nova.command.debug` | 调试：显示额外信息、重载网络 |
| `/nvrecipe` | `nova.command.nvrecipe` | 查看手上物品的配方 |
| `/nvusage` | `nova.command.nvusage` | 查看手上物品的用途 |

> **`/nova items` 是最重要的一条。** 你想知道自己装的东西有什么，先跑这个。

### 7. Addon：Nova 的内容主要来自这里

**Nova 本体是框架，好东西都在 addon 里。**

| Addon | 提供什么 |
|-------|---------|
| **Machines** | 全部机器：挖矿机、粉碎机、发电机等 |
| **Jetpacks** | 喷气背包（有多个档位，能悬停） |
| 以及其他第三方 addon | NPC、任务、biome、方块等 |

`/nova addons` 看当前装了哪些。

> 🔥 **Machines 是 Nova 的官方 addon，依赖 Nova。** 单独装 Machines 没用——必须先装 Nova。详见 [Machines](#/plugin/machines)。

### 8. 版本要求咬得紧

| 项 | 要求 |
|---|---|
| MC | **1.19.3 或更高** |
| 服务端 | Paper / Spigot / Purpur |
| Java | 以 MC 版本为准（1.20.5+ 需 Java 21） |

Nova 用到了不少新版 API，**低于 1.19.3 直接跑不了**。

> ⚠️ **addon 和 Nova 必须版本匹配。** 一个为 Nova 0.11 写的 addon 装到 Nova 0.14 上，可能加载失败或者行为异常。装 addon 前看它声明的 Nova 版本范围。

### 9. 常见坑

**全是紫黑块（未找到物品纹理）**

资源包没配好或玩家没下载。查：

1. 资源包地址玩家能不能访问
2. 玩家是否拒绝了资源包（有些服默认不弹提示）
3. `/nova debug` 看有没有报错

**玩家说看不到新物品**

**他没更新资源包。** 改了资源包内容必须重新上传，玩家要重新下载才会生效。

**addon 装了不生效**

顺序问题：**Nova 先装 → 重启 → 装 addon → 再重启。** addon 加载时需要 Nova 已经就绪。

**改了配置要重启**

Nova 的配置改动**大部分需要完整重启**，不是 `/nova reload` 就够。特别是涉及物品 ID 的改动——**物品 ID 改了会导致已有物品变成紫黑块**，因为玩家存档里存的是旧 ID。

**机器不工作**

按顺序查：能量供应了吗？线缆连了吗？GUI 里输入槽有材料吗？（石头生成器要水+岩浆）

**和 WorldGuard / FAWE 冲突**

Nova 会放置自定义方块和机器。保护插件的区域规则可能挡住，或者反过来 Nova 的机器被破坏。测试时两个都配。

### 10. 缺点和取舍

| 缺点 | 说明 |
|------|------|
| **吃资源** | 大量自定义方块 + TileEntity + 机器本身就是性能负担 |
| **必须依赖资源包** | 玩家不下载就全废，比纯服务端插件更容易「看起来坏了」 |
| **版本要求高** | 1.19.3 起步，跨版本要跟着更新 |
| **addon 质量参差** | 第三方 addon 的维护和兼容性你控制不了 |
| **物品 ID 是硬约束** | 改 ID 会毁掉玩家已有物品，改配置要非常小心 |
| **学习曲线陡** | 配置项多，机器体系要理解能量/线缆/产能 |
| **和同类框架冲突** | 装了其他自定义物品框架（ItemsAdder 之类）大概率打架 |

### 11. 关于汉化

**Nova 的汉化完整度非常高**——共 **118 个语言文件**，简体（`zh_cn.json`）和繁体（`zh_tw.json`）都在，翻译覆盖率很高。

机制是 JSON 格式，和 yml 完全不同。详见 [汉化机制](#/plugin/nova/lang.md)。
