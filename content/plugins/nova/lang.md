# Nova 汉化机制

> Nova 是本站收录的插件里**汉化最完整的一个**之一：118 个语言文件，简繁中文都在。
> 这一页说明它的机制，以及改文案时要注意什么。

## 一、结论：自带简繁中文，开箱即用

Nova 的语言文件是 **JSON 格式**（`.json`），不是 yml、不是 properties。

简体中文和繁体中文的文件名：

```
zh_cn.json      ← 简体中文
zh_tw.json      ← 繁体中文
```

**注意这里的语言码写法和小写形式** —— 是 `zh_cn` / `zh_tw`，全小写、下划线分隔。和其他插件常见的 `zh_CN`（大写地区码）**写法不同**。找文件时别只搜 `zh-CN`。

## 二、118 个语言文件意味着什么

这个数字值得单独说：

- **不是几个核心文件，是全量覆盖** —— 物品名、GUI 标题、机器提示、配方说明、错误消息、addon 文案都在里面
- **说明项目的本地化流程是常态化的** —— 不是「勉强翻一下就发出来」
- **对比**：大多数插件只有 2-10 个语言文件（只有英文 + 一两个）

实际效果：装好 Nova，简体中文玩家看到的**基本都是中文**。这是插件汉化做得最好的水平之一。

## 三、怎么切换

跟随玩家客户端语言自动切换，简体客户端自动用 `zh_cn.json`。

想强制统一语言，去 `plugins/Nova/` 下找语言/locale 相关的配置段。**具体配置键名请以你手上版本的配置文件注释为准** —— Nova 配置项较多且持续演进，本站不写死键名。

> **大多数服不需要改。** 默认行为（跟随客户端）对中文服是正确的。

## 四、文件结构

JSON 格式，层级和 yml 类似但语法不同：

```json
{
  "item": {
    "star_pickaxe": {
      "name": "星星镐"
    }
  },
  "gui": {
    "machine": {
      "title": "机器界面"
    }
  }
}
```

**要点：**

| 方面 | 说明 |
|------|------|
| 键名 | **英文**，是 Nova 的内部 ID，**不要改** |
| 值 | 可以改成中文 |
| 物品名改动 | 影响显示名，**不影响物品本身的 ID 和功能** |
| 格式 | 标准 JSON，逗号和引号必须正确 |

> ⚠️ **改 JSON 的时候小心语法。** 少一个逗号、多一个引号，整个文件加载失败，然后 Nova 表现成「没有语言文件」——所有玩家看到英文。这是最常见的事故。

改完**重启服务器**（或至少确认 `/nova reload` 生效）。

## 五、addon 的语言是独立的

这一点要分清：

| 内容 | 语言文件在哪 |
|------|-----------|
| **Nova 本体** | `plugins/Nova/` 下的语言目录 |
| **Machines 等官方 addon** | **addon 自己的目录** |
| **第三方 addon** | 各自的目录，看它们作者怎么实现 |

**每个 addon 是独立的框架实例**，有自己的语言文件。**不要指望改 Nova 本体的语言文件能影响 addon 的文案。**

好消息是官方 addon（Machines、Jetpacks 等）通常也跟本体一样有完整中文。

## 六、改文案 vs 改 ID：分清哪个能改

这是 Nova 特有的坑，比 JSON 语法更容易出事：

| 想改什么 | 改语言文件的后果 | 正确做法 |
|---------|----------------|---------|
| **物品显示名**「星星镐」→「神级镐」 | ✅ 安全，只影响显示 | 改语言文件的值 |
| **GUI 标题、提示文案** | ✅ 安全 | 改语言文件的值 |
| **物品内部 ID**（键名） | ❌ **玩家已有物品变紫黑块** | **不要改** |

**原因**：玩家存档里存的是物品 ID（键名），不是显示名。键名一改，旧物品就找不到对应数据了。

**想改名字，只改值，绝不动键。**

## 七、三个容易踩的坑

**改了没生效**

语言文件是启动时加载的。改完必须**完整重启服务器**，不能只靠 `/nova reload`。

**改完整个文件都不生效**

几乎一定是 **JSON 语法错了**。检查：

- 每行末尾的逗号（最后一项不能有逗号）
- 字符串的引号是否成对
- 有没有中文引号 `“”` 混进 JSON —— **JSON 只认英文直引号 `"`**

**用编辑器保存时选择了错误的编码**

存成 UTF-8。或者用记事本存成了 GBK，也会加载失败。

## 八、什么不会被汉化

语言文件只管 Nova 自己的界面文本。这些还是你自己写：

| 内容 | 在哪改 |
|------|--------|
| **物品的自定义名称** | 配置里直接写死 |
| **addon 的自定义文案** | addon 的配置 |
| **资源包里图片上的文字** | **改不了** —— 那是图片，不是文本 |

> 最后一条值得注意：如果资源包的贴图上画了文字（某些 addon 会这么做），那部分**语言文件管不到**，只能改图。

## 九、和 Skript 的机制对比

如果你同时用 Skript，这里有个直观差异：

| | Nova | Skript |
|---|--------|--------|
| 格式 | JSON | `.lang`（像 YAML 但不是 YAML） |
| 语言码 | `zh_cn.json`（小写下划线） | `simplifiedchinese.lang` |
| 语言数量 | **118 个** | 13 个 |
| 覆盖范围 | 界面文本 + addon 文案 | 界面文本 + 部分语法词条 |
| 改完生效 | 重启 | 重启或 `/skript reload all` |

详见 [Skript 汉化机制](#/plugin/skript/lang.md)。
