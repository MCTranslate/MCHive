# WorldEdit 自带中文，无需下载语言文件

WorldEdit 内置了完整的多语言系统，**简体中文随 jar 直接附带**，并且会**自动跟随每个玩家客户端的语言**显示：

- 玩家客户端语言是「简体中文」→ WorldEdit 的所有提示自动显示中文
- 玩家客户端是英文 → 自动显示英文，互不干扰

所以本页**不提供 lang.yml 下载**——你不需要往 `plugins/WorldEdit/` 里放任何语言文件，放了也不会被读取。

## 常见问题

- **游戏里还是英文？** 检查客户端「设置 → 语言」是否为简体中文，改完重进服务器即可
- **后台控制台一直是英文？** 正常现象。控制台没有客户端语言概念，WorldEdit 对控制台输出固定使用服务端默认语言（英文），不影响玩家
- **某些提示两种语言混着来？** 部分扩展功能（如 FAWE 新增的命令）的翻译进度和主插件不同步，属于上游翻译问题，不影响使用

## 游戏内提示词对照（注解速查）

汉化是自动的，但提示里的几个英文**术语**值得提前认识，看懂它们你才算会用 WorldEdit：

| 英文术语 | 中文含义 | 注解 |
|----------|----------|------|
| pos1 / pos2 | 第一/第二选点 | 用木斧左键、右键设置，两点确定长方体选区 |
| blocks affected | 受影响的方块数 | 每次操作完成后会显示这次改了多少方块，用于确认操作规模 |
| copied N blocks | 已复制 N 个方块 | //copy 的反馈，锚点是你复制时站的位置 |
| clipboard | 剪贴板 | 复制后建筑暂存在内存里的「剪贴板」中，//paste 粘贴的就是它 |
| schematic | 建筑文件 | 存盘的建筑（.schem 文件），放在 `plugins/WorldEdit/schematics/` 目录 |
| region | 选区 | 所有 // 命令默认作用于你框选的区域 |
| Max blocks changed | 已达变更上限 | 配置里设置了操作上限时的报错提示，见下方 Config 汉化页 |
| Unknown block / item | 无法识别的方块名 | 方块 ID 拼写错误，新版本请用 `minecraft:grass_block` 这类完整 ID |
| No region selected | 尚未选择区域 | 还没设置 pos1/pos2 就执行了需要选区的命令 |

## 想修改译文？

WorldEdit 的翻译托管在上游 EngineHub 的翻译平台，随版本更新自动改进。个人想改某句话的话需要自行编译带替换翻译的版本，投入产出比很低——对新手服来说，自带的简体中文已经完全够用。
