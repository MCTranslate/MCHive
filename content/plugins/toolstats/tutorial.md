## ToolStats 安装教程

### 1. 它解决什么问题

原版游戏里一件钻石镐在物品栏里长一个样。用了两年还是新的，用了十分钟看不出区别。**物品没有记忆。**

ToolStats 给每个工具/护甲挂上数据，显示在物品描述（Lore）里：

```
钻石镐
挖掘方块: 12,847
玩家击杀: 231
经验来源: 合成
```

**这里有一个设计上的关键点，也是它和 GearStats 这类插件的区别：**

> **数据存在物品本身（NBT），不是存在数据库里。**

这条决定了后面几乎所有的行为和取舍——先理解它，再看功能。

### 2. 两种统计模式

| 模式 | 说明 |
|------|------|
| **全部统计**（默认） | 所有工具都自动记录 |
| **Token 系统** | 玩家用某种「令牌/信物」给工具附上统计能力 |

**Token 系统的意义**：让统计变成一种**玩家主动选择**的行为，而不是所有装备都拖着几十行数字。你给一把传承之刃附上统计，普通木镐就干净。

**两种模式可以按需混用。**

### 3. 统计项一览

| 统计 | 适用的物品 | 触发条件 |
|------|-----------|---------|
| 挖掘方块 | 斧、锄、镐、剪、锹 | 挖方块 |
| 收获作物 | 锄 | 收割作物 |
| 发射箭矢 | 弓、弩 | 射箭 |
| 暴击次数 | 斧、锤、矛、剑、三叉戟 | 近战暴击 |
| 造成伤害 | 斧、弓、弩、锤、矛、剑、三叉戟 | 造成伤害 |
| 承受伤害 | 护甲、盾 | 受到或格挡伤害 |
| 击杀末影龙 | 武器类 | 击杀末影龙 |
| 击杀凋灵 | 武器类 | 击杀凋灵 |
| 钓到鱼 | 鱼竿 | 钓到鱼 |
| 鞘翅飞行时间 | 鞘翅 | 飞行 |
| 剥取原木 | 斧 | 剥树皮 |
| 击杀生物 | 武器类 | 击杀生物 |
| 击杀玩家 | 武器类 | 击杀玩家 |
| 剪羊毛 | 剪刀 | 剪羊毛 |
| 投掷三叉戟 | 三叉戟 | 投掷 |

**分类习惯**：伤害/击杀类只记在「武器」上，挖掘只记在「挖掘工具」上。**一把剑挖不了矿，所以它的统计里没有「挖掘方块」——这是正常的。**

### 4. 「来历」（Origin）追踪

这是 ToolStats 比较特别的一块——它不只记「做了什么」，还记「怎么来的」：

| 来源 | 说明 |
|------|------|
| **合成** | 玩家在合成栏里打造 |
| **获得** | 从末地船里找到鞘翅 |
| **掠夺** | 从箱子 / 木桶 / 试炼室金库里开出来 |
| **丢弃** | 从被击杀的生物身上掉落 |
| **交易** | 和村民交易获得 |
| **生成** | 创造模式生成 |
| **钓鱼** | 钓上来的 |

**为什么要记这个：**

- **防止刷物品破坏经济。** 你在商店里看到一把「击杀 5000 个玩家」的钻石剑，第一反应应该是怀疑它怎么来的
- **追溯「遗物」的合法性。** 有些服不允许刷击杀数出售物品，这个数据是判据

**它对刷取做了针对性处理**：它会正确标记从战利品箱开出来的装备（包括没打开就破坏箱子的情况），并和 ValhallaMMO 这类插件做了兼容。

### 5. 前置条件

| 要求 | 说明 |
|------|------|
| 服务端 | **Paper / Spigot / Purpur / Folia** |
| MC | 1.15+ |
| 硬依赖 | 无 |
| 可选 | **RoseStacker**（堆叠物品兼容）、PlaceholderAPI、OpenInv |

**注意它不支持 Bukkit/Spigot 吗？** 不，它列的是 Paper / Spigot / Purpur / Folia——**Spigot 在支持列表里**，但它是从 Paper 迁移过来的插件，**在纯 CraftBukkit 上不要指望**。

### 6. 安装

- Modrinth：搜 `toolstats`
- 文档：作者有 wiki，装之前建议先看一眼

丢进 `plugins/`，重启。生成 `plugins/ToolStats/`。

## 7. 两个必须知道的操作

| 操作 | 命令 | 说明 |
|------|------|------|
| 给物品加/改统计 | `/toolstats edit` | 修改手上物品的统计数据 |
| 清除物品的全部 ToolStats 数据 | `/toolstats purge` | **彻底移除，不是重置** |

> ⚠️ **`purge` 是不可逆的。** 它把物品上所有 ToolStats 数据彻底删掉，不是清零。误用之后那个物品就变成「从来没被统计过」的普通物品了。

## 8. 怎么配

主要配置在 `plugins/ToolStats/config.yml`。**具体可改的键名以你手上版本的配置注释为准**，这里只说方向：

| 想做的事 | 配置方向 |
|---------|---------|
| 关掉某些统计项 | 找到对应统计项的开关关掉 |
| 改 Lore 显示格式 | 改显示模板相关配置 |
| **按世界关闭** | 它有 world-limit 配置，可以在某些世界关掉 |
| 允许创造模式玩家获取带统计的物品 | 相关开关 |

**Lore 模板可以自定义** —— 你能控制每一行显示成什么样、用什么颜色、显示几行。这是决定玩家观感的地方，值得花时间调。

### 9. 常见坑

**物品变成紫黑块 / NBT 报错**

ToolStats 2.0 迁移进 Paper 插件模块时，**依赖从内嵌改成了 Paper 的加载器**。老版本物品的 NBT 结构可能和新版不兼容。出现这个问题要检查版本跨度。

**和物品堆叠插件冲突**

**RoseStacker 是它的兼容对象**，但别的堆叠插件不一定。堆叠插件会合并物品，而 ToolStats 的数据是每件物品独有的——合并逻辑不同就会出问题。

**玩家数据被复制 / 刷物品**

历史上有过复制漏洞（更新日志里多次提到修复复制问题，特别是与 RoseStacker 相关的）。**保持更新，别用老版本。**

**统计不准（比如砍树没记录）**

看物品类型对不对：剥原木需要斧，剪羊毛需要剪刀。用错工具不记录是设计行为。

**Villager 交易来的装备没有「交易」来源**

更新日志里修过「交易来的装备没有正确记录来源」的问题。如果你版本较老会遇到。

## 10. 缺点和取舍

| 缺点 | 说明 |
|------|------|
| **Lore 会让物品描述变长** | 全统计模式下物品描述能到十几行。**观感问题是它最大的争议** |
| **数据存在 NBT 里，堆叠插件是雷区** | 任何物品合并逻辑都可能出问题 |
| **经济服要额外考虑刷取** | 记录击杀数 = 把玩家的作弊记录写在物品上。处理不好会被用来刷钱 |
| **和同类插件冲突** | GearStats、MineStatues 等同类只能选一个 |
| **升级版本有 NBT 兼容风险** | 数据存在物品上，跨版本结构变化会影响旧物品 |
| **Paper 系专属倾向** | 从 Paper 迁移过来，纯 CraftBukkit 上别指望 |

**它的取舍很清楚：用物品描述变长的代价，换取「物品有记忆」这个体验。** 如果你的服氛围偏硬核生存，这个交换很值；如果你的服玩家喜欢干净的物品栏，那 Token 模式更适合。

## 11. 关于汉化

> ⚠️ **本站未核实到 ToolStats 的官方中文语言文件机制。**

ToolStats 的可见文本主要是 **Lore 模板**（物品描述）和命令反馈。想改：

1. 打开 `plugins/ToolStats/config.yml`，找 Lore / display 相关的段落
2. 模板里直接写中文
3. 命令和消息的文案搜配置文件里带 `message` 的条目

**具体键名以你手上版本的官方配置文件注释为准。** 别照抄网上找的「ToolStats 汉化 config」——这个插件配置结构随版本改过好几次。
