## Plugin Portal 安装教程

### 1. 它解决的是「运维那 5 分钟」

每次给服务器加插件，流程都一样：搜官网 → 找对版本 → 下载 → SSH/SCP 传上去 → 重启。

**问题不在于这流程本身，在于容易出错。** 传错文件、下错版本（拿了 fabric 版）、传完忘了重启——这类事每周都在发生。

Plugin Portal 把这个流程搬进游戏内：

```
/pp search ViaVersion      ← 搜
/pp install ViaVersion MODRINTH   ← 装（带平台自动匹配）
/pp list --outdated        ← 查哪些有新版
```

**装完重启服务器生效。** 不用碰 SSH。

### 2. ⚠️ 先看清楚：免费版和 Premium 的差别

这个插件是**同一个 jar 里包含免费和 Premium 两套命令**，靠 key 解锁 Premium。不是两个 jar。

| 能力 | 免费 | Premium |
|------|------|---------|
| 搜索（所有市场源） | ✅ | ✅ |
| 安装单个插件 | ✅ | ✅ |
| 更新单个插件 | ✅ | ✅ |
| 选择发布通道 / 精确指定版本 | ✅ | ✅ |
| 插件自更新（Plugin Portal 自己升级） | ✅ | ✅ |
| **批量市场更新** | ❌ | ✅ |
| **外部源**（GitHub Releases、GeyserMC 源） | ❌ | ✅ |
| **配置导入/导出** | ❌ | ✅ |
| **jar 扫描** | ❌ | ✅ |
| **临时网页编辑器** | ❌ | ✅ |

**免费版够单人服用了。** 批量更新和外部源是团队服、多服管理才需要的。

**Premium 通过 key 解锁：**

```
/pp key set <你的 key>
/pp info      ← 查当前权限状态
```

key 有效的话会直接刷新权限，不用重启。

> ⚠️ **别用 Premium 版的「网页编辑器」在生产服改配置。** 它是「临时」的网页编辑器——你改的东西，网页关掉就没了。这是个方便功能，不是配置管理工具。

### 3. 支持的市场源

| 市场 | 说明 |
|------|------|
| **Modrinth** | 最主要的源，Paper 系插件基本都有镜像 |
| **Hangar** | Paper 官方收录的新版插件源 |
| **SpigotMC** | 老牌资源站，覆盖很多 Modrinth 上没有的老插件 |
| **Polymart** | 含付费插件（**免费版不支持付费下载**） |

**认准作者**：这个项目是 **flytegg** 的 Plugin Portal（`flytegg/plugin-portal`）。搜索「plugin portal」会混进各种 Portal 相关的 Modrinth 页面，注意区分。

### 4. 前置条件与不支持的事

**硬性要求：**

| 要求 | 说明 |
|------|------|
| **Java 17+** | **Java 8 完全不支持**，这是硬门槛 |
| 正确的服务端与 MC 版本 | 平台匹配逻辑依赖这个 |

> ⚠️ **Java 版本是第一号坑。** 1.20 以下的 MC 需要 Java 17，1.20.5+ 需要 Java 21。**装之前先确认你服务器的 Java 版本**，别装完发现起不来。

**明确不支持的：**

- ❌ **数据包（datapack）管理** —— 只管插件 jar
- ❌ **代理服的插件**（Velocity / BungeeCord）—— 它管的是后端服务器
- ❌ **Polymart 付费下载**
- ❌ **Minecraft 数据包 / 资源包**

另外，**市场条目必须提供可下载的、兼容你服务端的 jar**。有些市场条目只放源码或只有其他平台的包——这类条目装不了，这不是 bug。

### 5. 命令速查

| 命令 | 说明 |
|------|------|
| `/pp search <关键词>` | 搜索市场 |
| `/pp install <插件> <市场>` | 安装（市场参数如 MODRINTH / HANGAR / SPIGOTMC / POLYMART） |
| `/pp list --outdated` | 列出有新版的已装插件 |
| `/pp info` | 查看自身状态与权限 |
| `/pp help <命令>` | 单个命令的详细帮助 |
| `/pp key set <key>` | 设置 Premium key |
| `/pp blacklist` | 解除版本排除（见下） |

> ⚠️ 完整命令表见仓库里的 `COMMANDS.md`。**本页只列核心命令**，以你版本的 `/pp help` 为准。

**版本选择机制**（这个设计挺好，值得知道）：

- Plugin Portal 会**按你的服务端软件和 MC 版本自动选 jar** —— 这正是它最有价值的地方，**不会给你装 fabric 版**
- 你可以指定**发布通道**（如 beta）或**精确版本**
- **指定了精确版本后，该插件会被排除在批量更新之外** —— 想恢复跟随更新，用 `/pp blacklist` 解除排除

### 6. 安装

1. 从 GitHub Releases 下载（`flytegg/plugin-portal`）
2. 丢进 `plugins/`
3. 启动

**建议第一次用之前先备份**。理由不是它会删你的东西——而是它**能改动你的 `plugins/` 目录**，这个权限本身就该谨慎对待。

**第一次用先做件小事**：`/pp info` 看看环境识别对不对（服务端软件、Java 版本、MC 版本）。识别错了，后面自动选版本也会错。

### 7. 值得注意的坑

**它给你的 `plugins/` 目录写权限**

这是这个工具的本质。它是设计来改你插件目录的——所以：

- **别把它装在权限已经收紧的机器上而自己不知道**
- 装它之前先确认你的服务器目录结构清楚
- 它自己也能被更新（自更新功能免费），确认这是你想要的

**自动选版本选错了**

平台识别基于服务端软件 + MC 版本。**如果你用的是 Paper fork（Purpur、Folia 等），识别可能不准。** 装之前用 `/pp info` 确认。

**装完不生效**

**这个插件的所有安装和更新都要重启服务器才生效** —— 这是硬规则，不是可以绕过的。「装完了怎么没反应」这类问题，九成是没重启。

**批量更新把不该更新的更了**

免费版没有批量更新，Premium 有。**用之前先看一眼 `--outdated` 的列表**，别盲点。

**SpigotMC 搜不到东西 / 装不了**

SpigotMC 上的条目经常**没有 jar 直接下载**（很多项目引导你去别处下），这类条目装不了。用 Modrinth 搜通常更顺利。

### 8. 什么时候值得装

**值：**

- 服主不想老开 SSH / 不想用 SFTP 传文件
- 服上有其他管理员，**在游戏里就能装插件**比教他们用命令行友好得多
- 需要快速给多个后端服同步插件

**不值：**

- **管理习惯已经是命令行/脚本化** —— 你原来的流程更快更可控
- **生产服严格管控** —— 能在游戏里往 `plugins/` 塞 jar，这个权限你未必想给
- 单人服且一周装不了一次插件 —— 为一个月一次的操作装一个持续在线的插件不划算

> **一个实际的判断**：如果你的服是**多人管理**（有其他管理员），Plugin Portal 的价值会明显上升——**它不只是省了 SSH，还省了「教人怎么传文件」**。如果是纯你自己管理，问自己一句：我一个月会装几次插件？答案是个位数的话，先别装。

### 9. 关于汉化

**本站未核实到该插件的官方中文语言文件机制。** 若要汉化需自行确认。

Plugin Portal 的界面文本比较简单（命令名、市场名都是英文专有名词，实际需要汉化的部分很少）。要改文案，建议：

1. 进 `plugins/PluginPortal/` 目录，看有没有语言文件
2. 在 `config.yml` 里搜 `lang`、`locale`、`message` 关键词
3. 仓库 `flytegg/plugin-portal` 里搜 `lang` / `i18n` 目录

**不要照抄其他版本的路径**——这个项目结构变动较频繁。
