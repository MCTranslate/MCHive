## ⚠️ 先看清楚：只支持 1.20

**TreeFella 最高只到 1.20.x。** 如果你的服是 1.21 或更高，这个插件直接排除。

这不是「还没更新」的问题——它从 2023 年之后就没有新版本了，作者基本没在维护。装之前想清楚：

| 你的 MC 版本 | 能用吗 |
|------------|--------|
| 1.20 / 1.20.x | ✅ |
| 1.21+ | ❌ **不要装** |
| 1.16 - 1.19 | ❌ 声明不支持，但你可以试（它代码很简单，大概率能跑） |

**如果你需要「连锁砍树 + 连锁挖矿」并且版本不受限**，建议看第 6 节。

## 1. 它做什么

**用法就一句话：站着不动，按住 Shift 挖一下。**

```
站到树旁边 → 按住 Shift → 挖一下 → 整棵树瞬间消失，方块全部掉落
```

矿石同理——挖一个矿石，整条矿脉全部掉落。

**就这么简单。** 没有命令、没有 GUI、没有配置文件要调。丢进去重启，用 `/` 键当修饰键砍树。

### 木材

| 要求 | 说明 |
|------|------|
| 需要**斧** | 徒手不行 |
| 支持范围 | 任何种类的木头、下界木板 |

### 矿石

| 要求 | 说明 |
|------|------|
| 需要**镐** | 徒手不行 |
| 支持范围 | **包括**深层石头变体（深板岩矿石）和下界矿石 |

### 耐久怎么算

- 工具按**破坏的方块数**正常扣耐久
- **如果工具会在这次连锁中途坏掉，它就停下，不继续破坏剩下的方块**

第二条是有意设计的——作者认为「工具坏了就停」比「手里握着空气继续挖」更真实。

## 2. 前置条件

| 要求 | 说明 |
|------|------|
| 服务端 | Paper（作者标注的主要目标） |
| MC | **1.20 / 1.20.x** |
| 硬依赖 | **无** |

**没有依赖是它的优点。** 对比一下：很多同类插件要 ProtocolLib 或 WorldEdit，它不要。

## 3. 安装

- GitHub：<https://github.com/HideTheMonkey/TreeFella>
- Hangar 上也有分发

1. 去 GitHub Releases 下载 1.20 对应的 jar
2. 丢进 `plugins/`
3. 重启

**没有配置文件。** 装完直接用。

## 4. 它和同类插件的区别

连锁采集插件不少，TreeFella 的定位是**极简**：

| | TreeFella | 同类连锁插件 |
|---|-----------|------------|
| 配置项 | **0 个** | 几十到几百个 |
| 触发方式 | 按住 Shift 挖 | 可配置（也常是 Shift） |
| 只砍树 / 只挖矿 / 两者都有 | **两者都有** | 各不同 |
| GUI / 菜单 | 无 | 很多有 |
| 权限 | 无 | 很多有 |
| 维护 | 基本停更 | 多数还在更 |

**它就是「一个够用的实现」，不是「一个可配置的平台」。**

## 5. 缺点和坑

必须说清楚，这插件的问题不少：

| 缺点 | 说明 |
|------|------|
| **只支持到 1.20** | **最大问题。** 1.21+ 直接排除 |
| **停更** | 上次更新是 2023 年，新版 MC 的问题不会有人修 |
| **没有权限控制** | 全服玩家都能连锁挖。**多人服务器不能这么开**——人手一棵树的效率会毁掉生存平衡 |
| **没有世界/区域限制** | 你划了领地保护，照样连锁挖走 |
| **没有耐久保护选项** | 工具必定消耗，只能靠工具本身的耐久 |
| **不处理玩家自建结构** | 玩家用自定义方块搭的架子可能被连锁判定 |
| **和领地保护可能冲突** | WorldGuard 之类插件拦住一部分方块时，连锁会中断或者只挖一半 |

### 关于和领地保护的关系

**这是最容易出纠纷的点。**

玩家在你的领地里砍树，连锁插件一次性破坏几十个方块。保护插件可能在过程中拦截，导致：

- 只掉一半的木头
- 或者触发一堆领地保护警报

**如果你的服有领地保护并且开启了连锁，务必测试一遍。** 反过来，不加限制的话玩家会拿它去偷别人家领地的树。

## 6. 什么情况下该用它

| 场景 | 适合吗 |
|------|--------|
| **1.20 单机 / 和朋友玩** | ✅ 完美契合，效率工具 |
| **1.20 小服（有领地保护）** | ⚠️ 要测冲突 |
| **1.20 公开生存服** | ❌ 没有权限和世界限制，玩家会拿它破坏平衡 |
| **1.21+ 任何服** | ❌ 不支持 |
| **想长期维护的服** | ❌ 停更插件 |

**如果你的服需要这个功能但版本不受限**，找那些还在维护的 Tree Feller 类插件（它们通常提供权限、世界限制、领地兼容），或者自己写一个——这插件代码量很小，改造起来不难。

## 7. 关于汉化

> ⚠️ **本站未核实到 TreeFella 的官方中文语言文件机制。**

实际情况是：**这个插件几乎没有玩家可见的文案。** 它不发消息、没有 GUI、没有命令输出。唯一的「文字」就是物品名和耐久。

**装上之后你找不到语言文件是正常的——因为它没有需要翻译的东西。**
