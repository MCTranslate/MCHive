# PlayerPoints 汉化机制

> 以下路径来自 `Rosewood-Development/PlayerPoints` 仓库实际文件树核实，不是猜测。

### 一、结论：有官方中文，改一行就能用

PlayerPoints 的语言文件是**平铺的单个 yml**，按 locale 命名：

```
locale/
├── en.yml
├── zh_CN.yml         ← 简体中文
├── zh_TW.yml         ← 繁体中文
└── ...
```

结构最简单的一种——一个语言一个文件，没有子目录、没有分模块。

### 二、怎么切换成中文

`plugins/PlayerPoints/config.yml`：

```yaml
locale: zh_CN
```

繁体：`zh_TW`。

### 三、⚠️ 这里是下划线，不是连字符

这是 PlayerPoints 最容易踩的坑，**和其他插件都不一样**：

| 插件 | 中文 locale 写法 |
|------|-----------------|
| **PlayerPoints** | `zh_CN`（下划线） |
| Quests | `zh-CN`（连字符） |
| BentoBox | `zh-CN`（连字符） |

写错的后果：**控制台不报错，游戏里默默变英文。** 你会以为配置没保存、以为文件坏了、以为是版本问题——其实是分隔符。

多服服尤其要注意：**每个后端的 locale 都要单独改**，别指望主控分发。

### 四、想自己补翻译

1. 进 `plugins/PlayerPoints/locale/zh_CN.yml`
2. 对照 `en.yml` 补
3. `/points reload`

优先补：

| 内容 | 缺失影响 |
|------|---------|
| 余额变动提示 | 玩家收了点券不知道是干嘛的 |
| 排行榜相关文本 | 排行榜界面英文 |
| 转账/支付提示 | 日常操作看不懂 |
| 错误信息 | 余额不足、执行失败等提示是英文 |

改完存 UTF-8。

### 五、几个容易踩的坑

**改了 locale 还是英文**

八成是分隔符。先检查是 `zh_CN` 还是 `zh-cn`——大小写和分隔符都得对。

**`/points reload` 后改的配置被还原了**

`reload` 会**把内存中的状态写回磁盘**。如果你是先重启前改文件、期间 reload 过，改动可能被覆盖。**改配置的正确姿势：停服 → 改文件 → 启动。**

**汉化后 `/points me` 顶部标题还是英文**

标题部分可能在代码里写死了，不全走语言文件。这种情况只能改 jar 内的 properties，不太建议——升级会被覆盖。

**跨服时语言不一致**

每个后端各改各的。语言和点券余额不一样是常态，别以为是数据库的问题。

### 六、别指望汉化能覆盖的部分

**语言文件只管 PlayerPoints 自己的输出。以下不会汉化：**

- **物品名 / lore** —— 如果你用点券买东西，物品名字面量得自己在商店插件里改
- **商店 GUI 的文字** —— BossShop / CMI 自己的语言文件
- **Vault 兼容层透出的货币名** —— 商店里显示的货币名称，部分商店插件取自 Vault 注册的名字
- **其他插件** —— 各管各的

想在商店里把「点券」两个字也翻对，得去商店插件的语言文件改，光汉化 PlayerPoints 没用。
