## AuthMeReReloaded 安装教程

### 1. ⚠️ 先搞清楚：这是 AuthMe 的 fork，不是原版

**这一节是本页最重要的部分。搞错了后面全白搭。**

`AuthMeReReloaded` **不是** `AuthMe` 的下载页，**也不是**「AuthMe 的中文版」。

它是一个**第三方 fork**——有人从 AuthMe Reloaded 的代码拉了个分支，自己改了，维护的也是这份分支。

| | **AuthMe Reloaded** | **AuthMeReReloaded** |
|---|---|---|
| 来源 | 上游原作者的仓库 | **第三方 fork** |
| 下载渠道 | 上游官方渠道 | **本页说的这个** |
| 版本号形态 | 常规语义化版本 | **`5.7.0-FORK`**（后缀一眼就能看出来） |
| 支持到哪 | 跟随上游 | **MC 1.21.3**（本 fork 的支持上限） |
| 维护者 | 上游作者 | **fork 维护者，不是上游团队** |

**看到版本号里的 `-FORK` 后缀，就该意识到这是别人维护的分支。**

### 2. 为什么会产生 fork

这个问题的答案直接决定了「能不能用」。

AuthMe 这个插件的处境很特殊：**它太老、太重要、上游更新太慢。**

```
时间线（大致）：
AuthMe 诞生于 2012 年前后 → 长期是离线服登录方案的事实标准
        ↓
Minecraft 每个大版本都改内部 API（尤其 1.13 物品系统、1.20+ 的大改）
        ↓
每次上游要重新适配，周期长
        ↓
服主要 MC 1.20+ 的登录插件 → 上游还没跟上 → 等不及
        ↓
有人 fork 自己修 → AuthMeReReloaded 这类分支出现
```

**fork 的动机通常不是「官方不行」，而是「官方节奏跟不上我的服」。** 这类分支的典型特征：

- 版本号带自己的后缀，和上游明确区分
- 更新日志和上游不同步
- 可能在某些方面领先上游，某些方面落后
- **上游后来修的 bug，fork 不一定有**

> ⚠️ 本站**未核实**这个 fork 相对上游的完整差异清单。**要判断能不能用、稳不稳，得自己去看它的仓库和更新日志**，本页不替它做承诺。

### 3. 什么时候该考虑 AuthMe 系

**先确认一件事：你的服是离线模式吗？**

```
online-mode=true（正版验证）
  → 玩家 UUID 由 Mojang 分配
  → 别人拿不走你的身份
  → 不需要 AuthMe

online-mode=false（离线模式）
  → 玩家 UUID 按名字生成
  → 别人只要用你的 ID 进服，就是你的身份
  → 需要 AuthMe
```

**这就是离线服必须有登录插件的原因。** 核心风险：

| 风险 | 后果 |
|------|------|
| 别人用你的 ID 进服 | 你的背包、等级、位置全成了别人的 |
| 别人故意不登录 | 挂着不玩，白吃服务器资源 |
| 别人登录后用别人的皮肤 | 混淆视听 |

> **Geyser / Floodgate（基岩版进 Java 服）会改变这个判断。** 基岩玩家没有正版账号，走的是 Floodgate 那套流程，**不受 AuthMe 的登录界面管**。装了 Geyser 的服要单独看 AuthMe 和 Floodgate 怎么配合。

### 4. 装之前必须做的决定

**这一步比装插件本身重要。**

登录插件的取舍是**不可逆的玩家体验**：

| 决定 | 说明 |
|------|------|
| **要不要装** | 装了就回不去了。玩家会觉得"多了一步" |
| **注册上限** | 同一 IP 能注册几个账号。不限制 = 小号泛滥 |
| **超时踢出** | 不在时限内登录就踢 |
| **输了密码怎么办** | 服主有管理手段（这是必须有的，不是可选项） |
| **和其他插件冲突** | 有些插件要求玩家已登录才能用（传送、经济、领地） |

**诚实的话：登录插件是玩家体验的敌人。** 它给每个玩家增加了一次摩擦。**但离线服不加它，等于把存档拱手让人。** 没有两全的方案，只有选一个代价。

### 5. 安装

1. **认准仓库**——见第 8 节「同名混淆」
2. 下载对应你服务端 MC 版本的 jar，放进 `plugins/`
3. 重启服务器
4. 生成 `plugins/AuthMe/` 目录（含配置和数据库文件）

### 6. 常用命令

| 命令 | 说明 |
|------|------|
| `/login <密码>` | 登录 |
| `/register <密码> <确认密码>` | 注册 |
| `/changepassword <旧密码> <新密码>` | 改密码 |
| `/logout` | 登出 |
| `/email <新邮箱> <确认邮箱>` | 改邮箱（用于找回） |
| `/captcha` | 取验证码 |

**管理端**（权限控制，具体节点名以 `plugin.yml` 为准）：查看登录状态、强制改密、踢出未登录玩家。

> ⚠️ 命令列表**以你版本的 `/authme help` 输出为准**。这个插件的命令在不同 fork 和版本之间有差异（fork 加自己的命令很常见），**本页列的是 AuthMe 系的通用命令，不是你手上那份的完整清单**。

### 7. 配置要点

配置在 `plugins/AuthMe/` 下。**具体键名以你手上版本的配置文件注释为准。**

逻辑上涉及这几类——**这一类的键名在 AuthMe 系里相对稳定，但请以实际文件为准**：

| 类别 | 管什么 | 建议 |
|------|-------|------|
| 注册 | 是否有数量上限、是否强制邮箱 | 邮箱找回是重要的兜底 |
| 超时 | 登录时限、是否踢出 | 别设太短，输错密码重来的玩家会被误伤 |
| 限制 | 同一 IP 限制、限制的国家/语言 | 同一 IP 限制能挡掉一部分批量注册 |
| 传送 | 登录前传送到哪 | 通常是专门的登录大厅世界 |
| 消息 | 提示文本 | 在语言文件里，见下节 |
| 禁止的插件命令 | 未登录时禁止用哪些命令 | 传送、经济、领地相关的都要禁 |

**「登录前禁止的命令」这一项要配全。** 漏了哪个，就等于给未登录的玩家开了个口子——比如漏了经济插件的 `/pay`，别人能在登录前转账。

### 8. 同名混淆（重要）

**AuthMe 这个名字在搜索结果里非常混乱。** 至少要分清：

| 名字 | 是什么 |
|------|-------|
| **AuthMe Reloaded** | 上游原版（原作者维护） |
| **AuthMeReReloaded** | **本页写的这个**，第三方 fork，`5.7.0-FORK` |
| AuthMe（无后缀的其他条目） | 各种二次打包/魔改版，来源不明 |

**本页说的 `AuthMeReReloaded` 版本是 `5.7.0-FORK`，支持 MC 1.8 - 1.21.3。**

**MC 支持上限 1.21.3 是一个硬信息**：如果你的服在 1.21.4 或更高，这个 fork 的支持区间就不覆盖了。**这不是「可能能用」，是官方声明的区间之外。**

### 9. 常见坑

**服主自己忘了密码，没人能进服了**
**这是登录插件最经典的事故。** 上线前确认：
- 控制台有强制改密 / 解锁的手段（AuthMe 系都有，具体命令以你版本为准）
- 你**现在就试一遍**控制台命令，别等出事才第一次用
- 服内另有一个 OP 账号能进

**「服务器后台」在线**
装了强制登录后，如果设置逻辑有问题，会出现「玩家已登录但连接没断」的状态。表现为后台挂着幽灵会话。**这是 bug，不是正常状态。**

**装完之后某些插件报错**
有些插件要求玩家已完成登录。表现是「登录后才能用 /xxx」。**这通常要在 AuthMe 里把该插件的未登录拦截加上，或在别的插件里改白名单。**

**和 Geyser / Floodgate 冲突**
基岩玩家走的是另一条认证路径。**装了 Geyser 的服必须单独测试基岩玩家的登录流程**，别假设和 Java 玩家一样。

**注册小号泛滥**
不限同一 IP 注册数量 = 一个人注册一百个号。**注册限制是必需的，不是可选的。**

**玩家反复输错密码被踢**
超时设太短的直接后果。改长一点，或者配一个「输 N 次后锁一段时间」而不是直接踢。

**MC 1.21.4+ 装不了**
见第 8 节。**这个 fork 的声明支持上限是 1.21.3。** 需要更新的 MC 就得看别的方案。

### 10. 关于汉化

**本站未核实 AuthMeReReloaded 的官方中文语言文件机制。** 若要汉化需自行确认。

AuthMe 系的提示文本**通常有语言文件机制**（fork 一般会保留上游的机制），引导式排查：

1. 进 `plugins/AuthMe/`，找 `lang/` 或 `messages` 相关文件
2. 搜配置文件里有没有 `language`、`lang`、`locale` 段落
3. **注意**：AuthMe 系有些版本的登录提示是在配置文件里内嵌的，不一定在独立语言文件里——**翻配置文件全文**

想看全站各插件的汉化情况，见 [插件汉化与本地化完全指南](#/guide/plugin-localization)。

### 11. 什么时候别用它

- **正版服（online-mode=true）** —— UUID 由 Mojang 管，不需要。装了纯属给玩家添麻烦
- **只是 1-2 个朋友连机** —— 用正版账号就行
- **MC 1.21.4+ 的服** —— 这个 fork 的声明区间不覆盖
- **已经在用其他登录方案**（如代理端 AuthMeVelocity）—— **别重复装**
