## Simple Voice Chat 安装教程

### 1. 先接受一件事：这是半模组插件

**Simple Voice Chat 的服务端是插件，但玩家端必须自己装模组。**

这是它和其他插件最大的区别，也是最容易踩的坑：

| 组件 | 装在哪 | 谁装 |
|------|--------|------|
| **服务端插件**（Bukkit/Paper 版 jar） | 服务器 `plugins/` | 服主 |
| **客户端模组**（Fabric / Forge / NeoForge / Quilt） | 每个玩家的游戏本体 | **玩家自己** |

**没装模组的玩家听不到任何人说话，也说不出话。** 他们不会看到「需要装模组」的提示——对他们来说就是「这里没人能说话」。

这不是 bug，是设计。语音数据必须经过玩家客户端，不能像聊天那样纯服务端渲染。

> ⚠️ **当前版本 `2.0.0-beta.9` 是 beta 通道。** 测试阶段，配置不保证跨版本兼容，升级前备份配置目录。

### 2. 真实前置条件

这是本节最重要的部分。**装之前逐条对一遍：**

| 要求 | 说明 | 容易漏吗 |
|------|------|---------|
| **玩家端模组** | Fabric/Forge/NeoForge/Quilt 客户端都要装对应版本 | ✅ 最容易漏 |
| **UDP 端口放行** | 语音走 UDP，和游戏的 TCP 端口**完全是两回事** | ✅ 最容易漏 |
| **模组版本匹配** | 模组版本要和服务端插件版本对得上 | ✅ |
| **Java 版本够** | 新版模组通常要 Java 17+ | |

**玩家端的安装负担是真的。** 一个 200 人的社区，意味着你要让 200 个人自己装模组、匹配版本、解决冲突。这不是发个公告就完事的事。

> **现实建议**：如果你的服玩家里有相当比例是**手机/主机/基岩版玩家**，先想清楚——他们装不了 Java 模组，这个插件对他们等于不存在。基岩玩家只能靠 Geyser，而 Geyser 不支持语音。

### 3. 服务端安装

1. 下载对应平台的 jar（`bukkit` / `paper` / `spigot` / `folia` / `velocity`）
2. 丢进 `plugins/`
3. 启动生成配置
4. **停服** —— 编辑配置
5. 再启动

**第 4 步不做，插件会用默认端口。** 默认端口是 UDP 24454，如果这个端口在你的网络环境里被占（比如某些加速器、部分云厂商的端口段），语音会连不上。

配置目录是 `plugins/voicesimplechat/`，主配置文件是 `config.toml`。**具体配置键名请以你手上版本生成的 `config.toml` 注释为准**——本页不列键名，beta 通道的键名会变。

你需要确认的核心是这几项（**按实际配置文件里的键名填**）：

| 要确认什么 | 说明 |
|------------|------|
| **UDP 端口** | 服务端监听端口，玩家端会自动跟随 |
| **语音距离** | 决定多远能听见，小服设太大反而吵 |
| **是否允许玩家关闭** | 有人对语音敏感时能退出 |

### 4. 玩家端怎么装

**这一步是给玩家的说明，你可以直接转发到公告。**

1. 根据自己的**模组加载器**（Fabric / Forge / NeoForge / Quilt）下载对应模组
2. 放进游戏本体目录的 `mods/` 文件夹
3. **确认服务端插件和模组版本是配套的**
4. 进服务器时会自动连上服务端配置的地址和端口

> **不需要**玩家手动填 IP 和端口——服务端会通过游戏本身的连接通道下发配置。这是它比某些老语音方案省事的地方。

**玩家端的常见问题：**

| 现象 | 原因 |
|------|------|
| 进服后听不到声音 | 模组没装 / 版本不匹配 / UDP 端口被挡 |
| 能说话但别人听不到 | 麦克风权限没给，或被其他程序占用 |
| 完全没反应 | UDP 端口问题（见下） |

**麦克风权限**：Windows 端第一次运行会弹权限请求，Mac/Linux 可能在系统设置里。玩家自己就能解决，但要提醒一句。

### 5. UDP 端口问题（最常见的技术故障）

**这个插件 90% 的「装完不能用」都是 UDP 端口问题。**

| 环节 | 要做什么 |
|------|----------|
| 服务器防火墙 | 放行 UDP 端口 |
| 云服务器安全组 | 放行 UDP 端口（**和 TCP 端口是两条独立规则**） |
| 家用路由器 | 做 UDP 端口映射（家用宽带的 UDP 转发经常是坏的） |
| 走代理的话 | **代理必须支持 UDP 转发** |

**最典型的坑**：你在云服务器上放行了 UDP，Java 版玩家都进来了，但自己在家连不上——问题在**你家路由器的 UDP 转发**。换个网络（比如手机热点）能连上，就确诊了。

> **走 Velocity / BungeeCord 的话，这一条要特别确认**：代理层要转发 UDP 才能用，只有 TCP 转发是不行的。装之前先查你的代理是否支持，不支持就别装——装了也是坏的。

### 6. 什么时候值得装

**值：**

- 玩家之间想有「自然感」的交流——**语音的社交密度和文字完全不是一个量级**
- 小型社区（20-100 人），大家都愿意装模组
- 长期稳定运营、有社区氛围的服

**不值：**

- **纯生存/建筑服** —— 玩家各玩各的，用不着语音
- **玩家流动性高** —— 新人不断进来，每个都要教一次装模组
- **大量基岩/手机玩家** —— 他们装不了，等于对这部分人无效
- **没有防骚扰机制的服** —— 语音没法靠日志追溯，举报了也没有记录可查

### 7. 必须提前想清楚的事：语音没法管

**这是语音相比文字最大的短板，也是服主最容易忽略的。**

聊天有日志、可以撤回、可以禁言、可以敏感词过滤。语音这些一样都没有：

- **没有文字记录** —— 玩家被骂了，事后无据可查
- **没法静音单个玩家** —— 只能全局关语音
- **没法过滤** —— 敏感词、辱骂全都放行
- **没法回放** —— 举报无门

**所以：**

- 装之前想清楚你的社区氛围够不够open（能不能接受无约束的语音）
- 需要举报机制的话，**得靠玩家录屏**——这在隐私上是有争议的
- 建议在规则里明确写上语音的行为规范，别等出事再补
- 有骚扰风险的话，考虑**允许玩家自行关闭语音**（配置里有相关选项，键名以你的 `config.toml` 为准）

### 8. 性能开销

语音本身流量很小，**真正的开销在数据处理和并发上**：

- 服务器要做音频编解码（插件自己实现，不依赖额外库）
- 玩家越多，CPU 占用越明显
- 多人同时说话时会叠加

**实际影响不大。** 除非你的服已经有明显的性能问题，否则这不是需要担心的点——比 Geyser 的开销小得多。

### 9. 常见坑速查

| 现象 | 大概率原因 |
|------|-----------|
| 玩家听不到任何人 | 玩家没装模组 / 模组版本不匹配 |
| 服务端日志报端口占用 | UDP 端口被占，换端口 |
| 家里连不上，热点能连 | 家里路由器的 UDP 转发坏了 |
| 装了代理后失效 | 代理不支持 UDP 转发 |
| 玩家说没声音 | 麦克风权限 / 被占用 |
| 能连上但延迟高 | 跨洲网络 + UDP 被限速，或走了代理 TCP 兜底 |
| 升级后配置变了 | beta 通道无兼容承诺，重装前备份 `plugins/voicesimplechat/` |

### 10. 关于汉化

**客户端模组自带简体中文和繁体中文**，语言文件在模组资源目录的 `assets/voicechat/lang/` 下，包含 `zh_cn.json` 和 `zh_tw.json`（共 20 多个语言）。这部分跟随玩家客户端语言自动切换。

**但服务端插件侧的情况不同：我们在服务端插件的代码路径下没有核实到独立的中文语言文件机制。** 也就是说：

- **模组界面**：已汉化
- **服务端发出的提示/配置相关文本**：**本站未核实到官方中文语言文件机制，若要汉化需自行确认**

要改服务端侧文案，建议在 `plugins/voicesimplechat/config.toml` 里搜 `message`、`locale`、`lang` 这类关键词，看你这个版本提供了什么。**不要照抄旧教程的键名**——beta 通道的键名会变。
