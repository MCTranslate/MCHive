# ViaBackwards 汉化机制

> 结论来自 `ViaVersion/ViaBackwards` 官方仓库的实际文件树核实。

## 一、结论：没有语言文件，也基本不需要

ViaBackwards 官方仓库里**语言文件数量为 0**——没有 `lang/`、没有 `locale/`、没有 `locales/`，任何语言都没有。

但**这一条和「插件该汉化却没汉化」不是一回事**。

## 二、为什么它不需要语言文件

ViaBackwards 是一个**协议翻译层**，玩家在界面上看不到它的任何输出：

| 它做的事 | 玩家能看到吗 |
|---------|------------|
| 翻译登录握手包 | 看不到 |
| 转换区块数据格式 | 看不到 |
| 改写物品栏 / NBT 数据 | 看不到 |
| 处理老版本专有数据包 | 看不到 |

**它没有面向玩家的界面，也就没有需要翻译的文案。**

## 三、那些英文出现在哪

控制台启动时可能会看到类似输出：

```
[ViaBackwards] Registered 1.7.x protocol support
[ViaBackwards] Loading mappings for MC 1.8 -> MC 26.3
```

这些是**技术日志和加载信息**，读者是服主和开发者。翻译它们对玩家毫无意义——你需要做的是看懂它们。

## 四、玩家实际看到的提示来自哪

如果你在用 ViaBackwards 时看到了英文提示（比如「This server is running version X」这类），**那大概率来自另一个插件**，常见的是：

- **ViaVersion 本身**的提示
- 服务器 MOTD / 登录阶段的原版提示
- 其他跨版本相关插件

要汉化那些，请去对应插件的文档里查机制。

## 五、什么情况下你需要自己动手

有一种例外：**如果你想在老版本玩家登录时显示自定义提示**（比如「你正在用 1.8 客户端进入，部分功能不可用」），那需要：

1. 确认服务端端的提示配置在哪里（多数服务端端插件把这部分交给原版 `server.properties` 或其他插件）
2. 这属于**你的自定义内容**，不是汉化——直接写中文即可

**不要**尝试往 ViaBackwards 目录里塞语言文件，它不会读。
