## ⚠️ 第一件事：MC 1.21 版本门槛

**这个插件不支持 1.20.4 及以下。** 不是「可能能用」，是明确的区间：**1.21 起**。

**如果你的服还在 1.16 / 1.18 / 1.19 / 1.20.x，这个插件直接排除。** 装不上的。

这带来一个现实问题：1.20.4 及以下曾经是长期最稳的 Paper 版本选择，很多中小服至今还在跑。**想用这个插件，你得先把服务端升到 1.21 或更高。**

升级前要做的准备：

| 检查项 | 说明 |
|--------|------|
| 插件生态是否都支持新版本 | 一个插件不兼容，整个服就得停 |
| 数据包 / 资源包 | 自定义内容在新版本大概率要改 |
| 核心版本 | 跟上当前推荐的 Paper 维护分支 |
| 备份 | 全量备份 worlds + plugins + 配置 |

**升服本身是一个独立项目，不要和「想加个拍卖行」混在一起做。** 详见 [服务器版本迁移](#/guide/server-migration)。

## 它解决什么问题

服务器上的物品流转，目前主要是两种模式：

| 模式 | 代表 | 问题 |
|------|------|-------|
| 服主定价出售 | ChestShop、QuickShop 这类 | **价格必须由服主定**，玩家没法议价，供给不平衡时报错 |
| 玩家直接交易 | 原版村民交易 | 不成体系，物品流不进服务器经济统计 |

AuctionHousePlugin 走的是第三条路：**玩家自己定价。**

| 特征 | 说明 |
|------|------|
| 上架挂价 | 玩家把物品放进拍卖行，标个价 |
| 竞价 | 想买的人出更高的价 |
| 成交 | 价高者得，钱和物品自动交换 |
| 挂单时间 | 到期未售自动下架（具体机制看配置） |

**为什么这对服务器有意义：**

- **价格由供需自然形成**，服主不用维护一张价格表
- **稀有物品有了流通渠道**，不再烂在背包里
- **玩家的物品有了「投资」属性**，刷怪塔的产出有了去处

## 安装

> ⚠️ 本站**未核实到该插件的官方发布仓库地址**。在 Modrinth / SpigotMC / Hangar 上搜索时**注意分辨同名项目**——拍卖行类插件重名情况不少。认准 jar 内 `plugin.yml` 的作者字段。

流程：

1. jar 丢进 `plugins/`
2. 启动一次生成配置
3. 重启
4. **确认你的经济插件已经装好**（见下）

**拍卖行不是凭空的经济。** 它是物品和货币的交换场所，**货币从哪来？** 这取决于你的经济插件（Vault 提供接口，具体经济实现要另装）。

**没有经济插件，拍卖行就是一个没有价格的物品仓库。** 上架能上，成交不了。

> 经济系统的搭建顺序和 Vault 的作用，见 [经济系统搭建](#/guide/economy-setup)。

## 配置里真正要调的东西

**具体键名、文件位置以官方 config.yml 注释为准。** 本站不写配置键——这类插件的配置结构随版本变化。

能明确说的是**你需要决策的几件事**：

| 项 | 决策点 |
|---|---|
| 手续费 | 太高没人用，太低等于白送。玩家最反感的就是「成交一次被抽一大笔」 |
| 挂单有效期 | 太短来不及卖，太长物品长期锁死。**过期物品怎么退回是个必须确认的行为** |
| 起始价 / 最低加价 | 决定市场能不能活跃起来 |
| 上架上限 | 防止有人把整个市场的流动性吃掉 |
| 货币类型 | 玩家手里得有这种货币才用得上 |

**手续费这一项是玩家体验的关键。** 拍卖行的价值是「让玩家自己定价」，如果成交一次被抽走一大块，交易就没人做了。**建议从低手续费起步，观察成交量之后再调。**

## 常见坑

**装了但玩家用不了**
九成是**没有经济插件**，或者货币类型对不上。先确认玩家背包里到底有没有这个插件认的货币。

**成交后物品或钱不见了**
**这个问题必须立刻处理。** 检查数据库（如果它用数据库存储拍卖数据）和服务器自动保存的配合情况。物品在拍卖行里是**离线的**，服务器崩了或关服时保存失败可能导致丢失——**这是玩家经济系统最不能容忍的问题**。

**市场没人用**
拍卖行是**双边市场**，需要买卖双方都有需求。常见原因：
- 只有人上架没人买（供过于求）
- 货币不通（玩家没钱）
- 手续费太高
- 没有宣传（新功能没人知道）

**物品过期后去哪了**
玩家找不到自己的东西是这类插件最常见的投诉。**上线前先自己测一遍过期流程**，确认物品退回逻辑正常。

**和其他商店插件并存**
不冲突，但要小心**价格差**。如果你自己店铺卖得比拍卖行便宜，拍卖行就没人用。**两个系统的价格要一起看。**

**和任务/奖励系统冲突**
如果某个插件会把玩家的物品直接扣走（比如罚款、消耗任务物品），而物品在拍卖行里，扣不到就可能出问题。**这类交互要单独测。**

## 关于汉化

**本站未核实到该插件的官方中文语言文件机制。** 若要汉化需自行确认。

**这个插件的汉化优先级不低**——拍卖行界面是玩家高频使用的界面，菜单标题、按钮文字、成交提示这些如果全是英文，跨服体验会明显打折。

排查方式：

1. 启动一次服务器，看插件数据目录里生成了什么文件
2. 在生成的文件里搜 `lang`、`locale`、`message`、`translat`
3. 看有没有 `_zh_CN` 之类的中文变体结构
4. 如果有语言文件，打开看它管的是哪些文案

**另一种常见情况**：界面文字写在配置里（比如菜单标题、按钮显示名），**这种直接改配置就行，不算汉化**。先分清是「语言文件」还是「配置里的字符串」。

系统的汉化方案见 [插件汉化与本地化完全指南](#/guide/plugin-localization)。
