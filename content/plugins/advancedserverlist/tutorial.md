## AdvancedServerList 安装教程

### 1. 它改的是「玩家还没进来之前看到的那个界面」

服务器列表页里每个服务器条目有四个可改的部分：

```
┌────────────────────────────────┐
│  [图标]  我的服务器             │  ← Favicon（64×64 png）
│         欢迎来到我的服务器       │  ← MOTD（支持多行）
│         在线人数: 12 / 100       │  ← 人数文字
│         鼠标悬停显示更多         │  ← 悬停文本
└────────────────────────────────┘
```

原版这四项基本不可改。AdvancedServerList 把它们全开放了。

**真正的价值在于「档案 + 条件」机制**：你可以准备多份显示方案，插件按优先级挑一份符合条件的显示。**同一个服务器，不同状态显示不同内容。**

典型场景：

| 场景 | 想要的效果 |
|------|-----------|
| 平时 | 正常 MOTD + 真实人数 |
| 开维护时 | 换成维护公告，人数显示成 `???` |
| 玩家客户端版本太老 | 换一条「请升级客户端」的警告 MOTD |
| 节日 / 活动期 | 换活动主题 MOTD |

### 2. 核心机制：优先级 + 条件

一份**档案（Profile）就是一个 YAML 文件**，里面定义：

| 字段 | 作用 |
|------|------|
| 优先级 | 数字越大越优先 |
| 条件 | 可选，判断这条档要不要用 |
| MOTD | 列表文字 |
| 人数文字 | 显示多少人 |
| 人数悬停 | 鼠标悬停内容 |
| 隐藏人数 | 换成 `???` |
| 图标 | 服务器图标 |

**判定逻辑：从高优先级往下找，第一个条件通过的档案生效。不写条件 = 恒为真（永远通过）。**

> **这是最容易配错的地方**：高优先级档案一定要写条件，否则它会永久生效，把其他档案全盖掉。

多个档的条件都成立时，用优先级最高的那个。

### 3. 条件与占位符

条件里可以用占位符做判断——这才是它的价值所在：

```
# 伪代码示意，具体语法以官方 wiki 为准
当 维护模式 = true        → 用维护档案
当 玩家客户端版本 < 1.20  → 用版本警告档案
当 玩家 = 某VIP           → 用 VIP 档案
```

**占位符两种格式，别搞混：**

| 来源 | 格式 |
|------|------|
| 插件内置 | `${ }` |
| PlaceholderAPI（Paper 端） | `%_%` |

内置占位符能用在自己的占位符**体系内**。PAPI 的占位符在 Paper 端可用（需装 PAPI），**在显示条件里不能用**。

**关于新代理端占位符**：5.0.0 加了 `${proxy ...}` 系列，可以读某个后端服的 MOTD / 在线人数 / 人数上限。**注意它每 10 秒 ping 一次后端服，值需要等一轮才更新**，不是实时的。

### 4. ⚠️ 平台：必须装对版本

**这是最常见的失败原因。** 插件有多个构建，装错就完全不工作。

| 平台 | 说明 |
|------|------|
| Paper / Spigot | ⚠️ **需要 ProtocolLib**，缺了不工作 |
| BungeeCord / Waterfall | 代理端构建 |
| Velocity | 代理端构建 |

**群组服要在代理端装代理端 jar。** 用 Spigot 的 jar 丢进 Velocity 是没用的。

> ⚠️ **Paper 端缺 ProtocolLib = 插件完全不工作。** 这不是「部分功能失效」，是整个不工作。看到「装了没反应」先查这个。

### 5. 安装步骤

| 平台 | 步骤 |
|------|------|
| Paper / Spigot | 装 **ProtocolLib**（硬依赖）→ 装 Spigot 构建 → 重启 |
| BungeeCord / Waterfall | 装代理端构建 → 重启代理 |
| Velocity | 装代理端构建 → 重启代理 |

首次启动生成目录，大致包含主配置、`profiles/` 档案目录、图标目录。`profiles/` 里会有一个 `default.yml` 带注释示例——**从它开始改最省事**。

### 6. 常用命令

| 命令 | 说明 |
|------|------|
| `/asl help` | 帮助 |
| `/asl reload` | 重载配置和档案 |
| `/asl profiles` | 管理档案（列出 / 添加 / 移除） |
| `/asl clearcache` | 清玩家缓存 |
| `/asl migrate` | 从其他服务器列表插件迁移设置 |

> 迁移命令用来从 ServerListPlus、miniMOTD 这类插件搬配置。**迁之前备份。** 跨插件的键名结构不一定对得上，迁完要逐项核对。

`/asl reload` 让你调显示不用重启代理——**调 MOTD 的时候这是刚需**。

### 7. 玩家缓存

插件会存一个玩家信息缓存（IP、UUID、名字），用于给占位符提供值。

**这带来一个坑**：部分占位符依赖缓存数据。**关掉缓存的话，某些占位符会解析不出来。**

还有一个前置条件：Paper 端的 PAPI 占位符，**要求玩家在插件运行期间至少进过一次游戏**，否则没有数据。

**隐私角度**：这个文件记了 IP 和 UUID。要不要留着、给不给、留多久，自己判断。关掉缓存是选项，但要知道关掉之后占位符会缺值。

### 8. 格式化

文本用 **MiniMessage**，不是老的 `&` 颜色码。作者明确说明这是刻意选择——`&1` 是什么新手看不懂，`<red>` 自解释。**RGB 渐变、hex 颜色都能用。**

> ⚠️ **只有 MOTD 支持高级格式**（hex、渐变）。其他文本选项只支持 MiniMessage 常规部分，**别指望所有字段都能上渐变**。

### 9. 常见问题

| 现象 | 原因 |
|------|------|
| Paper 端装了完全没反应 | **先查 ProtocolLib**，缺它插件不工作 |
| Velocity 上没反应 | 装的是 Spigot 构建，换代理端构建 |
| 高优先级档案一直生效 | 它没写条件，**不写条件 = 恒真**，会永久盖掉后面的 |
| 代理端占位符数据不准 | `${proxy ...}` 每 10 秒 ping 一次后端，**等一轮** |
| PAPI 占位符不出来 | PAPI 装了没；**这个玩家在插件运行期间进过服没** |
| 梯度 / hex 只有部分生效 | 确认是 MOTD 字段，其他字段不支持 |

**占位符原样显示成 `${xxx}`**
未识别的占位符会原样输出或被当作无效。检查拼写，以及该占位符在当前平台是否可用。5.0.0 起 `${server ...}` 未识别时返回空字符串而不是 null——但**完全瞎写的占位符仍然返回 null**。

**能不能用 Geyser 的基岩版玩家**
**不能。** 作者在评论里明确说了不支持基岩版，也**将来也不会支持**。有基岩玩家的服要知道这个。

### 10. 什么时候别用它

- **只有一台服务器，没有群组** → 代理端构建用不上；单服改 MOTD 有更简单的办法
- **想改的是游戏内 MOTD（Tab 列表那个）** → **这不是这个插件。** 它改的是多人列表页，不是 Tab 列表
- **有基岩玩家且想统一显示** → 明确不支持

### 11. 关于汉化

**没有核实到官方中文语言文件机制。**

它的可配内容基本都是 MOTD / 人数文字 / 悬停 / 条件——**这些本来就是你自己写的内容，直接写中文就行**，不依赖语言文件。

引导式排查：

1. 解压 jar 看 `resources/` 下有无语言资源
2. 首次启动后看插件生成目录里有没有语言相关文件
3. **如果你的目标是汉化插件自身的提示信息**（比如 reload 成功、档案加载失败），那才需要找语言文件；如果目标是汉化**玩家看到的条目内容**，直接改档案里的文本

> 这一点和多数插件不同：**它的主要输出内容天然就是可编辑的文本**，汉化需求本来就不强。
