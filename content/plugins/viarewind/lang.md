# ViaRewind 汉化机制

> 结论来自 `ViaVersion/ViaRewind` 官方仓库的实际文件树核实。

## 一、结论：没有语言文件

官方仓库里**语言文件数量为 0**。没有 `lang/`、没有 `locale/`、任何语言都没有。

## 二、为什么不需要

和 [ViaBackwards](#/plugin/viabackwards) 同理——它是**协议翻译层**，不是玩家看得见的界面：

| 它做的事 | 玩家能看到吗 |
|---------|------------|
| 为 1.8 客户端翻译登录握手 | 看不到 |
| 转换老版本区块格式 | 看不到 |
| 处理 1.8 专有数据包 | 看不到 |

**没有界面 = 没有需要翻译的文案。**

## 三、控制台那些英文是什么

启动时可能看到：

```
[ViaRewind] Enabled 1.8.x support
[ViaRewind] Loaded protocol translation for MC 1.8.8
```

这些是**技术日志**，读者是服主。翻译它们没有意义，你需要做的是看懂它们。

## 四、玩家看到的提示来自哪

1.8 玩家在登录时看到的任何提示，都来自：

- 原版服务器的登录界面
- **ViaVersion / ViaBackwards**（不是 ViaRewind）
- 你自己配的 MOTD 或其他插件

要汉化那些，请查对应插件的文档。

## 五、想给 1.8 玩家自定义提示

如果你想在老版本玩家登录时显示中文提示（比如「你正在用 1.8 客户端，部分功能不可用」），那属于**你自己的内容**，直接写中文即可——写在你控制提示来源的地方（服务器配置或相关插件里），**不要**往 ViaRewind 目录塞语言文件，它不读这个。
