## ⚠️ 先读：它拆掉的不只是「凑人数」

大部分人装 SleepFixer 是为了「一个人也能睡过去，不要因为没人在线而 stuck 在白天」。**但这个插件实际拆掉的是两样东西：**

| 被拆掉的东西 | 原版作用 |
|-------------|---------|
| 睡觉的人数比例要求 | 一个人也能跳夜 |
| **「所有在线玩家都在睡」这个全局条件** | **防止有人趁夜偷袭 / 阻止守夜** |

**第二项是很多人没想到的，也是真正要警惕的地方。**

官方仓库：<https://github.com/ArcanePlugins/SleepFixer>

### 1. 原版睡觉机制到底在防什么

原版里，一个玩家睡觉**并不能让夜晚过去**。需要「足够比例的在线玩家都在睡」，才跳过夜晚。

**这套机制的实际用途不是防夜袭，而是「逼所有人同时进入夜晚状态」：**

```
3 个玩家在线，1 个睡
    → 不跳过夜晚
    → 因为 1/3 比例不够
    → 那 1 个人可以继续玩、继续挖矿、继续建设
```

**所以「必须凑够人」在实践中的作用是：你想睡，就得等其他人都睡。** 反过来说：

- 大家在野外的服务器 → 大家都得睡 → **夜晚是全服同步的、相对安全的时段**
- 有人在主城挂机 → 野外的服务器凑不够人 → **大家永远等不到天亮**

SleepFixer 就是来解决第二种情况的。**但它也一并去掉了第一种情况的保护。**

### 2. ⚠️ 风险：夜袭变简单了

**具体怎么变简单：**

```
原版：
  目标 A 想夜袭基地
  → 必须等全服其他人都睡了 → 时机极难找
  → 一旦有人没睡，A 就得等 / 或者暴露自己在夜里

SleepFixer：
  目标 A 想夜袭基地
  → A 自己睡 → 直接天亮？还是不用睡？
  → 关键：能不能「A 睡完，天亮了，但 B 的基地正好在夜里」？
```

**这取决于配置。但要警惕的组合是：单人可睡 + 睡觉不被打断/不通知他人。** 攻击者能精确控制「现在是不是夜晚」，这对防守方是不利的。

**还有一个更直接的盗刷角度：**

| 原版 | 装了之后 |
|------|---------|
| 挂机的人不睡 → 别人睡不着 | **一个人能睡 → 挂机机能反复跳夜** |
| 睡眠需要全服配合 | 睡眠变成一个**纯个人操作** |

如果你的服有「挂机/挂机 farming」或者「夜晚限定任务/掉落」，**跳夜变成无成本操作 = 刷资源**。

### 3. 什么时候真的需要它

| 场景 | 为什么需要 |
|------|-----------|
| **玩家独居 / 深夜服时段只剩几个人** | 不装的话永远等不到天亮 |
| **单人服务器**（朋友私服、养老服） | 原版单人也可能受人数条件限制 |
| **AFK  farming 型经济** | 需要跳夜机制 |
| **PvP 服的防守方** | 需要随时确认天亮状态 |

**特别说明第三种：** 有些服务器故意让玩家「以睡觉刷夜晚相关资源」为玩法，那单人可睡是**功能**不是漏洞。**这取决于你服的设计意图。**

### 4. 什么时候别装（这个更重要）

| 服类型 | 为什么别装 |
|--------|-----------|
| **以 PvP 为主的服** | **夜袭和守夜是核心博弈，拆掉睡觉机制就拆掉了这层** |
| **有「夜晚防守」玩法的服** | 白天和夜晚的紧张感是设计出来的 |
| **PvE 刷怪夜有难度设计的服** | 单人跳夜 = 跳过难度设计 |
| **挂机 farming 是漏洞而非玩法的服** | 这个插件会让漏洞变大 |

**「PvP 服」这一条要特别强调。** 你的服如果有「白天builders 晚上 raiders」这样的循环，或者玩家习惯白天建墙晚上守家，**单人来去自由地控制天亮天黑会破坏这个共识**。玩家会开始算：「我现在睡过去，趁天黑去拆家，然后自己再睡回来。」

**这就是它真正的代价：不是「PvP 变复杂」（那是 Headstones 的问题），而是「夜晚失去了作为同步节拍器的功能」。**

### 5. 安装

1. 从 <https://github.com/ArcanePlugins/SleepFixer> 或插件站下载
2. 丢进 `plugins/`
3. 启动，看控制台
4. **读配置，重点确认它到底改了什么行为**（见下节）

> ⚠️ 支持区间很宽：**MC 1.8 - 1.21.4**。老版本跨度说明它逻辑简单、依赖少。**但也说明它没跟上近年的新玩法**。

### 6. ⚠️ 配置上必须确认的事

不列具体键名（**以你版本配置文件内注释为准**），但这几条你必须自己读明白：

| 确认项 | 为什么关键 |
|--------|-----------|
| **单人睡是否直接跳过夜晚** | 这是核心行为，不同版本可能不同 |
| **是否需要全服在线** | 决定了它到底改了多少 |
| **睡觉是否广播/通知他人** | **不广播 = 别人不知道你跳了夜，可能引发纠纷** |
| **是否影响PvP 时的时区/战斗** | PvP 服要确认 |
| **是否有世界级开关** | 最好能只在特定世界生效 |

**第三条特别值得留意。** 如果睡觉跳夜不通知任何人，别的玩家会遇到「我明明在挖矿，天怎么突然黑了」这种困惑。PvP 服里这就成了被偷袭的合理借口，容易起纠纷。

### 7. 常见问题

**装了之后多人一起睡还跳不跳过夜晚**

按上面的配置项确认它是否把「人数条件」完全去掉了。有些版本只是让「单人也行」，多人行为不变。

**和别的夜晚相关插件冲突**

如果你的服装了其他改时间/夜晚的插件（改天气的、加速夜晚的），它们和 SleepFixer **会互相覆盖**。**只留一个。**

**玩家说白天被卡住 / 时间不动**

如果装了 SleepFixer 之后还是卡在白天，多半是**还有其他东西在管时间**，或者有玩家不在线导致条件不满足。**看控制台和其他插件。**

**和 CatastrophicNight / 天气类插件不兼容**

夜间刷怪强度被改的话，跳夜会同时跳过那个强度。PvE 服的「夜晚难度」会失效。

### 8. 关于汉化

**本站未核实到 SleepFixer 的官方中文语言文件机制。** 若要汉化需自行确认。

引导式排查方法：

1. 进 `plugins/SleepFixer/` 目录，**搜文件名**找 `lang`、`locale`、`messages`、`zh`
2. 打开配置，**搜关键词** `message`、`locale`、`lang`
3. **这类插件的文本极少** —— 它的核心功能是「让夜晚过去」，**这个过程本身没有玩家可见的消息**。所以很可能**根本没有需要汉化的文本**
4. 如果确实有消息，判断它是不是硬编码（比如「你无法睡觉」这类）：
   - 在配置里 → 改配置
   - 搜不到 → **可能在 jar 里**

**实话：这类小插件的汉化需求基本为零。** 花时间排查之前先想清楚它到底有没有给你显示中文的界面。

> 通用排查方法见 [插件汉化与本地化完全指南](#/guide/plugin-localization)。

### 9. 折中方案：如果你只想要「不卡白天」

**不一定需要插件。** 一些服务器的做法：

| 做法 | 效果 |
|------|------|
| 设置和维护窗口的作息时间表 | 固定时间踢/不踢，避免夜晚困局 |
| 装夜晚跳转/时间控制的插件，用定时器而非单人 | 白天黑夜**全服强制同步**，夜晚依然「大家都得睡」 |
| 在规则里明确「夜晚是开放时段」 | 把机制变化变成共识 |

**定时器方案是关键区别：** 它保留了「全服同步」这个节拍器（大家同时处在夜晚），但不让玩家被离线玩家卡住。**这比单人可睡更安全，因为它没有把夜晚变成个人开关。**

如果你的顾虑是「PvP 被削弱」而需求只是「不卡白天」，**定时器方案大概率更适合你。**
