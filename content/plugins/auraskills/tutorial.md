## AuraSkills 安装教程

### 1. 它在做什么

AuraSkills 把「原版行为」变成「RPG 技能」：

| 玩家做的事 | 涨的技能 | 涨满后解锁 |
|-----------|---------|-----------|
| 砍树 | 伐木 | 更高的效率加成 |
| 挖矿 | 挖矿 | 更好的掉落 |
| 钓鱼 | 钓鱼 | 更多战利品 |
| 杀怪 | 战斗 | 伤害/防御 |
| 挖土/耕种 | 农业 | 收获加成 |
| 挖沙/其他 | 对应技能 | …… |

**和 Jobs、Quests 的区别**：Jobs 是「任务清单」，Quests 是「剧情任务」，AuraSkills 是**技能熟练度**——你不需要接任务，**你在干什么就在练什么**。挖1000 次矿，挖矿技能就练到一定水平。

**它还有个前身**：Aurelium Skills，现在改名 AuraSkills。**如果你在旧教程里看到 Aurelium Skills，是同一个东西。**

### 2. 什么时候值得装

**值：**

- **长期生存服** —— 给老玩家一个持续变强的目标，防止「玩到后期没事干」
- **不想搞剧情任务的服** —— AuraSkills 不需要任务设计，玩家行为直接驱动成长
- **需要玩家在野外「顺便变强」** —— 采集本身就是训练，不需要专门安排

**不值：**

- **小服**（10 人以内）—— 大家互相认识，不需要个人成长曲线
- **纯建筑/创造为主的服** —— 没有采集行为，技能长不起来
- **已经有 Jobs 或同类插件且玩得好** —— 功能重叠，两个一起装容易让玩家困惑
- **已经在玩重度 RPG 服（大量其他 RPG 插件）** —— AuraSkills 偏轻量，混在一堆 RPG 插件里会显得单薄

> **一句话判断**：如果你的服的问题是「玩家到了后期不知道干什么」，AuraSkills 是个低成本答案。如果你的服已经有清晰的成长节奏，它可能是多余的。

### 3. 前置条件

| 要求 | 说明 |
|------|------|
| **服务端** | Paper 系（Spigot/Paper） |
| **MC 版本** | 1.14.4 起 |
| **Java** | 较新的版本要求，**装前确认你的 Java** |
| **数据库（可选）** | 单服用默认即可；要跨服或存大量数据才需要配数据库 |

> ⚠️ **AuraSkills 是那种「Java 版本不够就起不来」的插件。** 1.20 以下的 MC 需要 Java 17，1.20.5+ 需要 Java 21。**装之前先确认 Java 版本。**

### 4. 安装

1. 从官方渠道下载（**Archy-X/AuraSkills**）
2. 丢进 `plugins/`
3. 启动，生成 `plugins/AuraSkills/`

**命令**：主命令用来查看技能、排行榜等。**具体命令和权限节点请以你版本的 `plugin.yml` 和配置注释为准**——本页不列，因为跨版本差异大。

### 5. 数据库：什么时候需要动

**单服默认配置就够了。** 除非你有这些需求：

| 需求 | 为什么需要数据库 |
|------|----------------|
| **多服共享技能数据** | 玩家换服/切服后技能要保留 |
| **群组服（BungeeCord / Velocity）** | 每个后端服独立存会导致数据割裂 |
| **重装服务器要保留数据** | 手动迁移很麻烦 |

**如果你要配数据库**：AuraSkills 支持 MySQL，配置在配置文件的数据库相关段落。**具体键名请以你版本的配置文件注释为准**——AuraSkills 历史上换过数据库层的实现方式（从自研换到别的库），键名可能不一样。

> **建议**：单服先别配数据库。等真需要多服共享了再配，提前配反而多一个可能出错的环节。

### 6. 平衡：这是需要花时间的地方

AuraSkills 开箱能用，但**「能用」和「平衡」是两件事**。

**默认配置下，最容易出问题的两个地方：**

| 问题 | 表现 | 处理方向 |
|------|------|----------|
| **收益过高** | 技能满级后产出远超原版，**经济通胀** | 调低加成幅度 |
| **收益过低** | 玩家感觉不到差别，不愿意练 | 提高有感知的加成 |

**调平衡的思路：**

- **先小幅度改，观察一个周期**。一次调 10% 幅度你根本感觉不到
- **注意技能的「投入产出比」是否失衡**——比如战斗技能练级很快（杀怪快）但收益低，挖矿练级慢但收益高，**玩家会自然流向性价比高的那个**，如果那不是你想 incentivize 的
- **同步调经济系统**。技能加成直接改变产出，**商店价格和刷怪塔产出要一起看**

> **实话说，AuraSkills 的平衡工作量不小。** 它是「给你一套系统」，不是「给你一个平衡好的成品」。**开箱即用的爽感和可控的平衡是两件事。**

### 7. 已有其他 RPG 插件怎么办

**先想清楚要不要两个都装。**

| 情况 | 建议 |
|------|------|
| 已有 Jobs（任务向） | ⚠️ **可以共存**（不同定位），但要意识到玩家面对两套成长系统 |
| 已有别的技能插件 | ❌ **别装**，功能重叠，玩家会困惑练哪个 |
| 已有 MMORPG 插件（大量） | ⚠️ AuraSkills 偏轻量，**功能可能被覆盖**，先想清楚它的定位 |

> ⚠️ **技能类插件装多了是负收益。** 玩家会困惑「我到底该练哪个」，这是服主不想看到的。

### 8. 汉化：这一批里做得最好的

**AuraSkills 自带官方中文，且是完整的一等公民。**

我们核实了它的仓库（Archy-X/AuraSkills），语言文件在 `messages` 目录下，**共 21 个语言文件**，中文占两个：

```
messages_zh-CN.yml    ← 简体中文
messages_zh-TW.yml    ← 繁体中文
```

**这意味着什么：**

| 项目 | 情况 |
|------|------|
| 技能名称、描述 | ✅ 已汉化 |
| 界面菜单 | ✅ 已汉化 |
| 系统提示消息 | ✅ 已汉化 |
| **跟随玩家客户端语言** | ✅ 自动切换 |

**连繁体中文都做了。** 这在本批插件里是少数——大部分插件连简体都没有。

> **注意**：语言文件管的是**界面和系统提示**。**技能本身的名称和描述**（比如「伐木」这个技能叫什么、说明文字写什么）**可能是可配置的**，通常在技能配置文件里，改这个不走语言文件。

### 9. 关于汉化的额外说明

需要自定义文案时（**不要直接改 jar 里的文件，升级就没了**）：

1. 找到 `plugins/AuraSkills/` 下的语言文件目录（**以你版本的实际目录结构为准**）
2. 复制一份 `messages_zh-CN.yml` 进去改
3. 重启服务器

**想强制统一语言**（不管玩家客户端设的是什么）：配置文件里应该有语言/locale 相关的配置项，**具体键名以你的配置文件注释为准**。

**不要照抄其他版本的路径**——AuraSkills 的目录结构在改版时变过。
