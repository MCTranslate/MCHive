# AuraSkills 汉化机制

> 以下路径来自官方仓库 `Archy-X/AuraSkills` 的实际文件树核实。

## 一、结论：自带简繁中文，开箱即用

AuraSkills 的语言文件在仓库里共 **21 个**，中文占 2 个：

```
common/src/main/resources/messages/messages_zh-CN.yml← 简体中文
common/src/main/resources/messages/messages_zh-TW.yml    ← 繁体中文
```

命名是 `messages_` 前缀 + 语言码，**跟随玩家客户端语言自动切换**。

这批核实过的插件里，AuraSkills 的汉化是**最完整的**——21 个语言文件，简体繁体都有。

## 二、怎么切换

默认跟随客户端语言，简体客户端自动生效。

如果服务器里玩家客户端语言五花八门、想强制统一，在 `plugins/AuraSkills/config.yml` 里找locale 相关的配置项改成 `zh_CN`。**具体配置键名请以你手上版本的 `config.yml` 为准** —— AuraSkills 改版时配置结构变过。

## 三、能汉化的是什么

| 内容 | 是否汉化 |
|------|---------|
| 技能名称与描述 | ✅ |
| 界面菜单 | ✅ |
| 系统提示消息 | ✅ |
| 升级提示 | ✅ |

**注意区分两件事**：语言文件管的是**界面和系统提示**；而**每个技能本身的名称和说明**通常在独立的技能配置文件里，**改那个不走语言文件**。想改「伐木」这个技能叫什么、描述写什么，要去技能配置文件改。

## 四、想改文案

1. 进 `plugins/AuraSkills/`，找语言覆盖目录（AuraSkills 用 `messages` 目录承载，**具体结构以实际生成的目录为准**）
2. 复制一份 `messages_zh-CN.yml` 进去改
3. 重启服务器

**不要直接改 jar 里的文件** —— 升级就没了。

## 五、三个容易踩的坑

**改了没生效**

语言文件启动时加载。改完必须**完整重启**。

**简繁体选错了**

`zh-CN` 是简体，`zh-TW` 是繁体（注意这里是大写 `CN`/`TW`，和小写写法的插件不一样）。给大陆玩家用 `zh-CN`。

**改技能名改错地方**

想改技能本身的名称/描述，**改语言文件没用** —— 要改技能配置文件。这是最常见的「我改了但没变」。

## 六、什么不会被汉化

- **技能平衡相关的数值** —— 那是配置，不是文案
- **数据库里的历史数据** —— 玩家已有的技能数据不会因为换语言而变
- **第三方扩展的文案** —— 各写各的
