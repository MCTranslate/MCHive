## LevelledMobs 安装教程

### 1. 它在解决什么问题

原版 Minecraft 的怪物难度是**平的**——你出生点旁边的僵尸和世界底部的僵尸，血量一样、伤害一样。

这导致一个经典问题：**玩家的第一个夜晚是全服难度最低的地方，第二晚出了门难度还是那样。** 探索没有成本。

LevelledMobs 把难度做成了**梯度**：

```
出生点 ──────►世界边缘
  Lv.1        Lv.20
  普通僵尸     血厚 3 倍、伤害翻倍 的僵尸
```

结果：

- **出门变危险了** —— 这是探索该有的感觉
- **玩家有了「先在附近发展还是直接跑图」的选择** —— 战略深度上来了
- **地图有了地理** —— 某个方向危险，某个方向安全，是玩家的知识

### 2. 什么时候真的需要它

| 场景 | 建议 |
|------|------|
| **长期生存服** | ✅ 强推荐，梯度难度能显著延长服务器寿命 |
| **PVE 为主的 RPG服** | ✅ 强推荐，这本来就是它的设计场景 |
| **原版速通/生存挑战** | ❌ 会破坏设计意图 |
| **PvP 为主的服** | ⚠️ 收益不大（怪物强度对PvP 无意义） |
| **小服（5 人以内）** | ❌ 你们互相熟悉，梯度难度带来的紧张感会被熟人氛围冲掉 |

**它在服务器类 Mod 的原版服务端（Minecraft 系）上成熟可用，适配 Survival、Skyblock 等玩法。**

> ⚠️ **但它会增加难度曲线的不可控性。** 新玩家不知道哪儿危险，可能一出门就送命。**建议配一个「显示怪物等级」的可见提示**（LevelledMobs 有这个功能），让玩家能预判，而不是猝死。

### 3. 核心概念：等级怎么算

LevelledMobs 的等级主要由**距离**决定，但可以叠加别的维度。

理解它的配置逻辑，比逐个抄键名重要：

| 概念 | 作用 |
|------|------|
| **等级范围** | 最低等级到最高等级，以及**多少格距离升一级** |
| **倍数曲线** | 血量和伤害按等级怎么放大（线性？指数？封顶？） |
| **权重/排除表** | 哪些怪不受影响（Boss？刷怪笼的怪？宠物？），哪些怪放大得特别多 |
| **多世界设置** | 各个世界独立配置——**下界和主世界肯定不是一个难度体系** |

**关键点：等级不是无上限的。** 血量放大有封顶，否则远处的怪会变成一击秒杀你的血牛。**配置时倍率要克制。**

### 4. 安装

1. 从 Modrinth 下载（**ArcanePlugins/LevelledMobs**）
2. 丢进 `plugins/`
3. 启动，生成 `plugins/LevelledMobs/`

配置目录里有一个主配置文件和**每个世界独立的一份**。

> ⚠️ **具体配置键名请以你版本生成的配置文件注释为准**，本页不列键名。LevelledMobs 的配置项很多、命名随版本变过。**照抄旧教程的键名是本站最不建议的做法。**

**上手路径：**

1. 先进游戏找一只怪，看看它头顶显示的等级（开了显示功能的话）
2. 走出去几百格，再看一只，对比等级和血量
3. 打开配置文件，**先把倍率整体调低**再微调——先让它别太难，再往上加

### 5. 必须配的一个功能：显示等级

**强烈建议开「显示怪物等级」。**

理由很直接：加了难度梯度之后，玩家**需要能预判**。头顶标着「Lv.12」和完全看不出区别的怪物，是两种完全不同的游戏体验——前者是「我要不要打」，后者是「我被偷袭了」。

LevelledMobs 支持把等级显示在怪物头顶。**具体显示样式和权限请以你版本的配置为准。**

> **这是「难度设计」和「劝退设计」的分界线。** 同样一个Lv.20 的怪，有提示是挑战，没提示是陷阱。

### 6. 平衡：新玩家的保护

加了难度梯度之后，**新手保护是必须考虑的**。

LevelledMobs 本身提供了一些用于调节的手段（范围控制、权重），**但具体键名以你的配置注释为准**。你需要注意的方向：

| 问题 | 处理思路 |
|------|---------|
| 新玩家出门就死 | 缩小等级生效范围，或给新玩家/低等级玩家所在区域降级 |
| 传送来的玩家被秒杀 | 传送落点要设在安全区（出生点通常是低等级区） |
| Boss 被倍率放大后太离谱 | 权重表里把 Boss 排除或单独设上限 |
| 刷怪笼产出的怪被放大 | **这个必须处理**——刷怪笼是刷资源的地方，放大后玩家收益失衡 |

> ⚠️ **刷怪笼这条是最容易出问题的。** 原版刷怪笼是玩家重要的资源来源（刷怪笼刷出来的怪掉落经验/装备）。**如果被难度倍率影响，玩家产出节奏会被打乱**，经济系统可能崩。

### 7. 性能开销

**这个插件吃性能，而且吃法很直接：它要持续检查每个怪物的位置和状态。**

| 因素 | 影响 |
|------|------|
| **刷怪密度** | 刷怪塔/大规模农场会让它持续工作 |
| **加载的区块数** | 玩家探索得越远，它要管的怪越多 |
| **视距** | 玩家视距拉大，服务器管理范围内的怪变多 |

**如果你服上有大型刷怪塔/农场，注意TPS。** 经验上这类密集刷怪场景是它最容易暴露性能问题的地方。

> **建议**：装完在玩家密集的时段（比如晚上在线高峰）观察 TPS，别只在空服测完就放心。

### 8. 和其他插件的冲突

| 插件类型 | 关系 |
|---------|------|
| **其他难度/强度插件** | ⚠️ **会叠加**。MythicMobs 之类自带强度的插件 + LevelledMobs =双重放大，怪物血量会失控 |
| **刷怪相关插件** | ⚠️ 检查是否互相干扰（尤其是倍率生效时机） |
| **经济/掉落系统** | ⚠️ 等级越高掉落越多，**要同步调经济平衡** |

> ⚠️ **「双重放大」是最需要警惕的冲突。** 如果你已经在用其他给怪物加强度的插件，**不要再叠 LevelledMobs**，除非你非常清楚两者的叠加公式。

### 9. 常见坑

**玩家说「我什么都没做就被秒了」**

大概率是新玩家跑到了高等级区。**这说明保护机制没配好**，不是插件坏了。回去配新玩家保护/区域降级。

**怪物血量爆炸/不正常**

- 多个强度插件叠加了
- 等级/倍率配置过于激进
- 检查 Boss 或刷怪笼怪是否被特殊处理了

**TPS 掉了**

- 先确认是不是这个插件导致的（临时禁用对比）
- 查刷怪密度和玩家视距

**天空/虚空刷怪也被算等级**

某些设置下会按 Y 坐标或环境算等级。**具体计算方式以你版本的配置注释为准**，如果发现行为异常，去配置文件里找距离/区域相关项。

**装了没反应**

确认版本和你服的 MC 版本对得上（详见下方 version 页），以及配置是否改完重启了。

### 10. 什么时候别装

- **原版速通 / 生存挑战服** —— 破坏设计意图
- **玩家会大量使用固定刷怪塔/农场的服** —— 产出节奏被破坏，除非你专门配好了
- **已经在用其他强度插件** —— 会叠加失控
- **小服** —— 梯度难度的价值在人数多时才显现

### 11. 关于汉化

**本站未核实到该插件的官方中文语言文件机制。** 若要汉化需自行确认。

LevelledMobs 有消息配置文件，但**是否支持中文语言文件机制、以及中文文件名/格式，本站未核实到**。要汉化或改文案建议：

1. 进 `plugins/LevelledMobs/` 目录，看有没有 messages 或语言相关文件
2. 在配置文件里搜 `message`、`locale`、`lang`、`translate` 关键词
3. 官方仓库 `ArcanePlugins/LevelledMobs` 搜语言资源目录

**不要照抄其他版本的路径。**

> **提醒**：这个插件需要汉化的文本很少——主要就是显示在怪物头顶的等级标签（`Lv.X`这种），**这个通常在配置里直接是个可改的格式字符串**。想显示中文等级名，改配置比改语言文件更直接。
