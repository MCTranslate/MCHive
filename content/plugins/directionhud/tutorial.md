## DirectionHUD 安装教程

### 1. 它解决的那个具体问题

**联机服务器里最耗时的一件事：**

```
你：你在哪？
队友：在基地……那边？
你：哪个基地？
队友：就那个……
（四分钟过去了）
```

**方向指示 HUD 常驻在屏幕上，标出目标在你地图的哪个方位。** 不用打字问，不用算坐标，一眼看到「东南方偏北，大概 80 格」。

**它不是小功能，是把「靠语言定位」换成「靠界面定位」。** 联机生存、朋友基建的服，这个省下的时间很可观。

### 2. 它和「小地图」不是一回事

很多服已经有地图插件了，为什么还需要这个？

| 方案 | 打开成本 | 适合 |
|------|---------|------|
| 网页地图（squaremap / BlueMap） | **要开浏览器、切页面、找位置** | 找建筑、找地形 |
| 客户端小地图 mod | 要装 mod（玩家装不了就是装不了） | 全局视野 |
| **方向 HUD** | **不用打开，一直在那** | **快速确认队友方位** |

**核心区别是「打开成本」。** 网页地图要看队友在哪得开浏览器；方向 HUD 是**零成本的、实时的**。

**两者是互补的。** 找地形用地图，确认队友方向用 HUD。

### 3. ⚠️ 客户端前置：先确认这件事

**这类 HUD 插件大多数是客户端侧的。**

界面上的指示文字、图标、箭头，**要在玩家的客户端上画出来**——服务端只能发数据。

这意味着：

| 问题 | 后果 |
|------|------|
| 需要资源包 | 玩家不装/不接受 → **看不到 HUD** |
| 或者需要 mod | 玩家没装 mod → 看不到 |
| 或者只有 OP 能用 | 取决于实现方式 |

**⚠️ 本站未核实到 DirectionHUD 的具体客户端前置要求**（是否必需资源包、是否需要 mod、支持哪些平台）。**这是本页最需要你自己去官方页面确认的一件事。**

**这个前置如果不可行，插件就没有意义。** 原因很简单：**如果一半玩家看不到，对一半玩家来说这个插件等于不存在**，而且他们还会问「为什么我看不到」。

### 4. 版本要求

**支持 MC 1.18 - 1.21.7。**

- **1.18 是下限** —— 1.18 是第一个用了新世界高度和资源包重做的版本，**低于这个版本的 HUD 实现方式差别很大**
- **1.21.7 是上限** —— 你的服在 1.21.8+ 或 26.x 的话，**声明区间不覆盖**

**装之前先对一下你的 MC 版本。**

### 5. 它能指示什么

这类插件的常见功能范围（**具体支持哪些以你版本为准**）：

| 指示对象 | 说明 |
|---------|------|
| 特定玩家 | 常盯某几个人（好友、队友） |
| 队伍成员 | 和队伍系统联动 |
| 所有在线玩家 | 信息量很大，可能很吵 |
| 生物/实体 | 找掉落物、找动物 |
| 坐标点 | 标记的地标 |

**「能指哪些对象」直接决定它是有用还是烦人。** 全都指 = 屏幕上几十个标记 = 什么都看不清。**实际配置时通常要限定范围或只指几个人。**

### 6. 安装

```
1. 确认你的 MC 版本在 1.18 - 1.21.7 范围内
2. 去官方页面确认客户端前置要求（资源包？mod？）
3. 下载服务端 jar，放进 plugins/，重启
4. 生成 plugins/DirectionHUD/
5. 配置要指示的对象
6. 玩家接受资源包 / 装 mod（如果需要）
7. 找一个玩家实际测试能不能看到
```

**第 7 步不能省。** 必须**用另一个玩家的账号实际看一眼**，确认他能看见。**管理员能看见不代表玩家能看见**（权限、配置范围、客户端前置都可能造成差异）。

### 7. 常用命令与配置

| 项目 | 说明 |
|------|------|
| 主命令 | 通常用于开关自己的 HUD、设置指向目标 |
| 配置文件 | `plugins/DirectionHUD/` 下，**具体配置键名以你版本的配置文件注释为准** |

> ⚠️ **具体命令以你版本的帮助输出为准。** 本页不写命令名——这类插件命令差异大，写错了你敲了没反应。

**配置逻辑上涉及这几类**（键名以实际为准）：

| 类别 | 管什么 |
|------|-------|
| 指示对象 | 指谁（玩家 / 队伍 / 实体） |
| 范围 | 多远之内显示 |
| 格式 | 怎么显示（名字？距离？方向？） |
| 显示位置 | 屏幕哪个角落 |
| 客户端前置 | 资源包 URL、是否强制 |

**「范围」和「格式」是要动的两项。** 范围太大屏幕会糊，格式太简略（只写「西北」）又不如原版罗盘直观。

### 8. 常见坑

**玩家说完全看不到**
**这是最常见的问题，按可能性排序：**

1. **没接受资源包 / 没装 mod** —— 头号原因。**先查这个**
2. 权限不够
3. 配置里没有把他列为指示对象
4. 距离太远超出范围
5. 客户端和服务端版本不一致

**先排除第 1 条**，因为它是唯一一个「玩家自己做错了但不知道」的原因。

**MC 版本超范围**
1.21.8+ / 26.x 的服装不了。**声明上限 1.21.7。**

**屏幕太挤**
- 指示对象太多 → 限定范围或只指几个人
- 和其他 HUD 插件（血量、状态效果、地图小地图）**位置冲突**

**和其他 HUD / 界面插件冲突**
多个 HUD 插件会抢同一个屏幕区域。**表现为互相遮挡、或者位置被抢。** 同时只留一个 HUD 类插件。

**有信息泄露的隐患**
**这个值得单独说。** 方向 HUD 显示的是**客户端渲染的数据**，那服务端会发什么数据给客户端？

| 实现方式 | 泄露程度 |
|---------|---------|
| 服务端发所有玩家的位置，客户端自己筛选 | **所有玩家的位置都被下发到客户端了**（哪怕看不见） |
| 服务端按配置筛选后发 | 只发该发的 |

**如果你的服在意隐私（比如隐藏其他玩家基地位置），这个差别是实质性的。** **第一次用的时候抓个包或者看服务端行为确认一下。**

**玩家觉得「跟外挂一样」**
HUD 在 PvP 语境下容易被玩家当成「开挂才有的东西」，哪怕它真的只是界面。**在 PvP 明显的服上要谨慎。**

**和移动端 / 基岩端不兼容**
Geyser / Floodgate 进来的基岩玩家**不会有这个 HUD**。**别把它当成「所有人都能看到的信息」。**

### 9. 关于汉化

**本站未核实到 DirectionHUD 的官方中文语言文件机制。** 若要汉化需自行确认。

引导式排查方法：

1. 进 `plugins/DirectionHUD/`，看有没有语言文件目录
2. 搜配置文件里有没有 `language`、`locale`、`format`、`display` 段落
3. **HUD 的「界面」和「消息」是两条完全不同的路**：
   - **HUD 上的指示文字**（方向、距离、目标名字）—— 这很可能是**配置里的格式字符串**，改配置就能改，**但注意它可能不走语言文件**
   - **游戏内提示消息**（切换成功、没权限）—— 服务端发出，可能走语言文件
4. **格式字符串的汉化比语言文件更值得先试** —— 因为 HUD 显示什么通常由格式决定

**一个务实的说明：** HUD 里的方向指示（东南西北）如果用的是原版可翻译组件，会跟随客户端语言；如果是插件自定义的文本，就得自己改。**先确认是哪一种。**

想看全站各插件的汉化情况，见 [插件汉化与本地化完全指南](#/guide/plugin-localization)。

### 10. 什么时候别用它

- **MC 1.17 及以下** —— 不支持
- **MC 1.21.8+ / 26.x** —— 声明上限 1.21.7
- **玩家不接受任何资源包 / mod** —— **那就没必要装**
- **服务器人数很少、大家本来就在一起** —— 沟通成本本来就低
- **PvP 竞技服** —— 方向信息会影响对局
- **有 Geyser 且基岩玩家占比高** —— 基岩端看不到，割裂体验

### 11. 替代方案

**在做决定之前，值得先看看有没有别的解法：**

| 方案 | 优势 | 劣势 |
|------|------|------|
| **队伍系统** | 不需要额外客户端前置 | 要玩家手动报位置 |
| **简单的坐标显示命令** | 零前置 | 打字麻烦 |
| **网页地图 + 队伍标记** | 不用装任何东西 | 要开浏览器 |
| **方向 HUD** | **实时、零打开成本** | **需要客户端前置** |
| **一个好的聊天/队伍插件** | 解决问题从根本 | 不是可视化 |

**判断标准很简单：你的玩家愿意为了「少问一句你在哪」而接受装资源包吗？**

如果答案是「愿意」，装 HUD。**如果答案是「懒得搞」，那就用队伍系统 + 地图的组合** —— 少一个客户端前置，运维上省很多事。
