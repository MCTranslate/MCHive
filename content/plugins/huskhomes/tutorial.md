## HuskHomes 安装教程

### 1. 它解决什么问题

玩家的家、传送请求、随机传送——这些是「服务器的基础便利设施」。原版没有，所以每个服都要装。

HuskHomes 把这一整块包了：

| 功能 | 命令 |
|------|------|
| 设置家 | `/sethome` |
| 回家 | `/home` |
| 删除家 | `/delhome` |
| 传送请求（要对方同意） | `/tpa` |
| 接受传送请求 | `/tpaccept` |
| 拒绝 | `/tpdeny` |
| 随机传送 | `/rtp` |
| 公共家（所有人可用） | 支持 |
| 传送前的位置 | 支持 |

**玩家零学习成本**——这些命令 everyone 都会。这不是巧合，是刻意设计的：**传送是基础设施，不需要教。**

### 2. 它的真实差异点

同类插件不少，HuskHomes 的区别在这几个：

| 特点 | 说明 |
|------|------|
| **跨服支持** | 配 MySQL/MariaDB 后，玩家能**在你整个代理网络里**跨服传送和设家。玩家坐 BungeeCord/Velocity 换服不丢家 |
| **聊天式菜单** | 官方强调「不是笨重的箱子 GUI，而是聊天菜单」——列表直接显示在聊天框里 |
| **地图与计划插件联动** | 和 Plan（玩家分析）、BlueMap/Dynmap（地图）联动——**玩家的家能在地图上看到** |
| **能管别人的家** | 管理工具齐全 |
| **开源 + API** | 有公开 API，可以自己扩展 |

> **「家能在地图上看到」这个功能对社区服价值很高。** 玩家能直接在网页地图上看到彼此的家位置，社交感拉满。

### 3. 什么时候装

**基本必装。** 传送是基础设施，没人会觉得「我们服不需要家」。

**需要额外考量的场景：**

| 场景 | 考量 |
|------|------|
| **群组服** | 一定要配数据库，否则换服就丢家 |
| **不想让玩家随便传送** | 需要考虑权限范围和频率限制 |
| **已有 EssentialsX** | ⚠️ **见下面「和 EssentialsX 的关系」** |

### 4. 和 EssentialsX Homes 的关系

**这不是 fork，但存在功能重叠。** 如果你的服已经在用 EssentialsX：

| 选项 | 后果 |
|------|------|
| **两个都装** | ⚠️ **命令冲突**（`/home`、`/sethome` 都是 EssentialsX 的经典命令），玩家会困惑，某些命令归属不明 |
| **只用 EssentialsX Homes** | 少一堆功能，但省事 |
| **换成HuskHomes** | 拿跨服能力，但要确认 EssentialsX 其他部分不受影响 |

> **建议先查你的服有没有 EssentialsX。** EssentialsX 是最常见的「全家桶」插件，很多人不知道它已经带了 Homes。

**HuskHomes 和 EssentialsX 其他模块（经济、权限、聊天）不冲突**——它只和 Homes 模块重叠。**如果你用 EssentialsX 但已经禁用了 Homes，HuskHomes 是个合理的选择。**

### 5. 安装

1. 从官方渠道下载（**WiIIiam278/HuskHomes**）
2. 丢进 `plugins/`
4. 启动，生成 `plugins/HuskHomes/`

支持 **Spigot / Paper / Fabric**。配 MySQL 还能跨服。

**命令**以你版本的 `plugin.yml` 为准——核心命令见上面表格，但**具体权限节点和别名可能有差异**。

### 6. 群组服必读：配MySQL

**这是本文档最实用的部分。** 单服不用管这段。

多服（群组服）场景下**不配数据库的后果：**

- 玩家在 A 服设的家，**切到 B 服就没了**
- `/tpa` 跨不了服
- 玩家会觉得「我的家不见了」——**这是群组服最常见的体验投诉之一**

**配了之后：**

- 全网络共享家园数据
- 玩家从任意后端服都能回家
- `/tpa` 可以跨服工作（玩家在代理网络内切服）

**配置步骤（概念，具体键名以你版本的配置注释为准）：**

1. 准备 MySQL / MariaDB 数据库
2. 在配置文件的数据库段落填连接信息
3. 重启，确认日志里显示连上数据库

> ⚠️ **本站未核实到该插件数据库配置的具体键名**，请以你版本 `config.yml` 的注释为准。**不同版本的数据库实现换过**（历史上换过数据库层），旧教程的键名不可信。

### 7. 传送权限：这是要花心思设计的

传送功能给多了会出问题。**你想清楚这几件事：**

| 问题 | 决策点 |
|------|--------|
| **谁能用 /rtp** | 所有人？还是有探索进度/等级门槛？ |
| **能设几个家** | 数量限制（免费版能设几个） |
| **家是否需要付费** | 接经济系统 |
| **/tpa 冷却** | 防止被用来追人骚扰 |
| **能否传送到战斗中的玩家** | 这是PvP 服的作弊口子 |

> **「能否 teleport 到PvP 中的玩家」是个真实的安全问题。** 如果能，PvP 服基本没法玩了——被追杀时 `/tpa` 求援，对方直接被传送到你面前，或者反过来。**HuskHomes 侧的配置和你的 PvP 规则要一起看。**

**经验做法**：`/rtp` 给延迟或限制（防止瞬间满图跑图找宝），`/tpa` 设冷却，PvP 状态下禁用相关传送。

### 8. 汉化：自带简繁中文

**HuskHomes 自带官方中文。** 我们核实了它的仓库（WiIIiam278/HuskHomes），语言文件在 `locales/` 目录下，**共 17 个语言文件**，中文占两个：

```
locales/zh-cn.yml← 简体中文
locales/zh-tw.yml    ← 繁体中文
```

其他语言包括英语、德语、法语、西班牙语、葡萄牙语、俄语、日语、韩语、波兰语、土耳其语、乌克兰语、越南语、保加利亚语等。

**这意味着**技能选择、家列表的界面文本、系统提示消息都跟随玩家客户端语言自动切换，不用做任何事。

详见 [汉化机制](#/plugin/huskhomes) 页。

### 9. 常见坑

**玩家说家不见了（群组服）**

没配数据库，或者数据库没连上。**看服务器启动日志**确认数据库连接状态。

**命令和 EssentialsX 打架**

两个都装了 Homes。见上面「和 EssentialsX 的关系」。

**/home 传送没反应或报错**

- 权限不足（检查 LuckPerms）
- 那个家不存在（删除过？）
- 家在 unloaded 的世界里（先加载那个世界）

**菜单不显示**

菜单是聊天式的，**可能你没看到——它显示在聊天栏而不是 GUI**。这是设计如此，别以为是 bug。

**跨服 /tpa 不通**

代理层和数据库都要支持。**只配了数据库不够**，代理配置也要允许跨服传送。

**数据库连接失败**

检查数据库地址、账号密码、端口、**以及数据库是否允许从你的服务器 IP 连接**——很多云数据库默认有 IP 白名单。

### 10. 什么时候别装

- **已经在用 EssentialsX Homes 且没发现问题** —— 没必要换
- **封禁服的「传送」类插件**（某些极限服会禁掉家）—— 违背服规
- **单机 PVE 无社交服** —— 家和 /tpa 的价值都不大
