## FancyHolograms 安装教程

### 1. 它在做什么

**全息文字**（hologram）= 悬浮在空中的文字/物品/方块，不占方块、不需要存档实体。

典型用途：

| 用途 | 效果 |
|------|------|
| **公告** | 出生点上方飘着公告文字 |
| **排行榜** | 悬浮显示前几名和数据 |
| **菜单标题** | NPC/商店上方的标题文字 |
| **装饰** | 展示一个旋转的物品、悬浮的方块 |
| **路标** | 指路/地标/传送点标识 |

它用的是**展示实体（display entities）**机制——这是Minecraft 原版的显示实体类型，**服务端是真实实体**，和 FancyNpcs 的「纯数据包」路线不同。

> **这个区别有实际意义**：全息内容是**服务端真实存的**，所以它**跟着区块加载**（玩家走近才看到），**不依赖玩家的可见范围实时发送**。

### 2. 三种全息类型

| 类型 | 展示什么 | 典型场景 |
|------|---------|---------|
| **文字（Text）** | 一行或多行文字 | 公告、标题、排行榜 |
| **物品（Item）** | 悬浮/旋转的物品 | 装饰、奖励展示 |
| **方块（Block）** | 悬浮/旋转的方块模型 | 装饰、地标 |

> ⚠️ 本站未核实到该插件的具体命令名与配置键名，请以你版本的文档、配置文件注释和 `/fh help`（若存在）为准，不要照抄其他版本的键名。

### 3. 为什么选它而不是别的全息插件

| 对比 | 说明 |
|------|------|
| **和 DecentHolograms 一样好用** | 两者定位相近，**选一个就好，不要都装** |
| **和 FancyNpcs 同合集** | 功能不重叠，**可以共存** |
| **MiniMessage 支持** | 格式能力强 |
| **Paper / Folia 支持** | Folia 可用加分 |

> ⚠️ **本站未核实到 FancyHolograms 与 DecentHolograms 的具体兼容性**。两者是同类需求，**建议只装一个**以避免功能重叠和命令/数据包冲突。

### 4. 前置条件

| 要求 | 说明 |
|------|------|
| **服务端** | **Paper / Folia**（Modrinth 标注 paper + folia，**不建议 Spigot**） |
| **MC 版本** | 1.19.4 起 |
| **硬依赖** | 无 |

**支持 Folia** 是加分项。

### 5. 安装

1. 从官方渠道下载（**FancyInnovations/FancyPlugins**，Modrinth: `fancyholograms`）
2. 丢进 `plugins/`
3. 启动

> ⚠️ **版本通道要留意**：Modrinth 上 FancyHolograms 的发布有稳定版（`2.12.0+196` 这种带构建号的形式）和 `3.0.0-SNAPSHOT.x` 快照版**同时存在**。装之前确认你下的是哪个通道，快照版行为可能和稳定版不同。

生成的配置目录是 `plugins/FancyHolograms/`。

**命令**：主命令和子命令以你版本的 `plugin.yml` 和官方文档为准（官方文档在 `fancyinnovations.com/docs/minecraft-plugins/fancyholograms`）。

### 6. MiniMessage：能用，但要小心冲突

全息文字支持 **MiniMessage 格式**——RGB 渐变、悬浮、点击、装饰都能用。这让全息文字的表现力远超原版颜色代码。

**但这带来一个必须提前想的冲突问题：**

| 问题 | 说明 |
|------|------|
| **格式双重解析** | 如果服务器装了管聊天格式的插件（EssentialsX Chat、Carbon 等），**两套格式系统可能同时作用** |
| **颜色代码和 MiniMessage 混用** | 同一段文本里混用 `&a` 和 MiniMessage 标签，**结果可能不可预测** |
| **悬浮/点击在 NPC 上** | FancyNpcs 文档里也有 MiniMessage 说明，**两个插件的 MiniMessage 处理可能不一致** |

> **实践建议**：**选一种格式风格，全服统一**。要么全 MiniMessage，要么全传统颜色代码。**混用是「显示乱掉」的头号原因。** 具体语法见 MiniMessage 官方文档，本页不复述（抄一份过时的语法比不抄更糟）。

### 7. 性能：轻量但别滥用

**它比大多数全息方案轻**，但不是零成本：

- **服务端真实生成展示实体**——数量多会占实体数
- 每条多行文字 = 多个实体
- 玩家走近才加载（区块加载机制）——**远处不渲染，但实体可能仍存在**

**实际影响：**

| 场景 | 影响 |
|------|------|
| 几十条全息| 基本无感 |
| 几百条 | 值得注意，实体数会涨 |
| 上千条/玩家密集区 | 会成为问题 |

> **建议**：全息是**给玩家看的**，做一堆没人经过的全息是浪费。做「路过能看见」的那几个就够了。

### 8. 常见坑

**全息看不见**

- 走近了吗？**全息跟着区块加载**，远处不显示
- **玩家视角问题** —— 有些角度/位置可能正好被方块挡住
- 版本不匹配（全息是原版实体，**服务端版本要匹配**）

**MiniMessage 不生效/乱码**

- 格式风格混用了（`&a` + MiniMessage 标签）
- 被别的格式化插件处理了
- **确认服务器装了几个管格式的插件**

**和其他全息插件冲突**

**同类只装一个。** 两个全息插件会争同一批展示实体。

**区块卸载后消失**

**这是正常行为**，不是 bug。区块没加载，实体就不存在。**这也是它性能友好的原因**——不需要全图常驻。

**命令找不到**

以你版本的 `plugin.yml` 为准。命令体系跨版本可能变过。

### 9. 什么时候别装

- **原版就能解决** —— 告示牌/sign 就够的场合，别上全息
- **已有其他全息插件且用得好** —— **换插件的收益一般不值得**
- **需要玩家也能看到的** —— 有些全息是**仅管理员可见**（装饰性），想给所有人看需要额外配置
- **Spigot 服** —— 建议 Paper/Folia

### 10. 关于汉化

**本站未核实到该插件的官方中文语言文件机制。** 若要汉化需自行确认。

我们核实了它的仓库（FancyInnovations/FancyPlugins），在 `plugins/fancyholograms/src/main/resources/languages/` 目录下有 `default.yml`，**未找到中文语言文件**。

**好消息：这个插件最需要中文的地方本来就是你自己写的内容。**

| 内容 | 怎么汉化 |
|------|---------|
| **全息显示的文字** | ✅ **直接写中文** —— 内容是你配的，不走语言文件 |
| **物品/方块展示的名字** | ✅ 直接写中文 |
| **插件系统提示消息** | ❌ 是英文，需改语言文件（**机制未核实**） |

**要改系统消息的话**：进 `plugins/FancyHolograms/` 看有没有语言覆盖目录，`default.yml` 的键值可改，**具体加载方式以你版本的文件结构为准**。仓库 `FancyInnovations/FancyPlugins` 的 `languages` 目录可以帮你理解机制。

> **实际建议**：全息文字是给玩家看的内容，**你自己配的时候就写中文**。系统提示消息出现频率低，为它折腾语言文件收益不大。
