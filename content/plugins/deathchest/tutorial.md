## DeathChest 安装教程

### 1. ⚠️ 先说清楚它到底是什么形态

这一条必须先讲，否则你会在错误的渠道找半天。

**我们核实到的 DeathChest 官方项目（ikafly144/DeathChests）发布形态是数据包（datapack）和模组（mod），不是 Bukkit/Paper 插件。**

Modrinth 上它的发布记录长这样：

| 版本号 | 形态 |
|--------|------|
| `1.21.11-1.6+mod` | 模组版（Fabric / Forge / NeoForge / Quilt） |
| `1.21.11-1.6` | 数据包版 |
| `1.21.11-1.5` | 数据包版 |
| `1.21.10-1.4` | 数据包版 |

**所以：**

- **Paper / Spigot / Folia 服上装不了这个 jar** —— 它不是 `plugins/` 插件
- **Fabric / Forge / NeoForge / Quilt 模组服**用模组版
- **想用原版机制、不装模组**，用数据包版（放进世界目录的 `datapacks/`）

> ⚠️ **如果你要的是 Paper 插件**，请先明确：市面上有别的同名/近名项目形态各不相同（有的确实是 Paper 插件）。**本页只覆盖我们核实到的这个项目**，不要把别家的用法套到这一页上。下载前看清项目名和作者。

### 2. 它解决的痛点

原版死亡会怎样：**你背包所有东西撒在死亡点， mobs 会不会捡走是一回事，别人路过捡走了就是你的损失。** 死了还要跑回去捡，捡不全还得重刷。

DeathChest 的做法：**死亡瞬间，在死亡点生成一个运输矿车，把你身上的物品全放进去。**

比原版好在哪：

| 对比 | 原版 | DeathChest |
|------|------|----------|
| 物品去向 | 撒在地上，会被捡走/销毁 | 收进容器，不会被别人捡 |
| 死后 30 分钟 | 物品可能还在 | 矿车自动消失，**物品掉出来**（等于给你一次最后机会） |
| 掉进末地虚空 | 物品直接没了 | **矿车会浮起来**，还有信标指示位置 |

**掉虚空还能捡回来**是这个设计最实用的部分。基岩版和部分服务器默认虚空伤害会直接销毁物品，这个插件帮你兜住。

### 3. 硬性前提：keepInventory 必须是 true

**这是本节最关键的一条，官方明确写出来了。**

> `keepInventory` 不是 `true` 的话不会正常工作。

**原因很直白**：原版 `keepInventory=true` 时物品根本不掉落，插件没有物品可以存。插件的整个工作前提是「物品会掉」。

**所以这个方案的适用条件是：**

| 服务器设置 | 能用吗 |
|-----------|-------|
| `keepInventory=false` + DeathChest | ✅ **正常工作的唯一情况** |
| `keepInventory=true` | ❌ 没东西可存，插件空转 |
| `/gamerule keepInventory` 被 griefer 改 | ⚠️ 会被绕过 |

**看清楚这个前提。** 如果你的服本来就是「死亡不掉落」（很多单人/朋友服用 keepInventory 免死），**你根本不需要这个插件**。

### 4. 行为细节（官方实现）

| 行为 | 细节 |
|------|------|
| **容器类型** | 运输矿车（chest minecart） |
| **位置** | 死亡地点 |
| **虚空死亡** | 箱子浮到 y=0 或当前坐标的地面，**发射信标光柱**指示位置 |
| **方向指引** | 玩家自己来取时，**会有指引指向矿车所在方向** |
| **归属标识** | 容器有名字，能看出是谁的 |
| **超时** | 死后 **30 分钟**自动消失，物品掉出来 |
| **计时规则** | **矿车没被打开过时，时间不开始算** |

**「没被打开就不计时」这个设计很贴心**——你不用担心「刚死 29 分钟时矿车消失，物品掉一地又被人捡」。

**「归属标识 + 方向指引」解决的是核心痛点**：原版最大的问题是「我不知道我的东西掉哪了」。这里直接指方向。

### 5. 安装

**数据包版（原版，不装模组）**

1. 下载数据包文件
2. 放进**世界目录**下的 `datapacks/`
3. 用 `/reload` 或重启世界

> ⚠️ 数据包是**按世界**的。**多世界服要注意**：每个世界都要单独放，或者确认你的多世界插件（Multiverse-Core 等）是否支持数据包跨世界生效。

**模组版（Fabric / Forge / NeoForge / Quilt）**

1. 确认服务端用的是哪个加载器
2. 下载对应模组文件
3. 丢进 `mods/`
4. 重启

**玩家要不要装？** 官方对模组版的标注是 **client side 为可选（optional）**，意思是**服务端装了就能生效**，玩家端不强制。是否需要玩家自装取决于具体实现细节，**建议先在测试服验证一遍**。

### 6. 常见问题

**物品没进矿车**

先查 `keepInventory`。如果是 `true`，插件不会工作——**这不是 bug**。

**多世界服只有一个世界有效**

数据包是**按世界目录**加载的。检查每个世界的 `datapacks/` 目录。

**虚空死亡后找不到箱子**

**往上找。** 虚空死亡时矿车会浮到 y=0 或附近地面，并且有信标光柱。**下界的话要往对应的维度找。**

**矿车自动消失了，物品撒了一地**

30 分钟到了会自动消失掉出物品。**如果你不想冒这个险，死了尽快去取。**

**和别的「死亡掉落」插件冲突**

这类插件（自己实现死亡掉落处理的）**大概率互斥**——两个都想处理同一批物品。**同时装必出问题。**

### 7. 什么时候用 / 什么时候不用

**用：**

- 纯生存服，死亡惩罚要保留
- 地图很大，死亡点和spawn 距离远，捡东西麻烦
- 有末地虚空死亡的环境
- 玩家会为掉落物互相偷窃、吵架

**不用：**

- **`keepInventory=true` 的服** —— 直接不需要（前提不成立）
- **单人服** —— 死了就死了，跑回去捡就行
- **有其他死亡掉落插件** —— 冲突
- **死亡点就在家旁边的服** —— 这插件解决的痛点你本来就没有

> **说白了：这是一个「给死亡加一层缓冲」的方案。** 如果你的服死亡惩罚很重（PvP、抢地盘），它能显著减少扯皮；如果惩罚不重，它就是多此一举。

### 8. 关于汉化

**本站未核实到该插件的官方中文语言文件机制。** 若要汉化需自行确认。

好消息是**需要汉化的文本极少**：

- 运输矿车的**容器标题**（显示归属的名字）
- 信标/指引相关提示

要改的话：

1. 数据包版：解开数据包，找到其中定义容器名/提示的 JSON 文件
2. 模组版：看是否有语言资源目录
3. 官方仓库 `ikafly144/DeathChests` 搜 `lang` / `json` 相关文件

**容器的自定义名字是原版可格式化的**（可以用命名时的格式），你可能不需要改插件，只需要改命名方式。
