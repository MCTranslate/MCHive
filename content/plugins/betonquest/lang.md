# BetonQuest 汉化机制

> 以下路径来自官方仓库 `BetonQuest/BetonQuest` 的实际文件树核实。

## 一、结论：自带完整中文，含增量补丁机制

BetonQuest 仓库里共 **42 个语言相关文件**，中文占 3 个：

```
zh-CN.yml                    ← 简体中文（主文件）
zh-CN-Old.yml                ← 旧版中文（迁移用）
zh-CN.patch.yml              ← 中文增量补丁
```

这个覆盖度在任务插件里算好的——42 种语言意味着社区翻译维护得比较活跃。

## 二、`patch.yml` 是什么，为什么重要

这是 BetonQuest 比多数插件做得好的地方。

**`zh-CN.patch.yml` 是增量补丁**：你写在这个文件里的条目会**覆盖** `zh-CN.yml` 里的同名词条，但不用改主文件。

这样做的好处：

- **升级不丢翻译** — 主文件跟着版本更新，你的补丁独立存在
- **改动可追溯** — 一眼看出哪些是你改的
- **不污染上游** — 不用把整个中文文件 fork 一份

示例：

```yaml
# zh-CN.patch.yml
quest_name:
  intro: "初来乍到"
  boss_1: "深渊之主"
objective:
  kill_mobs: "击杀 %amount% 个 %mob%"
```

改完执行 `/bq reload` 生效，不用重启。

## 三、怎么改

### 改文案（推荐方式）

在 `plugins/BetonQuest/lang/` 下建 `zh-CN.patch.yml`，按上面的格式写要覆盖的条目。

**这是推荐做法**，因为升级时不会冲突。

### 直接改主文件（不推荐）

直接编辑 `zh-CN.yml` 也能生效，但**插件升级会覆盖你的改动**。除非你确定某个版本不会再更新，否则别这么做。

### 加新语言

复制 `zh-CN.yml` 改名成你的语言码（如 `zh-TW.yml`），再改里面的文本。语言码用标准的 `zh-CN` / `zh-TW` 格式。

## 四、三个坑

**改了不生效**

BetonQuest 读语言文件需要 `/bq reload`。**光重启服务器有时候不够稳**，用 reload 命令。

**`%amount%` 这类占位符别删**

语言文件里有占位符：

| 占位符 | 含义 |
|--------|------|
| `%amount%` | 数量 |
| `%mob%` | 怪物名 |
| `%player%` | 玩家名 |

删掉会导致消息里出现 `%%` 或者变量直接不显示。**翻译时只换文案，别动占位符。**

**中文文件名不要用 GBK 保存**

用记事本改完保存时，编码选 **UTF-8**。存成 ANSI/GBK 的话，YAML 解析可能失败，症状是任务日志变成乱码或者整个任务读不出来。

## 五、什么不会被汉化

语言文件只管**任务日志和界面文本**。这些不走语言文件：

- **NPC 对话** — 对话内容在任务定义里（`.yml`），要中文就直接在任务 YAML 里写中文
- **任务描述文本** — 同上，在任务定义里
- **物品/装备名称** — 走 Minecraft 原生机制

写任务时**建议直接用中文写对话和描述**，不用绕道语言文件——BetonQuest 的任务 YAML 本身支持 UTF-8。
