## VanillaMinimaps 安装教程

### 1. 它的技术路线：原版着色器

**这个插件最特别的地方，也是它所有优缺点的来源：它用原版的着色器（shader）机制画小地图。**

**这意味着两个关键事实：**

| 事实 | 后果 |
|------|------|
| **靠资源包工作** | 服务器要下发资源包，**玩家必须接受** |
| **这是 Java 版专属功能** | **基岩版永远不支持**（原版着色器是 Java 特性） |

**「不用客户端 mod」是真的**——玩家不需要装任何 mod，只需要接受服务器的资源包。**这比要求玩家装mod 的方案友好得多。**

### 2. ⚠️ 三个硬限制（官方明确列出）

**这三条是官方 README 里直接写明的「常见问题」，非常值得先看：**

| 限制 | 说明 |
|------|------|
| ❌ **和 OptiFine / Iris 光影不兼容** | 官方原话：**「OptiFine/Iiris 覆盖原版着色器。这个修不了。」** |
| ❌ **基岩版（Geyser）不支持** | 官方原话：**「永远不会被这个插件支持」** |
| ⚠️ **和某些优化mod 冲突** | Sodium（不带光影）、OptiFine（不带光影）**兼容**；**Iris/OptiFine 光影、MoreCulling、ImmediatelyFast 不兼容** |

> ⚠️ **第一条是最硬的**：**玩家只要装了光影，小地图就没了，而且修不了。** 这在以生电/建筑为主的社区里是常见配置——**你的用户群和光影用户高度重叠**。

### 3. 功能

| 功能 | 说明 |
|------|------|
| **小地图** | 显示在玩家身上/附近 |
| **客户端图层实体** | 实现方式 |
| **平滑旋转** | 跟随玩家朝向 |
| **实时世界渲染** | |
| **位置插值** | 移动更顺滑 |
| **更好的地图配色** | 借用了 Godlander 的地图配色方案 |
| **可配置标记** | |
| **全屏地图视图** | |
| **可配置方块状态颜色** | |

### 4. ⚠️ 资源包：必须理解的一件事

**这个插件靠资源包下发着色器和小地图的渲染层。** 这带来一个连锁问题：

> **如果你服上还有别的插件也在管资源包**（ItemsAdder、Oraxen、Minepacks 等），**它们可能会覆盖/冲突**。

官方 README 里直接说了这个问题：

> 如果你用 ItemsAdder 这类插件，**它们可能会覆盖资源包里的着色器** —— 需要去问那个插件的开发者怎么处理资源包。

**这是真实会遇到的坑。** 资源包管理是 Bukkit 插件生态里一个老大难问题，多个插件都想改资源包就会打架。

### 5. 那���装

1. 从 Modrinth 下载（**JNNGL/VanillaMinimaps**）
2. 丢进 `plugins/`
3. 启动

**要求**：

| 要求 | 说明 |
|------|------|
| **MC 版本** | ⚠️ **支持范围较窄**（见下） |
| **服务端** | Paper 系 |
| **玩家** | **必须接受资源包** |

> ⚠️ **版本支持要先确认。** Modrinth 上这个插件的版本覆盖范围比较窄（**官方 README 写的是「支持的服务端版本：1.21」**）。**如果你不是那个版本，先去确认有没有对应构建，别假定它能装。**

### 6. 「出现两个地图，一个在胸口一个在头上」

**这是官方列的第一个常见问题，说明一下原因：**

> 这意味着**资源包没有正确安装**，**或者你开了 Iris/OptiFine 光影**。

**排查：**

1. 确认玩家**接受了资源包**（服务器资源包设置里）
2. 确认**没开光影**（Iris / OptiFine shaderpacks）
3. 如果服上有其他资源包插件，**确认它们没有覆盖掉这个插件的资源包内容**

### 7. 什么时候用

**值：**

- **想要小地图，但不想让玩家装mod** —— 这是它的核心优势
- **服务器以生存/探索为主** —— 小地图对导航帮助大
- **玩家群是纯 Java 版** —— 没有基岩玩家冲突

**不值/ 先想清楚：**

- **社区里大量玩家用光影** —— ⚠️ **对他们直接无效，且修不了**。**这是最大的风险**
- **有基岩玩家** —— **对他们完全无效**。有 Geyser 的话慎重
- **服上已有资源包管理插件** —— 资源包冲突风险
- **想找的是「网页地图」** —— ⚠️ **这不是那个东西**。想要玩家在浏览器看地图（能标点、能分享）应该用 **BlueMap / Dynmap**

> ⚠️ **最后一条值得强调**：**玩家问「地图怎么share 链接」「怎么在地图上标家」，这些 VanillaMinimaps 都做不到。** 它是**客户端实时小地图**，不是**世界地图**。要后者用 BlueMap/Dynmap。这两个不冲突，可以一起上。

### 8. 性能

**它主要吃客户端渲染和服务端少量同步。**

| 方面 | 影响 |
|------|------|
| **服务端** | 负担相对轻（不是重实体/重数据包） |
| **客户端** | ⚠️ **要渲染地图，有一定GPU 开销** |
| **玩家视距** | 地图渲染范围和视距相关 |

> **主要影响在客户端。** 低端设备 / 集显玩家可能会有压力。

### 9. 常见坑

**出现两个地图 / 地图显示异常**

见上面第 6 点——**资源包没装对或开了光影**。

**装了光影就没了**

**修不了，官方明说。** 只能让玩家关光影。

**基岩玩家看不到**

**正常，官方说不支持。**

**和 ItemsAdder 等冲突**

⚠️ **资源包被覆盖。** 需要和那个插件的开发者确认怎么处理。

**和优化 mod 冲突**

**兼容清单**（官方）：

| Mod | 兼容 |
|-----|------|
| Sodium（无光影） | ✅ |
| OptiFine（无光影） | ✅ |
| **Iris / OptiFine 光影** | ❌ |
| **MoreCulling** | ❌ |
| **ImmediatelyFast** | ❌ |

### 10. 什么时候别装

- **社区大量用光影** —— ⚠️ **对他们无效**
- **有基岩玩家（Geyser）** —— 对他们无效
- **想要网页地图** —— **用错工具了**，要 BlueMap/Dynmap
- **服上资源包管理混乱** —— 会冲突
- **MC 版本不在支持范围** —— 装不了

### 11. 关于汉化

**本站未核实到该插件的官方中文语言文件机制。** 若要汉化需自行确认。

**但对这个插件来说汉化价值很低**——它的界面元素极少（就是小地图本身和少量配置项）。

**需要汉化的话：**

1. 进 `plugins/VanillaMinimaps/` 看有没有语言文件
2. 仓库 `JNNGL/VanillaMinimaps` 搜 `lang` / `locale`
3. **具体机制以你版本为准**

> **实际建议**：**你需要汉化的东西不多。** 玩家看到的是地图和少量文字（标记名是你配的，直接写中文）。**不值得为它专门搞汉化。**
