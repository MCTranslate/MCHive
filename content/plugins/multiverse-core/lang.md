# Multiverse-Core 自带中文，无需下载语言文件

Multiverse-Core 5.x 的 jar 里**内置了简体中文语言包**（`multiverse-core_zh.properties`，同时还有西语、波兰语、俄语、土耳其语等），插件消息会**自动跟随每个玩家客户端的语言**显示：

- 玩家客户端语言为「简体中文」→ /mv 系列命令的所有反馈自动显示中文
- 玩家客户端是其他语言 → 自动切换对应语言

所以本页**不提供 lang.yml 下载**——不要往 `plugins/Multiverse-Core/` 里放任何语言文件，新版不会读取，旧版（4.x）放错位置还会引发加载报错。

## 常见问题

- **游戏里还是英文？** 依次检查三点：① 你装的是不是 5.x 新版（4.x 时代的旧包不带这套语言机制）；② 客户端「设置 → 语言」是否为简体中文；③ 重进服务器（语言在进入时确定，运行中不热切换）
- **控制台输出是英文？** 正常现象，控制台固定使用英文，只有游戏内消息会按客户端语言本地化
- **Multiverse-Portals 等附属的提示是英文？** 附属插件的语言包独立维护，简体中文覆盖进度可能落后于主插件，个别未翻译的句子会回退到英文，属正常现象

## 世界管理常用反馈对照（注解速查）

自带汉化后你很少需要看英文，但排查报错时认识这几个词很有用：

| 英文单词 | 含义 | 注解 |
|----------|------|------|
| world / overworld / nether / end | 世界 / 主世界 / 下界 / 末地 | 世界环境类型，创建世界时的参数 |
| flat / amplified | 超平坦 / 放大地形 | 地形生成器类型（-t 参数） |
| alias | 别名 | worlds.yml 里设置的显示名，建议填中文 |
| spawn | 出生点 | /mv setspawn 设置的位置 |
| unloaded / loaded | 未加载 / 已加载 | /mv remove 后世界变 unloaded，文件还在，用 /mv import 重新加载 |
| removed / deleted | 卸载 / 删除 | remove 只卸载（可恢复），delete 物理删除世界文件夹（不可恢复） |
| destination | 目的地 | 传送门、传送命令指向的目标（世界、锚点或精确坐标） |
| anchor | 锚点 | Multiverse 自带的命名位置点，比坐标好记 |
| entry fee | 进入费用 | worlds.yml 里可给世界设置进入收费，需 Vault 支持 |
| respawn world | 重生世界 | 玩家在该世界死亡后重生去哪个世界 |

## 玩家名字或世界别名乱码？

worlds.yml 用 UTF-8 编码保存，现代服务器直接写中文即可。如果你的控制台/游戏内出现 `???` 或 `???` 样式乱码：确认编辑器保存为 **UTF-8（无 BOM）**，不要用 Windows 记事本保存；老版本客户端显示不了中文别名时，改用颜色代码 + 英文/拼音即可。
