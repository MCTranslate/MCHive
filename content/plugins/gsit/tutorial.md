## GSit 安装教程

### 1. ⚠️ 先说最关键的一件事：它需要资源包

**GSit 不是纯服务端插件。**

原因很直接——「坐下」这个姿势，是**客户端把玩家模型弯折**才能显示出来的。服务端只能告诉客户端「这个玩家现在是坐姿」，具体怎么弯、弯成什么样，是客户端渲染的。

所以：

| 组件 | 作用 | 缺了会怎样 |
|------|------|-----------|
| 服务端插件 | 记录状态、判定能否坐、处理离开时恢复 | 插件不生效 |
| **资源包（模型）** | 让客户端真的把玩家显示成坐姿 | **玩家站着不动，只是不掉进方块里** |

**很多玩家说「装了 GSit 没反应」，九成是资源包没装。**

GSit 会自动生成/下载它的资源包，并提示玩家接受。玩家需要在**服务器列表里点「接受」**，或者进服后按提示同意。这一步玩家不点，服务端这边配置再对也没用。

> ⚠️ 强制资源包（`forced pack`）是可选的，但**强烈建议开**。不开的话玩家随时能关，模型就回原样，姿态体验不一致。

### 2. 它能做什么

| 动作 | 效果 |
|------|------|
| 坐下 | 坐在台阶、方块边缘、楼梯上 |
| 躺下 | 平躺在地面、床上 |
| 靠墙站 | 贴墙（部分版本支持） |
| 自定义姿势 | 玩家在动作选择里换姿势（dance、wave 等） |
| 姿势锁定 | 坐下后不能被推、被水冲走 |

配套的还有个**动作选择菜单**（`/gsit menu`），列出所有可用姿势让玩家自己挑。

### 3. 版本与前置

**支持 MC 1.13 - 26.3**，需要 Spigot / Paper 系服务端。

- 无硬依赖
- 可选联动：ProtocolLib（部分功能需要）

**1.13 是下限。** 你要跑 1.8 - 1.12 的老版本，GSit 用不了。

### 4. 安装

1. 下载 jar 放进 `plugins/`
2. 重启服务器
3. 生成 `plugins/GSit/`，里面有配置文件和语言文件
4. 玩家第一次进服会被要求接受资源包

**资源包这件事要跟玩家说清楚。** 在进服公告里写一句「进服后点接受资源包，否则坐下功能无效」，能省掉一半的答疑。

### 5. 常用命令

| 命令 | 说明 |
|------|------|
| `/sit` | 在当前位置坐下 |
| `/unsit` | 站起来 |
| `/lie` | 躺下 |
| `/nlie` | 从躺下状态起来 |
| `/gsit menu` | 打开动作选择菜单 |
| `/gsit reload` | 重载配置 |

> 权限节点和更多子命令以你版本的 `plugin.yml` 和 `/gsit help` 输出为准。GSit 15 个语言文件里也包含命令帮助文本，所以**玩家在游戏里敲 `/gsit` 能直接看到中文帮助**——这算是个实用细节。

### 6. 配置要点

配置在 `plugins/GSit/` 下。**具体键名以你手上版本的配置文件注释为准**，本节只讲 GSit 的配置逻辑：

| 配置类别 | 管什么 | 建议 |
|---------|-------|------|
| Resource pack | 是否启用、是否强制、URL | 强制开启，否则玩家关了没效果 |
| Sit / Lie | 是否允许坐、允许在哪些方块上坐 | 小服建议全开，紧凑服可以限制到台阶和床 |
| 姿势 | 启用哪些姿势 | 默认那批够用，别一次开太多 |
| 限制 | 允许在哪些世界用、区块加载时能否用 | 战斗世界建议关掉躺下 |

**最需要注意的是「能坐在哪些方块上」这个开关。** 默认值通常比较宽松，如果你的服有建筑玩法，玩家能坐在半空中任意方块上会破坏画面。

### 7. 常见坑

**装了完全没反应**
资源包没接受。**这是 90% 的原因**。让玩家在服务器列表点接受，或者检查客户端是否拦截了资源包下载。

**能坐但姿势很怪**
资源包版本和服务端版本不匹配。**让 GSit 重新下发一次资源包**（`/gsit reload` 后玩家重新接受）。

**坐下去卡在方块里不出来**
- 别人给了你一个不兼容的插件推了你（`/unsit` 能解决）
- 区块被卸载
- 服务器卡顿导致位移包没送到

**其他玩家看得到坐姿，自己看不到**
这是客户端渲染问题。让他**完全退出游戏**（不是退到主菜单）重进。

**躺下会被攻击 / 躺下能躲技能**
很多服的战斗规则没考虑躺姿。**躺下时如果允许被攻击，是能被击中的**。在战斗类服务器里，「躺下」这个功能本身就该关——玩家会拿来当移动手段，影响 PvP 平衡。

**和别的姿态/动作插件冲突**
GSit 控制玩家姿势，Hirez 的 CustomAnimations、部分 NPC 插件也控制姿势。**同时装会出现拉扯、姿态闪烁、客户端崩溃。** 同时只留一个控制玩家姿态的。

### 8. 关于汉化

**GSit 自带简体中文和繁体中文**，共 19 个语言文件：

```
zh_cn.yml    ← 简体中文
zh_tw.yml    ← 繁体中文
```

命名用下划线风格（`zh_cn`），跟随玩家客户端语言自动切换。**19 个语言文件在同类插件里算多的**，说明作者对多语言是有认真做的。

机制、改文案方法和坑，见 [汉化机制](#/plugin/gsit) 页。

### 9. 什么时候别用它

- **1.12 及以下的老服** —— 不支持
- **硬核 PvP / 竞技服** —— 躺下会被当移动手段，直接破坏平衡
- **不打算让玩家装资源包**（比如强制模式） —— 那 GSit 的核心体验就没了
- **纯建筑服** —— 有 WorldEdit 的话，玩家自己用命令摆姿势更有效率
