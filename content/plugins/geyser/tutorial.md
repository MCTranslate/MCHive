## ⚠️ 先看这里：Geyser 走的是 beta 通道

**当前版本 `2.11.3-b1248` 是 beta 发布。**

这不是「小版本号」的意思——版本号里那个 `-b1248` 就是作者自己标的构建号，Modrinth 上 Geyser 的正式通道和 beta 通道是**分开发布的**。具体风险：

| 风险 | 说明 |
|------|------|
| 配置不兼容 | beta 之间升级没有兼容承诺，配置可能丢 |
| 可能崩服 | 长时间实战验证不如正式版 |
| 随时停更 | 作者没义务一直维护 beta 分支 |
| 客户端行为差异 | 基岩版看到的方块/物品/红石表现可能和 Java 不一致 |

**建议：**

- ✅ 测试服、朋友服 —— 可以玩
- ⚠️ 商业运营服 —— 认真评估风险，基岩版玩家是付费用户，出问题代价大
- ❌ 已经在稳定运行的服想加基岩 —— 先在测试服完整跑一遍

> 本页内容以 `2.11.3-b1248` 为准。**具体命令、配置键请以你手上 jar 里的实际文件为准**——beta 通道还在改。

## Geyser 安装教程

### 1. 它到底在做什么

Geyser 是一个**协议转换层**。基岩版（手机、主机、Windows 版）用的是 Bedrock 协议，Java 版用的是 Java 协议，两者不通用。Geyser 放在服务器前面做翻译：

```
基岩版玩家 ──Bedrock 协议──> Geyser ──Java 协议──> Paper 服务器
```

所以 Geyser **不是**「让基岩版有 Java 版的全部功能」，而是「大部分常规玩法能玩」。以下这些是**已知做不到或做不好的**：

| 项目 | 表现 |
|------|------|
| 材质/模型 | 基岩版客户端看不到 Java 版的贴图动画、药水粒子效果 |
| 红石 | 跨版本不一致，别指望 Java 版的红石科技原样搬过去 |
| 深层世界生成 | 新版本下界/超界结构可能不完整 |
| 插件自定义物品 | 依赖 Java 客户端资源包的显示效果会丢 |
| 模组 | 基岩版玩家**完全无法使用** Java 模组 |

### 2. 两个组件，别搞混

Geyser 生态是两个 jar，缺一不可：

| 组件 | 作用 | 必需性 |
|------|------|--------|
| **Geyser** | 协议转换本体 | 必需 |
| **Floodgate** | **让基岩版玩家免账号验证直接进服** | 想让基岩玩家进来就必需 |

**Floodgate 是干什么的**：Java 版需要正版账号验证（正版登录 / 正版验证服）。基岩版玩家没有 Java 版账号，怎么进来？Floodgate 的做法是**开一个「 Floodgate 通道」**——基岩版玩家连上 Floodgate 指定的 UDP 端口，服务端用他们的 Xbox Live 身份做一次握手，之后就走 Geyser 进来，不再走 Java 的正版验证。

> ⚠️ **不装 Floodgate 的话，基岩版玩家根本进不来**——他们会卡在登录界面。Geyser 本体只负责协议翻译，不解决身份问题。

**装 Geyser 但不装 Floodgate 的场景**：给已经用其他方式登录（比如 Xbox 好友一起玩的「无需验证」方案）的服当协议层。但那涉及绕过验证，本站不推荐，也不展开。

### 3. 皮肤问题（新手最常踩的坑）

基岩版玩家想用**自己的皮肤**，光装 Floodgate 是不够的。

原因：基岩版客户端默认显示 Xbox 账号绑定的皮肤，服务端发的 Java 版皮肤（OptiFine 皮肤、皮肤站皮肤）基岩版认不出来。要让基岩玩家看到 Java 皮肤，需要额外方案：

| 需求 | 方案 |
|------|------|
| 官方皮肤 | 一般直接可用（Xbox 皮肤两边通用） |
| Java 站皮肤（OptiFine / LSS / MineSkin 等） | 需要额外的皮肤桥接插件（社区有多种实现） |
| 披风 | 多数皮肤桥接方案能带，取决于实现 |

> ⚠️ **本站未核实到 Geyser 官方内置的皮肤桥接方案。** 皮肤这块属于社区第三方方案，请自行确认所用插件的当前维护状态和隐私政策（皮肤方案往往需要把你的 UUID / Xbox ID 发给第三方）。**不要把这类方案装到有隐私要求的服上之前想清楚。**

### 4. 安装

1. 从官方渠道下载 Geyser 和 Floodgate（**两个都要**）
2. 丢进 `plugins/`
3. 启动生成配置目录
4. **停止服务器**，编辑配置
5. 再启动

关键一步是第 4 步——**首次启动生成的配置文件里有占位值，不改直接用会连不上。**

配置文件在 `plugins/Geyser/` 和 `plugins/floodgate/` 下。**具体配置键名请以你版本生成的 `config.yml` 注释为准**，本页不列键名——beta 通道的键名会变，照抄旧教程的键名很可能配错。

你需要确认的核心是这几个值（**按你实际生成的配置文件里的键名填**）：

| 要填什么 | 说明 |
|----------|------|
| Floodgate 的 **UDP 端口** | 两个组件必须填同一个端口 |
| Floodgate 的 **key（密钥）** | Geyser 和 Floodgate 两侧必须一致 |

**端口冲突**是最常见的失败原因：UDP 端口被其他程序占用（比如某些加速器、部分容器网络配置），Floodgate 起不来，日志里能看到端口绑定失败的报错。

### 5. 需要开放的网络端口

| 端口 | 协议 | 用途 |
|------|------|------|
| 服务器端口 | TCP | 基岩版/Java 版玩家都走这个（如果 Geyser 作为插件装在服务器上，共用同一端口） |
| Floodgate 端口 | **UDP** | Floodgate 握手通道 |

**UDP 必须放行。** 只开 TCP 的话，Java 版玩家正常玩，基岩版玩家连不上——这是最难查的一类问题，因为服务端日志可能什么都没错。

> 如果你在 NAT 后面，还需要路由器上做 UDP 端口映射。家用宽带的 UDP 转发经常是坏的，如果自测连不上而别人能连上，先怀疑自己家的路由器。

### 6. 和 ViaVersion 的关系

这两个解决的是**不同方向**的问题，经常被搞混：

| 插件 | 解决的问题 | 方向 |
|------|-----------|------|
| **Geyser** | 让**基岩版客户端**进 Java 版服务器 | 跨**版本系**（Bedrock ↔ Java） |
| **ViaVersion** | 让**老版本 Java 客户端**进新版服务器 | 跨**版本号**（1.8 ↔ 1.21） |

**Geyser + ViaVersion 可以共存**，各管一头。很多人两个都装，这是对的。

但要注意 ViaVersion 的已知副作用：**它允许老版本客户端进服，会削弱一些反作弊/协议层插件的效果**（比如 Vulcan 这类看数据包行为的）。装了 ViaVersion 后如果反作弊误报变多，先从这里查。

### 7. 常见坑

**基岩版玩家进不来，日志无报错**

按顺序排查：

1. Floodgate 装了吗？**装了，Geyser 侧配的端口和 Floodgate 侧一致吗？**
2. **UDP 端口在防火墙/安全组放行了吗？**（不是 TCP）
3. key 两边一致吗？
4. 玩家是不是用了 Xbox 家庭组/跨区账号？部分情况下握手会被拒

**基岩玩家能看到世界但操作异常/掉线**

- 开了 1.21+ 的新协议特性但 Geyser 版本跟不上，beta 通道不保证跟上
- 玩家客户端版本比 Geyser 支持的上限还新

**内存占用比想象的高**

Geyser 要做协议翻译和区块映射，**吃内存**。加上 Floodgate 握手，200-300 MB 起步是正常的（视同时在线的基岩玩家数量）。1-2 GB 的小服要算一下这笔账。

**性能问题：基岩玩家多的时候 TPS 掉**

协议转换是主线程附近的活。基岩玩家数量多、区块加载密集时会明显。缓解手段：

- 限制视距（Geyser 自己有视距相关配置项，**键名以你的配置文件为准**）
- 别让基岩玩家和新版 Java 玩家挤在同一台机器上（考虑 Geyser 独立部署）

**和某些插件不兼容**

Geyser 无法支持依赖 Java 客户端行为的插件功能。典型：

- 某些**自定义资源包**效果（基岩版有自己的资源包机制，不吃 Java 的）
- 依赖客户端 mod 的插件功能
- 部分 GUI 插件的自定义材质

装之前先想清楚：你的服里有没有强依赖 Java 客户端特性的玩法。

### 8. 独立部署 vs 作为插件装

Geyser 有两种部署方式：

| 方式 | 适合 |
|------|------|
| **作为 Paper 插件**（`plugins/` 里的 jar） | 单机小服，直接丢进去最省事 |
| **独立进程**（单独一台机器/容器） | 机器性能分化明显时——把协议转换的 CPU/内存开销和游戏服分开 |

**小服就用插件形式。** 独立部署是为了让 Geyser 的开销不和游戏服抢资源，只有在基岩玩家数量可观、你又在意 TPS 时才值得。

### 9. 什么时候别用 Geyser

- **服里有大量 Java 客户端专属玩法** —— 展示效果、Java 版资源包、自定义客户端
- **内存紧张的小服** —— 200 MB+ 的开销换一批新玩家，先算清值不值
- **要求稳定的商业服** —— beta 通道的风险不对等
- **有跨版本红石/建筑玩法** —— 基岩版的机制差异会破坏设计

### 10. 关于汉化

**本站未核实到 Geyser 官方中文语言文件机制。** 若要汉化需自行确认。

Geyser 面向的是**基岩版客户端玩家**，界面语言跟随玩家自己的游戏设置。**它自己发的提示消息**（报错、配置提示）是否可汉化，请自行确认：

1. 进 `plugins/Geyser/` 目录，看有没有语言文件或 messages 相关的配置文件
2. 在 `config.yml` 里搜 `message`、`locale`、`lang` 这类关键词
3. Geyser 的开源仓库（官方 GitHub）里搜 `lang/`、`zh` 目录

**不要照抄其他版本的配置键名**——beta 通道的键名会变。如果找不到语言文件机制，通常意味着只有少量英文提示，不值得为此折腾。
