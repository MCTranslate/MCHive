## ⚠️ 先想清楚：你在拿什么换什么

**这个插件用「玩法深度」换「效率」。这是笔交易，不是纯赚。**

```
你得到：  一次清一片，效率极高
你失去：  探索感、发现感、围栏和梯子的存在意义、矿脉的紧张感
```

**很多人装完爽三天，第四天觉得游戏没意思了。** 那不是错觉，是这个插件的正常效果。

官方仓库：<https://github.com/BeanFeed/TreeChopper>

### 1. 它做了什么

| 操作 | 原版 | TreeChopper |
|------|------|-----------|
| 挖树 | 打一个树干，得绕着捡地上的木头 | **打一个，整棵树的木头直接进包** |
| 挖矿 | 顺着矿脉一格格挖，或者一个个打 | **打一个，相连的同种矿全出** |

**为什么说它削弱玩法，而不只是「省事」：**

原版 Minecraft 里，**「准备下矿」本身是玩法的一部分**：

| 原版的仪式 | 被消解后 |
|-----------|---------|
| 挖矿前先做安全屋、放床、检查岩浆 | 不需要了，去一趟就回 |
| 找到钻石那一刻的兴奋 | 和挖石头差不多 |
| 楼梯、电梯、火把的布置 | 连锁直接上下 |
| 「够不够挖一整组矿」的规划 | 不需要规划了 |

**连锁的效率越高，这些准备的价值就越低。** 这就是它在削弱什么。

### 2. 适用场景：什么服适合装

**✅ 适合：**

| 场景 | 为什么适合 |
|------|-----------|
| **有独立矿物倍增插件的服** | 矿物产量已经被另一个系统按设计放大了，连锁的边际影响变小 |
| **建造 / 建筑为主的服** | 木料和石料是消耗品，快速补货是刚需 |
| **玩家反复抱怨挖矿无聊** | 痛点已经存在，插件是解药 |
| **小服、朋友服** | 效率损失的痛感低，玩法深度本来也不是重点 |
| **纯建造/创造向生存服** | 没人靠挖矿吃饭 |

**❌ 不适合：**

| 场景 | 为什么不适合 |
|------|------------|
| **以采矿为核心玩法的服** | 你的核心玩法被它砍了 |
| **靠「稀有资源获取」做内容设计的服** | 稀有资源变容易 = 内容贬值 |
| **奖励模式（P2W 经济）** | 采矿本来是玩家赚钱的正当途径，压缩它会让经济结构失衡 |
| **硬核生存服** | 硬核的定义就是这些麻烦 |
| **想靠「准备过程」做内容的服** | 连锁把准备过程跳过了 |

### 3. ⚠️ 和矿物倍增系统的关系：这是关键判断

**如果你有独立的矿物倍增插件（矿物追踪、倍数叠加、矿脉增强之类），连锁的影响会被显著吸收。**

```
没有倍增系统：
  原版矿产量 = 1
  装连锁后  = 10x ~ 几十倍  ← 产出膨胀了几十倍

有倍增系统：
  原版矿产量 = 1
  装连锁后  = 10x
  但倍增系统已经把设计产量定在 20x
  → 实际影响 = 1.5x ← 影响小得多
```

**所以判断标准是：你服里 mineral 产出被谁管着？**

- 已有成熟的矿物倍增/经济调控系统 → **装连锁的影响可控**
- 纯原版产出，靠采集做经济 → **装连锁等于放开经济阀门**

> 如果你还**没有**倍增系统，又想装连锁，**建议先做倍增系统**（那部分内容在 [经济系统配置](#/guide/economy-setup) 里有思路），再上连锁。否则你会同时面对「产出膨胀」和「玩法变浅」两个问题。

### 4. 和 Timber / VeinMiner 怎么选

这三个是**同类竞争关系**，不是互补：

| 插件 | 范围 | 特点 |
|------|------|------|
| **TreeChopper** | 树 + 矿 | 覆盖最全，两者都做 |
| [Timber](#/plugin/timber) | **只砍树** | 专精，行为可预测 |
| [VeinMiner](#/plugin/veinminer) | **只挖矿** | 专精，服务端侧生效 |

**建议：**

- **只想要砍树方便** → Timber，更单纯
- **只想要挖矿方便** → VeinMiner
- **两个都要，且不介意玩法被削弱** → TreeChopper

> ⚠️ **不要三个一起装。** 连锁判定会互相抢：谁先处理方块、连锁范围怎么叠、掉落怎么算——这些组合起来的行为不可预测。你会在工单里看到「有时候挖树挖出了矿石」这种 bug。

### 5. 安装

1. 从 <https://github.com/BeanFeed/TreeChopper> 或插件站下载
2. 丢进 `plugins/`
3. 启动，看控制台有无报错
4. **读配置** —— 连锁范围、消耗、是否需要特定工具，这些都需要你明确
5. **测一遍** 树和矿，确认连锁范围符合你的预期

> ⚠️ 支持区间 **MC 1.21 - 1.21.10**。注意这个区间比多数插件窄，**新版本 MC 请先确认**。

### 6. ⚠️ 配置上要盯的几件事

不列具体配置键名（**以你版本配置文件内的注释为准**），但这几类项目你必须逐条确认：

| 项目 | 为什么重要 |
|------|-----------|
| **连锁范围上限** | 连锁是有限制的，不设上限的话挖一座山试试 |
| **是否消耗耐久/工具** | 如果完全不消耗，工具耐久系统就形同虚设 |
| **是否区分工具类型** | 斧头挖矿 vs 镐子挖树，行为应该不一样 |
| **是否只对玩家有效** | 如果对刷怪塔也生效，机器会变成全自动 |
| **权限控制** | 是否限制只有特定权限能用 —— 这是你给老玩家的特权工具 |
| **世界/区域开关** | 是否能在某些世界关掉（比如刷怪塔世界不要连锁） |

**第 4 条特别容易出事。** 如果连锁对非玩家实体也生效，你的刷怪塔、机器就会自动连锁采集，可能瞬间把地图挖空。这是很多服装连锁后回档的原因。

### 7. 常见问题

**连锁把不该挖的挖了（比如基岩、容器、TNT）**

连锁判定应该有一个**黑名单/白名单**。如果没有，你可能挖掉容器里的东西、或者碰到 TNT 连锁爆炸。**装完一定要在你重要的区域外面先测一遍。**

**和领地保护冲突**

连锁挖到的方块会**跨区块、跨领地边界**，这会触发 WorldGuard 之类插件的检查。典型现象是**连锁到一半断了**，或者部分方块挖不掉——原因就是保护插件在链条中途拦了一下。

**老玩家抱怨「没意思了」**

**这不是 bug，这是这个插件的设计效果。** 应对方式：给老玩家补偿别的乐趣（新区域、建造任务、探索内容），或者给一部分玩家权限限制只让新玩家用。最诚实的做法是**承认它改变了游戏**——如果服的核心玩法受损，宁可回退。

### 8. 关于汉化

**本站未核实到 TreeChopper 的官方中文语言文件机制。** 若要汉化需自行确认。

引导式排查方法：

1. 进 `plugins/TreeChopper/` 目录，**搜文件名**找 `lang`、`locale`、`messages`、`zh`
2. 打开配置，**搜关键词** `message`、`locale`、`lang`
3. 这类插件的文本通常很少，主要是「连锁挖到了 N 个方块」这类提示。如果它压根没有提示消息，那可能**根本不需要汉化**
4. 特别注意**物品名和方块名走的是 Minecraft 本体语言**，不是插件的——「木头」「钻石」这些是游戏自带的，不用改

> 连锁插件的汉化需求普遍很低。**别为一个提示消息花半小时，先看有没有必要。**

想看全站各插件的汉化情况，见 [插件汉化与本地化完全指南](#/guide/plugin-localization)。

### 9. 什么时候别用它

- **采矿是核心玩法** —— 直接冲突
- **靠采集做 P2W 经济** —— 产出膨胀会打崩平衡
- **没有矿物倍增系统却想装** —— 先做调控
- **硬核生存服** —— 定义冲突
- **同时想用 Timber / VeinMiner** —— 选一个
