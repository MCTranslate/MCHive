## Timber 安装教程

### 1. 它做什么，一句话说清

**原版 Minecraft 砍一棵树是这样的：**

```
打树干 → 树倒了 → 得到原木
     → 但树叶还挂着，地上散着 6-20 个树苗
     → 你得绕着捡，或者爬上去打
```

**Timber 让你打一下树干，整棵树（含树叶和树苗）的掉落直接进背包。**

连锁范围是向上生长的方块——砍最底下的树干，整根柱子加附着的树叶一起掉。

### 2. 为什么这个需求是刚需

不是「方便一点」，是**痛点具体到无法忍受**：

| 场景 | 原版的痛苦 |
|------|-----------|
| 砍树盖房子 | 一棵树要打几十下（耐久掉光） |
| 大量砍树做燃料 | 地上全是树苗，要跑很久 |
| 极限模式 | 树苗被别的玩家捡走了 |
| 玩家觉得「挖木头」是苦差 | 新手十分钟就放弃了 |

**尤其是极限/生存服**——木头是前期唯一能大量获取的燃料和材料。原版挖木头的体验是劝退新手的重灾区。

### 3. ⚠️ 危险：默认开着就是灾难

**Timber 的所有风险都来自同一个特性：它不看这是不是你的树。**

```
玩家 A 的木森林基地
  → 隔壁玩家 B 走过来，打了一下 A 的树干
  → 整片森林没了，材料全进了 B 的背包
  → A 的基地被清空，A 不知道是谁干的
```

**这个插件天然是个「一键偷树」按钮。** 不是因为它有漏洞，而是因为它的功能本身就是「砍倒眼前的树」。

**所以上手第一件事不是开功能，是配保护。** 见第 5 节。

### 4. 版本与依赖

**支持 MC 1.14 - 26.3。**

- 无硬依赖
- 可选：领地保护插件（**实际是必需的**，见下）

**1.14 是下限。**

### 5. 上手顺序：先配保护，再开功能

**顺序反了你会后悔。**

```
① 装 Timber，重启，但先不开功能（或限制在无人区）
② 配好领地保护 / 权限
③ 确认保护生效（去别人家砍一下试试，打不出来）
④ 再开放功能
```

**具体的保护措施：**

| 措施 | 作用 |
|------|------|
| 领地保护（WorldGuard / GriefPrevention 等） | **最重要**——别人的家砍不动 |
| 玩家自建领地 | 木头多的地方先圈起来 |
| 限制在特定世界开 | 生存服开，冒险服别开 |
| 权限节点控制 | 至少要有权限的玩家才能用 |

**用 Timber 就必须用领地保护。** 这两个是配套的，不是可选搭配。

### 6. 命令与开关

| 命令 | 说明 |
|------|------|
| `/timber` | 切换自己的 Timber 开关 |
| `/timber toggle` | 同上（**具体写法以你版本为准**） |
| `/timber <其他子命令>` | 视版本而定 |

> ⚠️ **以你版本的命令帮助输出为准。** 核心是「每个玩家能自己开关」这一点——**这个设计很好**，玩家可以在自己家里关掉它，在外面打开。**确认这个功能存在，如果存在，善用它。**

### 7. 配置要点

配置在 `plugins/Timber/` 下。**具体键名以你手上版本的配置文件注释为准。**

逻辑上涉及：

| 类别 | 管什么 | 建议 |
|------|-------|------|
| 启用范围 | 哪些世界能用 | 生存世界开，创造世界随便（创造模式能秒挖） |
| 连锁范围 | 往上连锁多少格 | **别开太大**——一棵树连锁 20 格跨进了别人家就麻烦了 |
| 掉落模式 | 树苗/树叶怎么处理 | 原版会撒一地，插件可以收进背包 |
| 工具要求 | 是否必须用斧 | 关掉的话空手也能砍 |
| 耐久消耗 | 砍多少耐久 | 影响平衡 |

**「连锁范围」这一项要结合第 3 节看。** 连锁距离大 = 影响范围大 = 越界概率高。**保持在树的高度范围内比较安全。**

**「是否撒落树叶树苗」这一项值得想一下：**

| 方案 | 效果 |
|------|------|
| 全部进背包 | 玩家省事，但要清理背包 |
| 撒到地上 | 原版体验，但会满地掉落物（可能被别人捡） |

很多服选前者，然后抱怨「玩家说背包满了」——**这是取舍，不是 bug**。真要严格还原原版体验，第二种更合适。

### 8. 常见坑

**玩家基地被清空了**
**用 Timber 就必须上领地保护。** 没有保护 = 给了所有人一个偷树按钮。这不是 Timber 的 bug。

**连锁进了别人的领地**
连锁范围太大。**调小范围，或者确认领地保护优先级高于 Timber。** 这两个插件的拦截顺序要注意测。

**和领地保护冲突（一方不生效）**
取决于安装顺序和具体插件的拦截机制。**实测一次**：去别人领地里打树干，看是被拦住了还是被连锁了。**以实测为准，不靠猜。**

**耐久消耗不合理**
- 关掉了耐久要求 → 空手砍树，速度飞快
- 耐久要求太高 → 玩家抱怨斧子不够用

**树苗 / 树叶满地**
掉落模式的取舍，见第 7 节。**想要一个干净的地面，就得让玩家背包承担这些。**

**和砍树类插件同时装**
市面上有若干同类插件（连锁砍树）。**同时装会重复处理**——表现为砍一下掉两倍材料，或者日志报错。**只留一个。**

**和 WorldEdit 冲突**
WorldEdit 有自己的方块处理逻辑。**在 WorldEdit 选区范围内用 Timber 可能出现选区被连锁修改**，导致 WorldEdit 撤销出问题。**大型工程前先备份。**

**玩家说砍不动 / 权限不足**
- 玩家没给权限节点
- 领地保护把玩家的砍树也拦了（**在保护区内 Timber 应该失效**，这不是 bug）

**大型红石/建筑被误连锁**
有些结构（比如用木头搭的巨型建筑）会被连锁砍掉一大片。**开在生存服的玩家区，范围别开太大。**

### 9. 关于汉化

**本站未核实到 Timber 的官方中文语言文件机制。** 若要汉化需自行确认。

引导式排查方法：

1. 进 `plugins/Timber/`，看有没有语言文件目录
2. 搜配置文件里有没有 `message`、`language`、`locale` 段落
3. **注意区分**：
   - 插件自己的消息（切换开关的提示、没权限的提示）—— 服务端发出
   - **连锁砍树时的音效/粒子提示** —— 这些往往不走语言文件
4. 消息量通常很小（就是个「已开启连锁砍树」之类的提示）。**如果只有一两行，用其他插件的消息接管改掉可能比汉化它更省事**

想看全站各插件的汉化情况，见 [插件汉化与本地化完全指南](#/guide/plugin-localization)。

### 10. 什么时候别用它

- **没有领地保护** —— **绝对不要装**，见第 3 节
- **纯创造模式建筑服** —— 创造模式能秒挖，没意义
- **PvP / 争夺型服务器** —— 「打一下就偷走一片林」是核心玩法漏洞
- **竞技/高强度生存服（ hacked / 相邻生存）** —— 会破坏平衡
- **服务器有大型木质建筑** —— 连锁误伤风险高

### 11. 平衡性：连锁砍树到底该不该给

**这是一个设计判断，不是「装了就好」的事。**

| 立场 | 理由 |
|------|------|
| **该给** | 挖木头是新手劝退点；木炭/木头的获取效率影响生存节奏 |
| **不该给** | 破坏了「手动采集」的劳动感；材料获取太快会让其他环节失去意义 |
| **折中** | 给，但**消耗耐久**；或者**只在特定区域给**（玩家自己圈内） |

**大多数生存服会选折中**：功能开着，但耐久消耗调高一点，保留一点「要换斧」的重量感。

**如果你不确定，先开小范围 + 高耐久试试，观察一周玩家反馈再调。** 这比看别人的配置抄数字靠谱——**你的服的节奏只有你知道**。
