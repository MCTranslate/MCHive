## LifestealZ 安装教程

### 1. 它做什么

**打中东西，回血。**

```
你攻击一个生物 → 命中 → 你回复一定量的生命值
```

数值通常是**固定值或按伤害比例**计算，取决于配置。这个机制有个通俗名字叫「吸血」，在 PvP 和生存里都被广泛使用。

**它改变的是「容错」：**

| 无吸血 | 有吸血 |
|--------|--------|
| 两个人对打，A 有 10 血、B 有 10 血，谁先打死对方谁赢 | 打到对方就能回血，**血多的一方优势被放大** |
| 打怪要小心翼翼，血量是稀缺资源 | 打怪能回血，敢冲 |

### 2. ⚠️ 它对 PvP 平衡的影响：这是本页最需要说的事

**吸血不是「小加成」，它是一个会自我强化的机制。**

```
你有 20 血，对手 10 血
  → 你打中对手，吸 2 血 → 你 22 血
  → 对手打中你，你掉血
  → 血多的更容易赢 → 赢的继续吸 → 更血多
  → 差距被放大，血少的一方基本翻不了盘
```

**在 1v1 的近战对拼里，吸血让「血量压制」变成「胜率压制」。** 本来 50% 的对局可能被拉成 70:30。

**几个具体的破坏场景：**

| 场景 | 问题 |
|------|------|
| **1v1 近战对决** | 血多即胜，技巧和操作的价值下降 |
| **老玩家 vs 新玩家** | 新玩家回不起血，**挫败感极强** |
| **PVP 竞技服** | 属于外挂性质机制，**很多竞技服明确禁止** |
| **带治疗的职业体系** | 如果你还有回复道具/技能，**和吸血叠加后回血过量** |

**所以它适合什么服，很关键。**

| 适合 | 不适合 |
|------|-------|
| 生存服（PvE 为主） | 竞技 PvP |
| 休闲向 PvP（不是竞技） | 高端 PVP 服 |
| 想让玩家敢探索、不怕死 | 服务器之间要公平对抗 |
| 有其他「生存向」设定的服 | 已经有回血机制的 |

**如果你不确定服是 PvE 还是 PvP 向：先别装。** 这个机制装了之后想关会有一批玩家觉得「游戏变了」。

### 3. 版本要求

**支持 MC 1.19 - 26.1.2。**

- **1.19 是下限**
- 上限 26.1.2

需要 Spigot / Paper 系服务端。

### 4. 安装

1. 下载 jar 放进 `plugins/`，重启
2. 生成 `plugins/LifestealZ/`，含配置和语言文件
3. 配置吸血数值
4. 确认 PvP 相关设置

**注意**：`plugins/LifestealZ/` 里同时有**配置文件**和**语言文件**，两者要分清——改错文件（把文案写进配置）不会生效。

### 5. 配置要点

配置在 `plugins/LifestealZ/` 下。**具体键名以你手上版本的配置文件注释为准。**

逻辑上涉及：

| 类别 | 管什么 | 注意 |
|------|-------|------|
| 吸血量 | 每次命中回多少血 | **这个数值直接决定平衡，见第 2 节** |
| 触发条件 | 打玩家 / 打生物 / 都行 | 很多服**分开配**（打怪回得多，打人回得少） |
| 是否需要权限 | 谁能用吸血 | **给不给所有人是两个完全不同的游戏** |
| 上限 | 血量上限是否被突破 | 有些实现允许超过原版上限，**这会引发「血条异常」的报告** |
| PvP 开关 | PvP 时是否生效 | 可以在 PvP 区域关掉 |

**最需要想清楚的两项：**

**「PvP 时是否生效」** —— 这一个开关就能让插件从「PvP 平衡破坏者」变成「PvE 便利插件」。

**「血量上限」** —— 如果允许突破 20 点血上限，玩家会看到血条显示异常（超过满血、或者数字乱码）。**这是玩家最常见的抱怨来源**，而且看起来像 bug。

### 6. 常用命令

| 命令 | 说明 |
|------|------|
| 主命令 / 帮助 | 查看用法 |
| 相关状态命令 | 查看自己当前是否启用等（以实际输出为准） |

> ⚠️ **具体命令以你版本帮助输出为准。** 这类插件的命令通常较少。

**权限方面**：如果「谁能用」是可配的，那管理员就要想清楚要不要给 VIP / 玩家组。**给一部分人的吸血会造成 PvP 中的实质性不公平**——这比全员都有更糟（因为只有知情者能用）。

### 7. 常见坑

**玩家说血条显示不对 / 溢出 / 乱码**
**超过原版血量上限的表现。** 见第 5 节。**这是最常见的投诉。** 要么调低吸血量，要么配置上限。

**PvP 变难受了**
那就是这个插件的作用。**要么调低数值，要么在 PvP 区域关掉。** 别硬扛——PvP 是PvP 体验的核心。

**和回血插件 / 药水机制冲突**
- 治疗药水 + 吸血 = **回血溢出**，玩家在满血时被吸会浪费
- 一些战斗插件自带吸血 = **两个机制叠加**，回血量翻倍
- **先查一遍你装的其他战斗/生存插件有没有自带吸血。** 这是最容易漏的一步。

**和击杀回血机制冲突**
有些插件是「击杀时回血」，这个是「命中时回血」。**同时装 = 双重回血。**

**新玩家流失**
老玩家有吸血、能扛，新玩家没有。**一个正常生存服从零开始玩，前两个星期死亡率很高** —— 这段时间吸血带来的体验差异最大。**小服可以先观察新手的感受。**

**和反作弊 / 战斗检测冲突**
Vulcan 这类反作弊可能会把「回血速度异常」报出来（**但通常是误报** —— 合法插件造成的血量变化可能被误判）。**装反作弊 + 吸血之后要有心理准备会收到误报报告。**

**PvP 规则里没考虑「能回血」这件事**
如果你的服有「血量低于 X 装备禁用」这类规则，吸血会让这个门槛形同虚设。

### 8. 关于汉化

**LifestealZ 自带简体中文**，共 **15 个语言文件**，中文是 `zh-CN.yml`。

注意**命名风格是连字符 + 大写语言码**（`zh-CN`），和 GSit 的下划线风格（`zh_cn`）**不一样**。**给别的插件做汉化方案时不能一套模板套所有插件。**

机制、改文案方法和坑，见 [汉化机制](#/plugin/lifestealz) 页。

### 9. 什么时候别用它

- **竞技 / 高端 PvP 服** —— 直接是破坏平衡
- **已经有回血机制的服**（治疗药水、吸血职业、技能回血）—— 叠加成 bug
- **PVP 排行榜 / 战绩系统** —— 血量压制会让排名失真
- **服务器之间要公平对比的服** —— PvE 服开 PvE 吸血可以，跨服对比就不行
- **想让玩家敬畏死亡的服** —— 吸血会削弱死亡的重量

### 10. 如果你就是想要「回血」效果

**吸血不是唯一的实现方式，而且不一定适合你的服：**

| 想要的效果 | 更适合的方式 |
|-----------|------------|
| 打怪能持续续航 | **吸血**（最直接） |
| 升级/成长能变强 | 等级成长、装备、附魔 |
| 探索时不容易死 | 食物/药水/装备减伤 |
| 战斗失误有容错 | 装备提供的减伤、护盾类机制 |
| 玩家能自愈 | 提供治疗道具/食物，靠玩家自己选择 |

**吸血的问题是「自动回血，不给玩家决策空间」。** 如果你想让玩家**主动管理**风险和续航，装备/道具/食物的方案往往比吸血更合适。

**当然，如果你就是想做一个「敢冲敢打」的服，吸血是对的。** 只是要知道代价。
