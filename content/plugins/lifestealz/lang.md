# LifestealZ 汉化机制

> 以下结论来自官方仓库文件树核实。LifestealZ 的多语言覆盖在同类小插件里算不错的。

## 一、语言文件清单

LifestealZ 共 **15 个语言文件**，中文是：

```
zh-CN.yml    ← 简体中文
```

**只有简体中文，没有繁体中文。**

| 语种 | 有无 |
|------|------|
| 简体中文 | ✅ `zh-CN.yml` |
| 繁体中文 | ❌ 未提供 |

对大陆服来说够了。**如果你的服有港澳台玩家，繁体这边要自己补**（补法见第三节，结构一样）。

## 二、命名风格：注意和其他插件不一样

这是本页最值得单独拎出来的一点：

| 插件 | 中文文件名 | 风格 |
|------|-----------|------|
| **LifestealZ** | `zh-CN.yml` | **连字符 + 大写语言码** |
| GSit | `zh_cn.yml` | 下划线 + 小写 |
| Maintenance | `language-zh_tw.yml` | 前缀 + 连字符 + 小写 |
| Carbon | `messages-zh_CN.properties` | 前缀 + 下划线 + 大写 + properties |
| SkinsRestorer | 无 | 无语言文件 |

**四种风格，没有一种统一规范。**

**这意味着：任何「通用的汉化方案」都是不可行的。** 每次都得看这个插件实际用什么命名。照抄别的插件的经验会静默失效。

## 三、怎么切换

**默认跟随玩家客户端语言**，简体中文客户端进服自动生效。

需要强制统一语言的话，在 `plugins/LifestealZ/` 的配置里找语言 / locale 相关段落。**具体键名以你手上版本的配置文件注释为准。**

## 四、想改文案

```
1. 进 plugins/LifestealZ/
2. 复制 zh-CN.yml，改成自己要的文案
3. 重启服务器
```

**只改等号/冒号后面的值，不要动键名。**

关键是要**覆盖**原文件而不是新建一个名字不同的文件——名字必须严格是 `zh-CN.yml`。

## 五、三个容易踩的坑

**文件名大小写错了**

`zh-CN.yml` 和 `zh-cn.yml` 在 Windows 上能共存，在 Linux 服务器上**可能是同一个文件，也可能不是**——取决于文件系统大小写敏感性。

**跨系统搬服务器时这里容易出事。** 大小写敏感的系统上文件名不对 = 插件找不到 = 静默回退默认语言，**不报错**。

**直接改 jar 里的文件**

不要。升级插件就没了。语言文件从数据目录读。

**改了没生效**

**完整重启服务器。** 很多插件的语言文件是启动时加载的，`/lifestealz reload` 之类的重载命令不一定覆盖语言文件。**不确定就重启，重启永远是对的。**

## 六、配置和语言文件别搞混

`plugins/LifestealZ/` 里同时有**配置文件**和**语言文件**。两个都是 YAML，都用冒号，都很容易被搞混。

```
plugins/LifestealZ/
  ├── config.yml（或其他配置文件）  ← 吸血量、开关
  └── zh-CN.yml                     ← 消息文本
```

**症状对照：**

| 你改了什么 | 结果 |
|-----------|------|
| 改语言文件里的文案 | 生效 |
| 把文案写进配置文件 | **不生效**（配置不是消息来源） |
| 改配置文件的数值 | 生效 |
| 在语言文件里改数值 | **不生效**（语言文件不读配置） |

**分不清就多看两遍文件名。**

## 七、什么不会被汉化

语言文件只管**插件发出的消息文本**。这些不管：

- **原版界面元素**（血条、物品栏、伤害数字）—— 跟随客户端语言
- **其他插件的提示** —— 各写各的
- **战斗数值的显示**（比如超出上限的血量显示）—— 这是客户端渲染的

## 八、验证有没有生效

```
改完重启 → 简体中文客户端进服
  → 敲插件主命令看帮助
  → 看返回是中文还是英文
```

英文 → 检查文件名（99% 是这个问题）。

## 九、全站汉化情况对比

| 插件 | 简中 | 繁中 | 文件名风格 |
|------|------|------|-----------|
| **LifestealZ** | ✅ | ❌ | `zh-CN.yml`（连字符大写） |
| GSit | ✅ | ✅ | `zh_cn.yml`（下划线小写） |
| Maintenance | ❌ | ✅ | `language-zh_tw.yml`（前缀） |
| Carbon | ✅ | ✅ | `messages-zh_CN.properties` |
| SkinsRestorer | ❌ | ❌ | 无 |

**规律：完全没有。** 每个插件的作者各写各的。这就是为什么本站逐个插件核实，而不是给一个「通用汉化方案」。
