## InteractionVisualizer 安装教程

### 1. 它是什么

一个服务器管理员视角的调试工具。

玩家在破坏方块、放置方块、开关门、按按钮、挖东西——**这些操作平时只有玩家自己看得到**。InteractionVisualizer 让你在**你自己的客户端里**看到这些动作被标记出来。

```
平时：  玩家 A 挖了某块石头 → 只有他自己知道
        管理员看不到

装上后：玩家 A 挖了某块石头 → 管理员屏幕上那块石头被框出来
```

### 2. 真正有用的三个场景

**这是这个插件的核心价值，说清楚才知道什么时候装。**

| 场景 | 怎么用 |
|------|-------|
| **抓 Grief 证据** | 有人被说挖家，管理员打开可视化看他到底动了哪些方块 |
| **验证刷怪塔设计** | 自己设计的红石刷怪场，开可视化确认每个环节的触发顺序 |
| **排查玩家行为异常** | 有人行为可疑，标记出他碰过的所有方块，复现他的操作路径 |

**刷怪场验证这一条是很多人没想到的。** 做一个 10 层刷怪塔，靠猜是调不好的——可视化下能直接看到每一层水流/活塞的动作顺序，出问题立刻能看出来。

### 3. 为什么不是一个「大家都能用」的功能

**可视化信息只对你自己有用。** 别人的屏幕不需要显示这个。

所以它不是「给服务器加一个可视化功能」，而是**给管理员加一个调试视角**。这也决定了它的性能特征（见第 5 节）。

### 4. 版本与依赖

**支持 MC 1.11.2 - 26.3**，MC 兼容范围很宽。

- 需要 **Spigot / Paper 系服务端**
- 无硬依赖

**1.11.2 是下限。** 极老的服务端上也能用，但你的服如果在 1.11.2 以下，那也不现实了。

### 5. ⚠️ 性能：这是你最需要看的一点

**可视化要传输额外的方块标记数据给客户端。** 这意味着：

| 因素 | 影响 |
|------|------|
| **在线管理员数量** | 每个开可视化的管理员都增加一份传输量 |
| **在线玩家正在操作的数量** | 玩家操作越多，标记数据越多 |
| **服务器带宽** | 带标记的数据要走网络 |

**实践上的建议：**

- **只开自己一个人的可视化**，不要给整个管理组常开
- **人多的服务器（200+）别在高峰期开**——标记会随在线人数增长
- **发现「装了插件之后卡了」**，第一件事是关掉可视化开关看 TPS 是否恢复

> 这类可视化工具的典型代价：**服务器没变慢，但管理员客户端变卡了**。因为标记数据是发给你客户端的，你的机器要渲染这些框。**如果你客户端本身不流畅，开可视化会更卡。**

### 6. 安装

1. 下载 jar 放进 `plugins/`，重启
2. 生成 `plugins/InteractionVisualizer/`
3. 权限分配给管理员
4. 需要时打开开关，用完关掉

**默认应该是关闭的。** 如果它默认常开且影响性能，那和另一个设计思路（常驻标记）就不是一回事了——**以你版本的配置注释为准**。

### 7. 常用命令

| 命令 | 说明 |
|------|------|
| 主命令 + 开关参数 | 打开/关闭可视化 |
| 主命令帮助 | 看具体子命令 |

> ⚠️ **具体命令写法以你版本的帮助输出为准。** 这类插件的命令结构简单，通常就是「主命令 + on/off」或「主命令 + toggle」。本页不写死，避免你敲了没反应。

权限方面：**必须限制给管理员**。给玩家的后果是每个人都在传标记数据，服务器直接变卡。

### 8. 配置要点

配置在 `plugins/InteractionVisualizer/` 下。**具体键名以你手上版本的配置文件注释为准。**

逻辑上一般涉及：

| 类别 | 管什么 |
|------|-------|
| 显示哪些类型 | 破坏 / 放置 / 交互 / 全部 |
| 全局开关 | 默认开还是默认关 |
| 范围限制 | 距离管理员多远内显示（**这个很重要**——不限距离的话标记数据量会爆） |
| 显示样式 | 用什么方式标记（方块高亮 / 线条 / 其他） |

**「范围限制」是控制性能的关键。** 不限距离的话，管理员能看到全服所有玩家的操作，标记数据量随在线人数线性增长。**限制到一个合理的半径（几十到一百多格）是必须的。**

### 9. 常见坑

**客户端卡**
- 关掉可视化看是否恢复 → 确认是它造成的
- 调小范围限制
- 降低在线玩家数量时再看

**看不到标记**
- 你的客户端是不是自己开了可视化
- 距离超出范围限制了
- 被遮挡的方块不显示（正常的视线遮挡）
- **管理员需要对应权限**，别忘了分配

**能看到但别人说看不到**
这是**设计如此**——可视化只发给开了这个功能的客户端。别人看不到是正常的，不是 bug。

**服务器 TPS 掉了**
- 多个管理员同时开着可视化 → 只留一个人开
- 范围限制没配 → 配小

**和反作弊插件一起用**
两者**功能不冲突**（一个标记，一个检测），但都吃性能。同时开的时候注意 TPS。

**世界加载时大量标记刷屏**
进世界/传送时周围大量方块被加载，会产生一批标记。**这是正常现象**，如果太卡就调小范围。

### 10. 关于汉化

**本站未核实到 InteractionVisualizer 的官方中文语言文件机制。** 若要汉化需自行确认。

引导式排查方法：

1. 进 `plugins/InteractionVisualizer/`，看有没有语言文件目录
2. 搜配置文件里有没有 `message`、`language`、`locale` 段落
3. **注意**：这个插件的「界面」主要是**方块高亮这种视觉效果**，没有多少文本。**需要汉化的可能只有命令回显那几行**——文字量小的时候，自己用其他插件的消息接管功能改掉可能比汉化整个插件更快

**一个务实的判断：** 如果可汉化的内容只有三五行命令回显，且不影响核心功能，**不值得为了它折腾**。这类小插件的中文支持通常不是刚需。

想看全站各插件的汉化情况，见 [插件汉化与本地化完全指南](#/guide/plugin-localization)。

### 11. 什么时候别用它

- **不是管理员、玩家服** —— 你的屏幕用不上这个，纯浪费
- **超大型服（500+ 在线）** —— 标记数据量会很难看，除非限制到很小的范围
- **找不到「谁在干什么」的需求** —— 大部分服根本用不到这个
- **想靠它当反作弊** —— 它**不做检测、不报警、不阻止任何事**，只显示。反作弊要 Vulcan

### 12. 顺便说：它不能替代什么

这个插件很容易被误解成「管理神器」，说清楚边界：

| 它能做 | 它不能做 |
|--------|---------|
| 显示方块操作标记 | ❌ 检测作弊行为 |
| 帮你复现玩家操作路径 | ❌ 自动处罚 |
| 验证红石/刷怪设计 | ❌ 回滚被破坏的方块 |
| 提供「目击证据」 | ❌ 永久记录（**关掉就没了**） |

**最后一条尤其重要：这不是日志系统。** 关掉可视化就没有历史数据了。**要做事后追溯，得配 CoreProtect 这类方块记录插件**——两者互补，不是替代。
